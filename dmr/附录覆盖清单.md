**覆盖口径**

| 标记 | 含义 |
|------|------|
| **COVERED** | 有对应中文学习笔记（可跨文件） |
| **NAMES ONLY** | 仅名称/用途索引，不抄矩阵/完整 hex |
| **PRINCIPLES COVERED** | 故意不抄矩阵/全比特/符号表，但有原则级中文说明 |
| **STUB** | 故意短注（图例/notation） |
| **SKIP** | 故意跳过（CR 历史、书目、Void；纯表体仍回 PDF） |

内容型附录优先补：**编址、定时器、拨号、省电/接入、IPv6 策略、FID、高层状态**。  
不补：**FEC 生成矩阵、SYNC hex 全表、Idle 96-bit 逐位表、Annex E 发射符号逐表、MSC/SDL 画图规则长文**。  
原则补丁：[`01-空中接口/跳过项原则说明.md`](./01-空中接口/跳过项原则说明.md)（Part1 B/D/E → **PRINCIPLES COVERED**）。

## 1. 各文档 Annex 子结构（Contents 摘录）

### 1.1 TR 102 398
- **A** Power Save：Wake-up / Synchronized；登记 PowerSave_RQ
- **B** Channel Access：Withdrawn slots；Mask / Service Function；Random Backoff
- **C** Protocol Architecture：L1/L2/L3
- **D** Power Control：闭环功率
- **E** Bibliography

### 1.2 Part 1
- **A** Table A.1 个号/组号分区
- **B** BPTC / Trellis / Golay / Hamming / RS / CRC…（矩阵 SKIP；原则见 `跳过项原则说明.md`）
- **C** Direct mode / Reverse Channel 时序例
- **D** Null（全 0）/ Idle（指定 PRBS→BPTC）（原则 COVERED）
- **E** 突发 dibit 发射顺序表（表 SKIP；原则 COVERED）
- **F** L2 timers / constants
- **G** MS/BS 高层 SDL 状态
- **H** SFID / MFID
- **I** Void · **J** CR

### 1.3 Part 2
- **A** L3 timers / constants（ACKWait、TO、CT 等）
- **B** FLCO / CSBKO / SLCO
- **C** UI↔AI 拨号（informative）
- **D** CR · **E** Bibliography

### 1.4 Part 3
- **A** PDP L2 timers / constants
- **B** FLCO=`110000` TD_LC only
- **C** IPv6 over PDP（informative）
- **D** CR · **E** Bibliography

### 1.5 Part 4
- **A** Timers / constants / levels / Gateways(A.4)
- **B** Opcode + UDT 载荷格式 B.3.*
- **C** Physical Channel Plan
- **D** Hunt
- **E** Fleet dialling
- **F** MSC/SDL notation
- **G** Native addressing
- **H** Bibliography
