> **学习用整理，冲突以 ETSI 原文为准；非全文复制。**  
> 源：ETSI **TS 102 361-3 V1.3.1 (2017-10)**（Packet Data Protocol）

## 1. 与 Part 1 的衔接

| Part 1 概念 | 在 PDP 中的角色 |
|-------------|-----------------|
| Data Type = Data Header (`0110`) | C_HEAD / U_HEAD / SP_HEAD / R_HEAD / DD_HEAD / UDT_HEAD / P_HEAD / C_RHEAD |
| Data Type = Rate ½ / ¾ / 1 Data | 用户数据续块 / 末块（确认可含 DBSN） |
| Data Type = Terminator with LC | 数据 hangtime 时 BS/MS 可发 **TD_LC** |
| DPF（Format，4 bit） | 包类型 |
| SAP（4 bit） | 上层处理 / 压缩类型 |
| LLID 24+24 | 目的/源；可与 SAID/DAID 推导 IPv4 |

**DPF**（Part 1 Table **9.30**）：

| Value | Meaning |
|-------|---------|
| 0000 | Unified Data Transport (UDT) |
| 0001 | Response packet |
| 0010 | Unconfirmed data |
| 0011 | Confirmed data |
| 1101 | Short Data: Defined |
| 1110 | Short Data: Raw or Status/Precoded |
| 1111 | Proprietary |

**SAP**（Part 1 Table **9.31**）：

| Value | Meaning |
|-------|---------|
| 0000 | UDT |
| 0010 | TCP/IP header compression |
| 0011 | UDP/IP header compression |
| 0100 | IP based Packet data |
| 0101 | ARP |
| 1001 | Proprietary Packet data |
| 1010 | Short Data |

> **TCP HC**：SAP=`0010` 已预留；Part 3 V1.3.1 **clause 7.2** 正文展开的是 **UDP/IPv4** 压缩头字段表。未见与 UDP 对等的完整 TCP 压缩八位组表 → 本速览不编造 TCP HC 字段。

## 2. C_HEAD / U_HEAD 逐比特对照

引用：Part 1 Tables **9.10 / 9.15**；过程 clause **8.2.1**。两端头均为 **96 bits**。

### 2.1 字段表

| IE | Len | C_HEAD（确认） | U_HEAD（非确认） | 条款 |
|----|-----|----------------|------------------|------|
| Group or Individual (G/I) | 1 | 目的 LLID 是否组 | 同左 | 9.3.15 |
| Response Requested (A) | 1 | 是否请求响应 | **固定 `0`** | 9.3.16 |
| Reserved | 1 | `0` | `0` | |
| Pad Octet Count (POC) MSB | 1 | 合成 5-bit POC | 同左 | 9.3.22 |
| Format (DPF) | 4 | 包类型 | 同左 | 9.3.17 |
| SAP Identifier | 4 | 上层 | 同左 | 9.3.18 |
| POC LSBs | 4 | | | 9.3.22 |
| LLID Destination | 24 | | | 9.3.19 |
| LLID Source | 24 | | | 9.3.19 |
| Full Message Flag (FMF) | 1 | 首试/重试 | **固定 `1`** | 9.3.20 |
| Blocks to Follow (BF) | 7 | 后续块数（不含本头） | 同左 | 9.3.21 |
| Re-Synchronize (S) | 1 | 是否同步序号 | （无：改为 Reserved 4） | 9.3.23 |
| Send sequence N(S) | 3 | mod 8 | （并入 Reserved） | 9.3.24 |
| Reserved | — | — | **4 bit =0**（替 S/N(S)） | 9.15 |
| Fragment Sequence Number (FSN) | 4 | 分片（含末片标志） | 同左 | 9.3.25 |
| Header CRC | 16 | CRC-CCITT | 同左 | B.3.8 |

### 2.2 八位组直觉（确认头）

```text
  [G/I|A|0|POC_msb| DPF ][ SAP | POC_lsb ][ Dest LLID 24 ][ Src LLID 24 ]
  [FMF| BF 7 ][ S | N(S) 3 | FSN 4 ][ Header CRC 16 ]
```

非确认：A=0，FMF=1，S/N(S) 位置为 Reserved=0。

POC 与用户八位组数关系 → Part 1 **9.3.22**（含 pad 计算）。

## 3. 续块 / 末块载荷（确认 vs 非确认）

引用：Part 1 Tables **9.11–9.18C**。

| PDU | 确认 | 非确认 |
|-----|------|--------|
| Rate ¾ DATA | DBSN(7)+CRC-9(9)+User(128)=144 | User 144 |
| Rate ¾ LDATA | DBSN+CRC-9+User(96)+MsgCRC(32) | User(112)+MsgCRC(32) |
| Rate ½ DATA | DBSN+CRC-9+User(80)=96 | User 96 |
| Rate ½ LDATA | DBSN+CRC-9+User(48)+MsgCRC(32) | User(64)+MsgCRC(32) |
| Rate 1 DATA | DBSN+CRC-9+User(176)=192 | User 192 |
| Rate 1 LDATA | DBSN+CRC-9+User(144)+MsgCRC(32)（确认表 9.18B） | User(160)+MsgCRC(32) |

DBSN → Part 1 **9.3.26**；MsgCRC 为 32-bit CRC（B.3.9）；块内 CRC-9 覆盖 DBSN+User（B.3.10）。

## 4. 确认响应字段（C_RHEAD / C_RDATA）

引用：Part 1 Tables **9.13 / 9.14**；Part 3 Tables **6.4–6.6**。

### 4.1 C_RHEAD（96 bits）

| IE | Len | 备注 |
|----|-----|------|
| Reserved | 1 | `0` |
| A | 1 | **`0`** |
| Reserved | 2 | `0` |
| Format (DPF) | 4 | 通常 Response=`0001` |
| SAP | 4 | |
| Reserved | 4 | `0` |
| LLID Dest / Src | 24+24 | |
| FMF | 1 | **`0`** |
| BF | 7 | 若跟 C_RDATA 则为块数 |
| Class | 2 | 响应类 |
| Type | 3 | 响应类型 |
| Status | 3 | 状态 |
| Header CRC | 16 | |

### 4.2 C_RDATA（96 bits）

| IE | Len | 备注 |
|----|-----|------|
| Retry Flags (RF) | 64 | 选择重传位图；未用/超出块号的位置规范置约定值 |
| Response CRC | 32 | |

### 4.3 短数据响应 Class/Type/Status（Part 3 Table 6.6）

| Class | Type | Status | Message | 含义摘要 |
|-------|------|--------|---------|----------|
| 00 | 001 | 000 | ACK | 全部块成功 |
| 01 | 000 | 000 | NACK | Illegal format |
| 01 | 001 | 000 | NACK | Packet CRC failed |
| 01 | 010 | 000 | NACK | Memory full |
| 01 | 100 | 000 | NACK | Undeliverable |
| 10 | 000 | 000 | SACK | 按 C_RDATA 位图选择重传 |

完整响应集另见 Part 1 **8.2.2.3**（Table 6.6 为其子集）。短数据仅支持 stop-and-wait。

### 4.4 A + SARQ → 响应模式（Table 6.5）

| A | SARQ | 含义 |
|---|------|------|
| 0 | 0 | 非确认（无响应） |
| 0 | 1 | 保留 |
| 1 | 0 | 确认（整消息） |
| 1 | 1 | 确认 + 按块 SARQ |

R_HEAD / DD_HEAD：无 SARQ 时 F 置约定值；有 SARQ 时首次 F=`1`、重试 F=`0`（Part 3 正文）。

## 7. UDP/IPv4 压缩头（Part 3 clause 7.2 / Table 7.14）

压缩头位于**第一个数据续块**；SAP = UDP/IP header compression (`0011`)。

### 7.1 压缩头字段

| IE | Len | 备注 | 条款 |
|----|-----|------|------|
| IPv4 Identification | 16 | 原样传送 | 7.2.2.5 / T7.8 |
| SAID | 4 | 源网段索引 | T7.15 |
| DAID | 4 | 目的网段索引 | T7.16 |
| HC Opcode bit1 | 1 | Opcode MSB | T7.19 |
| SPID | 7 | 源端口索引；`0000000`→扩展头带真端口 | T7.17 |
| HC Opcode bit2 | 1 | Opcode LSB | |
| DPID | 7 | 目的端口索引 | T7.18 |
| Extended Header 1 | 16 | 可选 UDP 端口 | T7.20 |
| Extended Header 2 | 16 | 可选 UDP 端口 | T7.21 |

**Header Compression Opcode**（2 bit）：`00` = UDP/IPv4 Header Compression；其它保留。

### 7.2 SAID / DAID / SPID / DPID 取值摘要

| IE | 关键值 |
|----|--------|
| SAID | `0000` Radio Network；`0001` USB(Ethernet)；`1100–1111` 厂商；其它保留 |
| DAID | 同上，另 `0010` Group Network |
| SPID/DPID | `0000000` → 真端口在 Extended Header；`0000001`→5016 UTF-16BE Text；`0000010`→5017 LIP；高值厂商可配 |

### 7.3 Extended Header 选用（Tables 7.20/7.21）

| SPID | DPID | EH1 | EH2 |
|------|------|-----|-----|
| 0 | 任意 | 源 UDP 端口 | （若 DPID 也 0 → EH2=目的端口） |
| ≠0 | 0 | 目的 UDP 端口 | 不用→改放应用数据 |
| ≠0 | ≠0 | 不用→应用数据 | 不用→应用数据 |
| 0 | 0 | 源端口 | 目的端口 |

### 7.4 解压侧常量 / 推导（摘要）

| 字段 | Len | 处理 |
|------|-----|------|
| UDP Length | 16 | = 8 + User − 压缩头字节（T7.2） |
| UDP Checksum | 16 | 接收侧重算（RFC 768） |
| IPv4 Version / IHL | 4+4 | 常量 `0100` / `0101`（IHL=5） |
| IPv4 TOS / Flags / FragOff | 8+3+13 | 规范默认（常 0） |
| IPv4 Total Length | 16 | = 20 + UDP Length |
| IPv4 TTL / Protocol | 8+8 | 默认；Protocol=UDP |
| IPv4 Header Checksum | 16 | 接收侧重算 |
| IPv4 Src/Dst Addr | 32+32 | SAID/DAID + Data Header LLID 推导（DLL derived IP） |

## 9. 缺口

- ARP 过程、IP PDP 无压缩路径的完整状态机未展开。  
- **TCP/IP header compression**：仅有 SAP 编码，无 Part 3 逐字段表（不臆造）。  
- UDT Opcode / 控制信道短数据字节布局 → Part 4。  
- FEC/交织仍以 Part 1 Annex B 为准（本库不抄矩阵）。
