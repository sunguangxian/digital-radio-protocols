## 3. 阶段 A–E 速通复习（要能一口气说清楚）

每一阶段给你五样：一口气解释、钉子事实、现场易错、回库翻哪篇、以及「若只能留一张纸条写什么」。**不要只背标题。**

### 3.1 阶段 A（第 1–8 课）· 通信地基

**一口气**：无线电把信息装进电磁波发出去；频率是抖多快，带宽是占多宽；DMR 用 **12.5 kHz** 宽的一条「车道」，用 **4FSK** 把比特变成四种频率偏移；多址上 DMR 选 **TDMA 两时隙**，所以同一条车道里能跑两路独立业务；半双工 + 中继/直通是业务形态，个呼/组呼是「找谁说话」。

**钉子**：

1. **频率 ≠ 信道号 ≠ 带宽**——频率是位置，信道间隔是相邻车道间距，带宽是这条信号占多宽。  
2. **4FSK：1 符号 = 2 bit；4800 符号/s → 9600 bit/s**。  
3. **12.5 kHz 车道 + 两时隙 → 业界常说的「6.25 kHz 等效」**（容量口径，不是真把 RF 切成 6.25）。  
4. 模拟对讲是连续波形；数字对讲先量化/编码再调制。  
5. 个呼找一台、组呼找一群——空口最终都落成地址比特。

**易错**：把「听得到」当成「协议对了」；把信道间隔和占用带宽混谈；以为数字对讲不需要天线与覆盖规划；把「数字」理解成「不吃干扰」。

**纸条上只写**：`12.5 kHz · 4FSK · 9600 b/s · 两时隙 TDMA`。


**现场小故事**：新同事把分析仪上的「有能量」当成「DMR 正常」。你带着他看 SYNC：能量在，SYNC 解不出——可能是邻频、模拟残留或 CC 不对。阶段 A 的价值就是：先分清「射频有东西」和「协议有身份」。

**回库**：`学习推送/加餐_频率带宽与调制解调.md`；`00-入门/DMR术语与帧结构速查卡.md`；第 1–4 课原文。

### 3.2 阶段 B（第 9–14 课）· DMR 全貌

**一口气**：DMR 是 ETSI 标准的数字对讲体系；**Tier I** 免执照直通，**Tier II** 执照直通/中继，**Tier III** 带控制器的集群；文档上 **TR 102 398** 讲系统设计，**TS 102 361-1/2/3/4** 分别管空口、语音通用、数据、集群；分层上 L1 物理、L2 链路积木、L3 业务；互操作要看 **SFID / MFID / FLCO** 这几块「门牌」。

**钉子**：

1. Tier 决定「有没有中继 / 有没有 TSCC」，不是决定「是不是 4FSK」。  
2. Part 1 是所有 Tier 的空口底板；Part 4 主要在 Tier III 上场。  
3. 语音 / 数据 / 补充业务是三条业务河，共用同一条空口河床。  
4. 厂商私有功能靠 MFID；标准功能走标准 FID。  
5. `总索引.md` 是「我想查什么」入口，不是按页码读书。

**易错**：把厂商手册当成 ETSI 原文；Tier II 经验直接套 Tier III（缺少登记/Grant 会整段失语）；一上来就啃 Part 4 Annex，地基和空口还糊。

**纸条上只写**：`Tier II=中继 · Tier III=TSCC+Grant · Part1底板 · 总索引检索`。


**现场小故事**：销售材料写「全面支持集群业务」，交付却是 Tier II 中继 + 厂家私有调度。阶段 B 教你先问：有没有 **TSCC**？有没有 **登记 / Grant**？没有前台就不要用 Part 4 的词去承诺 Part 2 的系统。

**回库**：`00-入门/DMR_Tier说明.md`；`DMR整合学习手册.md`；`DMR协议学习导航.md`；`总索引.md` §0–§1；`00-入门/TR102398_V1.5.1_系统设计总览.pdf`。

### 3.3 阶段 C（第 15–24 课）· 空口深入

**一口气**：时间切成 **30 ms** 时隙，两时隙组成 **60 ms** 帧；每个时隙里塞一个突发（约 264 bit）；语音用 **A–F 超帧** 轮转；**CACH** 夹在基站下行缝里捎带路况；**SYNC** 告诉你这是语音还是数据/控制；**Colour Code** 区分同频邻居；**EMB / SLOT / LC / CSBK** 是控制与嵌入信息的积木；FEC 负责「修小错」，学习口径只懂原则、不背矩阵。

**钉子**：

1. **30 ms · ~264 bit · 9600 bit/s** 三者互相咬合——算一算：30 ms × 9600 ≈ 288 bit 量级，扣掉保护与开销后有效载荷落到约 264 bit 这一档（细节以 Part 1 为准）。  
2. 超帧 A–F：语音连续说时的「呼吸节奏」；嵌入 LC 让迟后进入成为可能。  
3. SYNC 是「当前突发身份牌」；认错 SYNC 后面全错。  
4. Colour Code 同频不同网的「小区油漆」。  
5. CSBK / LC 是控制信令的两种常见容器；Tier III 的 C_RAND / C_AHOY / Grant 多数是 CSBK 家族。

**易错**：只看音频好坏不看 SYNC/CC；把 FEC 失败当成「没覆盖」；在分析仪上忽略 CACH；背 FEC 矩阵却说不清「它挂在哪类突发上」。

**纸条上只写**：`先认 SYNC 与 CC，再拆 LC/CSBK；FEC 懂原则即可`。


**现场小故事**：两网同频，用户抱怨「串台」。能量图看起来像干扰，解码一看 Colour Code 不同——有的终端配置错了 CC，有的扫到了邻居。阶段 C 让你相信：**身份牌（SYNC/CC）比音量重要**。

**回库**：`01-空中接口/帧结构与字段定义.md`；`CSBK与LC字段详表.md`；`跳过项原则说明.md`；`AnnexA编址与AnnexH_FID.md`；`00-入门/DMR术语与帧结构速查卡.md`；PDF `TS102361-1_V2.7.1.pdf`。

### 3.4 阶段 D（第 25–30 课）· 语音与数据

**一口气**：一次语音呼叫在空口上大致是「可选预告 → Voice LC Header → 超帧 A–F（嵌入 LC）→ Terminator → Hangtime → Idle」；迟后进入让中途开机的人还能加进来；数据侧有确认/非确认 PDP、短数据与头压缩；查字段时先速览文再回 PDF。

**钉子**：

1. Hangtime 不是「电话还通着」，是「信道还被这次呼叫占着等你续说」。  
2. 迟后进入依赖嵌入 LC / 头信息窗口——和超帧设计绑在一起。  
3. Part 2 管语音与通用服务，Part 3 管分组数据协议。  
4. 「字段文怎么查」本身是技能（第 29 课）：先总索引关键词 → 速览 → PDF 条款。  
5. 第 30 课小综合是 Tier II/通用空口跟读；Tier III 还要在前面加 TSCC 信令。

**易错**：把 Tier II 中继呼叫流程直接当成集群流程；短数据（Part 3）与 UDT（Tier III 控制信道小货车）混名；只会点网管按钮，不会在速览文里定位字段。

**纸条上只写**：`语音=头+A–F+Terminator+Hang；查字段走总索引→速览→PDF`。


**现场小故事**：用户说「电话没挂干净，信道一直被占」。其实是 Hangtime 还在——对方松开 PTT 后系统仍短暂保留信道等续说。阶段 D 把「用户体感」翻译成「空口时间线」，避免误判为死锁。

**回库**：`02-语音业务/语音业务字段速览.md`；`AnnexA定时器.md`；`03-数据协议/数据协议字段速览.md`；对应 Part 2/3 PDF。

### 3.5 阶段 E（第 31–39 课）· 集群 Tier III

**一口气**：集群多了**前台（TSCC）**和**客房（业务信道）**；手台要先**猎站 → 登记（常伴随鉴权）**，打电话先 **C_RAND**，网络用 **Grant** 派客房，用 **Reason** 解释拒绝/排队；频率用 **CHAN**（0 / 1…4094 / 4095）或绝对频率续块；拨号把键盘串映射到 24-bit 地址（Annex E 信息性，Annex G 规范性原生编址）；Stun/Revive/Kill、短信、DGNA 走**控制信道上的管理与 UDT 搬运**，不另占业务信道。

**钉子（务必能默写）**：

| 钉子 | 要点 | 课 |
|------|------|----|
| TSCC vs Payload | 前台发令、客房跑语音/大数据 | 31 |
| 登记 / Aloha | 先被网络认得，才能稳定要业务 | 32 |
| Grant | 成功路径发 Grant（常重复）；失败走 NACK+Reason | 33 |
| Reason | ACK 族里的「为什么」；认码值胜过认中文别名 | 34 |
| 鉴权 | C_AHOY Source=RAND，响应在 ACK；Kill/带鉴权 Stun 有反向考网络；RC4 边界 | 35 |
| CHAN | 0 无效；1…4094 查表；4095=看绝对频率续块；`f = fbase+(CHAN−1)×SEP` | 36 |
| Hunt | 四阶段思路：上次 TSCC → 受令 → 短列表 → 综合扫描；先验证再确认才发射 | 37 |
| 拨号 | NAI‖SSI/SGI；NP=NAI+296 等映射；PSTNI `FFFEC0`；全呼特殊地址；Annex E/G | 38 |
| 管理/UDT | STUNI `FFFECC` / KILLI `FFFECF` / DGNAI `FFFED6` / SDMI `FFFEC5`；UDT 80/176/272/368 bit；DGNA 15+1 | 39 |

**把第 38–39 课几个「门牌地址」再钉一遍**（教学用，不是让你去扫网）：

| 地址 | 名字 | 用途直觉 |
|------|------|----------|
| `FFFEC0` | PSTNI | 外线网关（拨号课） |
| `FFFEC5` | SDMI | 短数据「要货」名义 |
| `FFFECC` | STUNI | 远程暂时禁用/恢复 |
| `FFFECF` | KILLI | 永久禁用（须鉴权） |
| `FFFED6` | DGNAI | 动态组业务台 |

**易错**：Grant 成功却无声——先查 CHAN↔频率表与 CC，再查射频；Reason 当噪声忽略；Stun 后仍见登记以为「没禁上」（Stun 本就保留登记/定位）；组短信「已送达」当成「某人已读」；DGNA Address 模式漏带旧组导致「组丢了」。

**纸条上只写**：`前台要票(Grant)·客房说话·Reason解释拒绝·CHAN是房号不是MHz`。


**现场小故事（三则速记）**：  
1）Grant 成功无声 → 写频缺 CHAN（第 36 课）。  
2）组短信「已送达」投诉 → 组呼不保证个体（第 39 课）。  
3）Stun 后地图仍有点 → 定位保留是设计（第 39 课）。  
阶段 E 的学习成果不是「会背网关地址」，而是**把现象翻译成步骤号**。

### 3.6 五阶段速查卡（打印贴墙）

```text
A 地基     12.5kHz | 4FSK | 9600b/s | TDMA两时隙 | 半双工·中继·个呼组呼
B 全貌     TierI/II/III | TR+Part1-4 | L1/L2/L3 | 语音·数据·补充 | SFID/MFID
C 空口     30ms | 264bit | A-F超帧 | CACH | SYNC | CC | EMB | LC | CSBK | FEC原则
D 语音数据  Header→A-F→Term→Hang | 迟后进入 | PDP | 短数据 | 字段文检索技能
E 集群     TSCC/Payload | 登记Aloha | Grant | Reason | 鉴权 | CHAN | Hunt | 拨号 | Stun·DGNA·UDT
```

**阶段之间的「接口」——最容易断的四根线**：

1. **A→C**：会说 4FSK，但不会把 9600 bit/s 和 30 ms 突发对上。  
2. **C→D**：会认 SYNC，但跟不住一次语音呼叫的时间线。  
3. **D→E**：会跟 Tier II 呼叫，但一上 TSCC 就丢掉「先要票再进客房」。  
4. **E 内部**：会 Grant，但 CHAN 表错；或会 Stun，但把组短信语义当已读。

收官自检：挑一根你最容易断的线，用对应两课各重读 20 分钟。
