# DMR 深入学习推送大纲（由浅入深）

面向：通信基础弱的 DMR 方向工作人员。
**篇幅要求（用户明确要求加厚）**：每课约 **20–35 分钟**阅读量；必须含：总图/故事、术语表、与现场工作对照、自测题、加深阅读链接。禁止只有大纲式短条。
资料库：`/workspace/digital-radio-protocols/dmr/`（总索引、手册、字段文、官方 PDF；兼容软链 `/workspace/dmr-protocol` → 多协议库根）。

## 阶段 A · 通信地基（约第 1–8 课）
1. 无线电在干什么：发射、接收、信道、干扰
2. 频率、波长、频段、信道间隔（12.5 kHz 从哪来）
3. 模拟对讲 vs 数字对讲：声音怎么变成比特
4. 调制直觉：4FSK 是什么（不推公式）
5. 多址：FDMA / TDMA / CDMA 谁占什么
6. 双工、半双工、中继、直通
7. 寻址直觉：谁在跟谁说话（个呼/组呼）
8. 从模拟到 DMR：为什么要标准化

## 阶段 B · DMR 全貌（约第 9–14 课）
9. DMR 是什么 + Tier I/II/III
10. 12.5 kHz 与 6.25 kHz 等效
11. 文档地图：TR + Part1–4 各管什么
12. 协议分层 L1/L2/L3
13. 业务全景：语音 / 数据 / 补充业务
14. 互操作：SFID / MFID / FLCO

## 阶段 C · 空口深入（约第 15–24 课）
15. 时隙 30 ms 与 TDMA frame
16. 突发 264 bit 与 108+48+108
17. 语音超帧 A–F
18. CACH 与 Guard
19. SYNC：语音/数据如何区分
20. Colour Code 与同频系统
21. EMB / SLOT 字段
22. FULL LC / SHORT LC
23. CSBK 控制信令块
24. FEC 原则（不贴矩阵）

## 阶段 D · 语音与数据（约第 25–30 课）
25. 语音呼叫过程直觉
26. 补充业务（迟后进入等）
27. PDP：确认与非确认数据
28. 短数据与头压缩
29. Part2/Part3 字段文怎么查
30. 小综合：跟一次语音呼叫空口

## 阶段 E · 集群 Tier III（约第 31–40 课）
31. 控制信道 vs 业务信道
32. 登记与 Aloha
33. Grant 变体地图
34. Reason Code 怎么读
35. 鉴权挑战响应（边界：RC4）
36. 频率 CHAN / 绝对频率
37. 猎站 Hunt
38. 拨号与本地编址
39. Stun / DGNA / UDT
40. 总复习 + 岗位深挖路线（已完成 · 全课程收官）

推送时：用白话讲清「是什么→为什么→在 DMR 里落在哪→去资料库哪一篇加深」；内容必须加厚，达到 20–35 分钟阅读量。
