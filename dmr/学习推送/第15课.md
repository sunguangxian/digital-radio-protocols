# 第 15 课 · 时隙 30 ms 与 TDMA frame

> DMR 深入学习 · **阶段 C 空口深入开篇**  
> 适合：已走完阶段 B（业务全景 + SFID/MFID/FLCO），但写频看到 Slot1/Slot2、听同事说「拧错时隙」、看中继「一路忙一路闲」仍觉得抽象的人  
> 阅读量：约 **30–40 分钟** · 几乎不推公式 · 要把「**Timeslot = 30 ms、TDMA frame = 60 ms、同一 12.5 kHz 路上两段绿灯**」钉死  
> **频谱提醒（一小段，不是本课主线）**：RF 载波仍是整条 **12.5 kHz**；双时隙是在这条路上用**时间**切开两路业务，**不是**把载波劈成两条 6.25 kHz。所谓 **6.25e** 是频谱效率记账。调制仍是 **4FSK**，总比特率约 **9.6 kbps**。细节见 `学习推送/加餐_频率带宽与调制解调.md` 与第 2–5 课；本课主线是**时隙 / 帧时序**。

## 1. 为什么本课重要（动机）

第 14 课收官了阶段 B：你会看门牌（FID）和功能码（FLCO/CSBKO）。从本课起进入阶段 C——**空口肌肉记忆**。下一关不是再背菜单，而是学会**在时间轴上走路**：

- 写频软件里 Channel 表有一列 **Slot / Timeslot = 1 或 2**。同频、同色码、同 Talkgroup，**Slot 写反**——对端 RSSI 可能很好，就是听不见话。像拧错台，但台号看起来「都对」。  
- 中继站对外说「一个频点顶两路」：Slot1 在开组呼会议，Slot2 同时在做个呼调度。**物理上还是一个 12.5 kHz 载波**；时间上轮流绿灯。  
- 现场报障「听不到声」：先查电量、天线、频率、色码——然后**务必查时隙**。错槽是高频误区，排障清单里常被漏掉。  
- 直通（Direct / Talkaround）两台要对齐同一时隙节拍；否则像两个人抢同一段绿灯，或各走各的「看不见」的车道。  
- 抓包 / 频谱仪：看到的是**脉冲状**占空（每 60 ms 里大约一半时间有该逻辑信道的突发），不是「载波宽度变窄一半」。

若只背「DMR = 双时隙」五个字，后面会卡在同一处：

> **时隙不是第二个频点。同一条 12.5 kHz 马路上，按 30 ms 切成两段绿灯；两段绿灯拼成一个 60 ms 的 TDMA frame。听得见比特之后，时间轴上到底轮到谁说话——才是本课要钉死的事。**

本课目标是让你能自己讲清十件事：

1. **为什么**要用「双车道红绿灯 / 两人共用一条马路」记双时隙；  
2. 一张总图：TDMA frame = TS1 + TS2 = 60 ms；入站 Guard vs 出站 CACH；  
3. 白话术语：Timeslot、TDMA frame、Burst、Guard、CACH、Inbound/Outbound、Logical vs Physical、6.25e、Superframe（脸熟）；  
4. 现场岗位：写频 Slot、中继两路、MS 50% 占空、错槽、频谱仪脉冲；  
5. 完整时钟例子：0–120 ms 跟一次 Tier II 中继双路业务；  
6. 数字账本：30 / 60 / 27.5 / 2.5 / 264 / 360 等；  
7. 常见误区（至少五条）+ 自测；  
8. 资料库加深路径；  
9. 为第 16 课「264 = 108+48+108」留下钩子；  
10. 核验过的外链（白皮书图 + Part1 4.2 + 现场直觉文）。

## 2. 总图 / 故事：双车道红绿灯（同一条 12.5 kHz 马路）

先把整课装进一个故事，再落到 Part1 clause **4.2** 与资料库速查卡。精神与 `00-入门/DMR术语与帧结构速查卡.md`、`01-空中接口/帧结构与字段定义.md` §2 一致。

### 2.1 马路 + 红绿灯（直觉）

想象专业对讲规划给你**一整条**马路：宽度固定是 **12.5 kHz**（这是频谱尺子上的「地皮」）。DMR 不把马路从中间砌墙劈成两条窄路，而是装上一套**红绿灯**：

```text
同一条 12.5 kHz 马路（物理载波 / Physical channel）
────────────────────────────────────────────────────────
时间 →

  ┌────────── TDMA frame = 60 ms ──────────┐┌── 下一帧…
  │  Timeslot 1 = 30 ms  │ Timeslot 2=30ms ││
  │  绿灯：逻辑信道 1    │ 绿灯：逻辑信道 2 ││
  │  （Slot1 上的业务）  │ （Slot2 上的业务）││
  └─────────────────────┴─────────────────┘└─
```

- **绿灯亮 30 ms**：轮到这一侧逻辑信道发/收自己的 **Burst（突发）**。  
- **两段绿灯 = 一个 TDMA frame = 60 ms**：帧是「一对时隙」的包装名，不是另一种更长的「语音超帧」。  
- **用户耳朵**听不到「咯噔咯噔断续」：因为一突发里装的压缩语音大约够 **60 ms** 听感，接收端再平滑——细节账在第 16 课，本课先记住「**30 ms 窗口里能塞约 60 ms 话**」这个反直觉结论。

口诀：**分的是时间，不是把载波劈成两半。**

### 2.2 一个时隙内部：27.5 ms 干活 + 2.5 ms「缝」

时隙名义长度 **30.0 ms**，但「装比特的货箱」大约只有 **27.5 ms**，里面塞 **264 bit**。剩下约 **2.5 ms** 不是浪费，用途看方向：

```text
入站（MS → BS，手机/手台往中心站送）：
  [==== 27.5 ms · 264 bit 业务突发 ====][≈2.5 ms Guard]
       ↑ PA 爬升、传播时延、避免撞上下一时隙

出站（BS → MS，中心站往外广播）：
  [==== 27.5 ms · 264 bit 业务突发 ====][≈2.5 ms CACH]
       ↑ 公共通告信道：时隙忙闲、信道号、低速信令等
```

| 方向 | ≈2.5 ms 常干什么 | 一句话 |
|------|------------------|--------|
| **入站 Inbound** | **Guard（保护间隔）** | 给功放爬升、传播时延留缝，降低「踩到邻时隙脚趾」 |
| **出站 Outbound** | **CACH（24 bit）** | 基站夹在业务突发之间的小广播；约每 **30 ms** 一次 |

本课对 CACH 只要求脸熟：**仅出站、24 bit、约每 30 ms**。字段拆解留给第 18 课。

### 2.3 264 bit 钩子（本课不深挖）

```text
一个 Traffic burst ≈ 27.5 ms · 264 bit
        ┌─────────┬──────────┬─────────┐
        │ 108 bit │  48 bit  │ 108 bit │
        │ Payload │ SYNC/嵌入│ Payload │
        └─────────┴──────────┴─────────┘
两个 Payload 合计 216 bit → 约可承载 60 ms 压缩语音
```

下一课（第 16 课）专门拆 **108+48+108**。本课只要你会说：「时隙是 30 ms 的时间窗；窗里主要货箱是 264 bit。」

### 2.4 语音超帧脸熟（360 ms）

连续 **6** 个业务突发标成 **A–F**，合起来叫 **Voice superframe = 360 ms**。本课只要求：看到「超帧」别和「TDMA frame（60 ms）」搞混。第 17 课再深挖 A–F 与 SYNC 疏密。

### 2.5 入站相对出站的常见 30 ms 偏移

两频中继常见做法：入站突发相对出站**中心对齐**，编号上常见 **30 ms 偏移**方案，好让 **CACH 用同一信道号**指「这一侧入站 / 出站」。实现细节以 Part1 clause **4.2.1** 为准；现场语感是——**基站出站可以两槽都在响，手机入站一次只占自己的那一槽**。

### 2.6 和第 5 课多址地图的接口（不重讲加餐）

第 5 课钉过：DMR 主流专业层是 **2-slot TDMA**。本课把那句落到毫米钟面：

| 第 5 课说法 | 本课落点 |
|-------------|----------|
| 分的是时间 | Timeslot = **30 ms** 绿灯 |
| 一帧两槽 | TDMA frame = **60 ms** |
| 6.25e 是记账 | 地皮仍 **12.5 kHz**；本课不再展开四句话表 |
| 逻辑信道 vs 物理信道 | Slot1/2 = 逻辑；12.5 kHz 载波 = 物理 |

若第 5 课「三种排座法」还熟，本课只是把 TDMA 那张椅子的**椅背高度（30 ms）**量清楚。

## 3. 白话术语表

把墙上词一次说清楚。冲突时以 **ETSI TS 102 361-1 V2.7.1** 为准；TR 102 398 是导读。

| 术语 | 白话 | 钉死的数 / 要点 |
|------|------|-----------------|
| **Timeslot / Slot / 时隙** | 红绿灯的一段绿灯 | **30 ms**；编号 **1 或 2** |
| **TDMA frame** | 一对绿灯的包装名 | **60 ms** = TS1 + TS2 |
| **Burst / 突发** | 这一段绿灯里真正发出去的那一包比特 | 业务突发内容约 **27.5 ms / 264 bit** |
| **Guard time** | 入站时隙之间的「缝」 | 约 **2.5 ms**；PA / 传播 |
| **CACH** | 出站夹缝里的小广播 | **24 bit**；仅出站；约每 **30 ms** |
| **Inbound / 入站** | MS → BS | 常见形态：Traffic + Guard |
| **Outbound / 出站** | BS → MS | 常见形态：Traffic + CACH |
| **Physical channel** | 频谱上的那条 12.5 kHz 马路 | RF 载波间隔仍 **12.5 kHz** |
| **Logical channel** | 马路上的一条「时间车道」 | Slot1 / Slot2 各是一路逻辑业务 |
| **6.25e（6.25 kHz 等效）** | 会计记账：一路话约占一半时间 | **不是**真的 6.25 kHz 载波宽度 |
| **Voice superframe** | 语音用的「六连拍」 | **6 × 30 ms = 360 ms**（A–F）；本课脸熟 |
| **4FSK / ~9.6 kbps** | 怎么把比特骑上载波 | 本课顺带一句；细节回第 4 课 |

对照口诀：

> **Physical = 地皮宽度；Logical = 时间车道；Frame = 两车道一轮；Burst = 这一车道上的货箱。**

## 4. 现场对照：写频、中继、听感、频谱仪

### 4.1 写频软件里的 Slot

几乎所有 DMR 写频工具（CPS）在信道行都有：

- Frequency / Colour Code / Talkgroup 或 Contact  
- **Slot / Timeslot / TS = 1 或 2**

同系统规划常约定：「调度组走 Slot1，临时个呼走 Slot2」。**写反 = 射频都对也听不见。** 排障顺序建议：

1. 电量、天线、静音、音量  
2. 频率、色码、收发频率是否中继对  
3. **Slot 是否与对端/中继规划一致**  
4. 再查 FID/业务类型（第 14 课）等上层

### 4.2 中继同时两路通话

Tier II 中继典型画面：

- **物理**：一对频率（上行 + 下行），每条仍是 12.5 kHz 地皮。  
- **逻辑**：下行（出站）上 Slot1、Slot2 **都可以有业务**；上行（入站）各 MS **只在自己的时隙发射**。  
- 调度台显示器可能显示「TS1 Busy / TS2 Idle」——这是逻辑信道忙闲，不是「半个频点坏了」。

### 4.3 MS 只占一槽 ≈ 50% 占空

手机按 PTT 时，在自己的逻辑时隙上发突发，另一时隙通常在听或休息。粗略直觉：**发射占空大约一半时间量级**（再扣 Guard 等细节）。好处：省电、同频可并行另一路；坏处：必须**守时**——时钟漂了会踩邻槽。

### 4.4 错槽 = 像拧错台

现象：对方 RSSI 强壮、你 squelch 打开——**完全无语音**。原因常是：你守在 Slot2，对方在 Slot1 说话。数字系统不会像模拟串台那样「隐隐约约听得到」，错槽往往是**干净的静音**。

### 4.5 频谱仪：看脉冲，不要看「半宽载波」

若用频谱仪/示波器看 DMR：

- **分辨率带宽很粗**时：仍像一条 12.5 kHz 量级的能量团。  
- **时间域**看：该逻辑信道呈**间歇脉冲**（按 60 ms 周期里约 30 ms 有能量）。  
- **不要**期望看到「载波宽度变成 6.25 kHz」——那是把 **6.25e 记账**误当成 **FDMA 真劈频**（对比 dPMR/NXDN 一类真 6.25 kHz FDMA 故事）。

### 4.6 直通要对齐

两台 MS 直通：没有基站帮你维持全局节拍时，更要约定同一 Slot，并依赖协议里的同步手段。现场培训一句话：**直通也选对 Slot；不要以为「无中继就无所谓时隙」。**


### 4.7 排障口诀卡（可贴工位）

把本课压成六行，明早还能用：

```text
听不到声？按这个顺序扫：
  ① 电量 / 音量 / 天线
  ② 频率（含中继上下行）
  ③ Colour Code
  ④ ★ Slot 1 还是 2（本课主角）
  ⑤ 组呼/个呼号码与联系人
  ⑥ 再往上：FID/业务类型（第14课）、弱场与干扰
```

对照「模拟串台」经验：模拟错频可能隐约有声音；**DMR 错槽常常是干净静音**——别用「有没有杂音」判断「有没有同频」。

### 4.8 容量直觉：为什么规划爱说「一个频点两路」

售前材料常写「频谱效率翻倍」。用本课语言翻译：

- 地皮还是 **12.5 kHz 一条**；  
- 时间上切成两车道，**在同步良好、两槽都有业务时**，同一对频率可并行两路语音/数据；  
- 若全网业务都挤在 Slot1，Slot2 空转——**纸面两路 ≠ 实际用满两路**。规划要约定「哪些组走哪槽」，写频模板要锁死默认 Slot。

这对弱基础同事很重要：容量故事来自**时分**，不是来自「把滤波器拧窄一半」。

## 5. 完整例子：Tier II 中继上 Slot1 组呼 + Slot2 个呼

假设：

- 下行频率 `460.125 MHz`，上行 `450.125 MHz`（数字仅示意）  
- Colour Code = 1  
- **Slot1**：车队组呼（TG 101）正在开会  
- **Slot2**：调度与司机个呼  

跟时钟走两圈（0–120 ms）。时间零点取「某个出站 TDMA frame 的起点」——教学用，不是仪器触发绝对零。

```text
时间轴（出站 / 下行，BS→MS）示意：

0 ms          30 ms         60 ms         90 ms        120 ms
|-------------|-------------|-------------|-------------|
| TS1 组呼突发 | TS2 个呼突发 | TS1 组呼突发 | TS2 个呼突发 |
| ~27.5ms 264b| ~27.5ms 264b| …           | …           |
| +~2.5ms CACH| +~2.5ms CACH|             |             |

入站（上行）常见相对出站偏约 30 ms 编号/中心对齐方案：
  MS_A（组呼成员）只在「自己的 TS1 入站窗」发射；
  MS_B（个呼司机）只在「自己的 TS2 入站窗」发射；
  彼此不在同一 30 ms 绿灯里抢话筒。
```

逐步解说：

| 时刻（教学） | 出站发生什么 | 入站谁在说话 | 用户听感 |
|--------------|--------------|--------------|----------|
| 0–30 ms | BS 发 TS1 组呼突发 + CACH 缝 | 组呼侧 MS 若在讲，占 TS1 入站窗 | 组呼听众在收 TS1 |
| 30–60 ms | BS 发 TS2 个呼突发 + CACH 缝 | 个呼司机若在讲，占 TS2 入站窗 | 个呼双方在收 TS2 |
| 60–90 ms | 下一帧 TS1… | 同上交替 | 组呼连续听感靠声码器平滑 |
| 90–120 ms | 下一帧 TS2… | 同上交替 | 两路并行，互不「模拟串台」 |

要点回顾：

1. **物理信道还是那一对 12.5 kHz 频率**；  
2. **两路逻辑业务靠时隙分离**；  
3. **CACH 只在出站缝里**，帮系统报告忙闲等（细节第 18 课）；  
4. 若你把写频 Slot 写成 2，却加入的是只在 Slot1 上的组呼——你会对着「正确的频率」听到**正确的静音**。

可选一句直通：两台离开中继改 Talkaround 时，仍要选同一 Slot，并明白此时没有 BS 的 CACH 帮你「报站」，同步压力更大。

### 5.1 把例子讲给新人听（30 秒版）

你可以这样说：

> 「中继下行一直在按 30 ms 换车道：先播组呼那一包，再播个呼那一包，一分钟里两路都在说话，但谁也不是模拟意义上的『同时占满整段载波』。手机上行更乖——按 PTT 时只在自己的绿灯窗口冲刺，另一半时间把路让给别人。」

若新人追问「那我听见的话为什么不断？」→ 指回账本：**216 bit payload ≈ 60 ms 压缩语音**，播放侧再还原成连续听感。

### 5.2 错误配置剧本（请对照自检）

| 剧本 | 配置真相 | 用户感受 | 你怎么一句话定性 |
|------|----------|----------|------------------|
| A | 频率/色码对，Slot 写成 2，组呼只在 Slot1 | 完全无声；对端显示忙 | **错槽** |
| B | Slot 对，色码错 | 无声或无法接入 | 色码墙，不是时隙课主角 |
| C | 两槽都通，但规划未约定，全员默认 Slot1 | Slot1 拥挤、Slot2 空 | **逻辑容量没用上** |
| D | 直通两台 Slot 不一致 | 面对面无声 | 直通也要同槽 |
| E | 中继只开启了 TS1 转发 | Slot2 用户以为「台子坏了」 | 查中继时隙使能，别先换天线 |

剧本 A/D 是本课要练到「肌肉反应」的；B/C/E 用来防止「只会喊时隙」。

## 6. 数字账本（请钉死）

来自资料库速查卡与 `帧结构与字段定义.md` §2；实现冲突以 **TS 102 361-1 V2.7.1** PDF 为准。

| 项 | 数值 | 记法 |
|----|------|------|
| Timeslot | **30 ms** | 编号 1 或 2 |
| TDMA frame | **60 ms** | = 两个连续时隙 |
| Traffic 内容时长 | **27.5 ms** | 承载 **264 bit** |
| Guard / CACH 间隔 | **约 2.5 ms** | 入站 Guard；出站 CACH |
| Traffic 总比特 | **264** | = **108 + 48 + 108**（第 16 课拆） |
| Payload 合计 | **216 bit** | 约可承载 **60 ms** 压缩语音 |
| CACH | **24 bit** | 仅出站；约每 **30 ms** |
| Voice superframe | **360 ms** | **6** bursts A–F（第 17 课） |
| RF 载波间隔 | **12.5 kHz** | 物理地皮 |
| 6.25e | 记账名 | 不是真劈频 |
| 调制 / 速率 | 4FSK · 约 **9.6 kbps** | 顺带一句 |
| 入/出站编号 | 常见 **30 ms** 偏移 | 便于 CACH 同信道号 |

墙上 10 秒版：

> **30 → 60 → 27.5+2.5 → 264 →（6×30=360）。**

### 6.1 和速率的直觉对一下（不代公式考试）

总比特率大约 **9.6 kbps**（4FSK 故事，细节回第 4 课）。粗算帮助建立信任，不算认证：

- 27.5 ms 里装 264 bit → 264 / 0.0275 ≈ **9600 bit/s**，和「约 9.6 kbps」同量级。  
- 若误用整段 30 ms 去除 264，会得到偏小的速率，这就是**忽略 2.5 ms 缝**时的典型算术坑（见误区 3）。

记住：**规范以毫秒窗 + 比特结构为准**；口算只用来防呆，不拿来改实现。

### 6.2 「一帧两槽」和「一超帧六突发」谁先记？

学习顺序建议：

1. 先背 **30 / 60 / 27.5 / 2.5 / 264**（本课）；  
2. 再认 **108+48+108**（第 16 课）；  
3. 再认 **A–F = 360 ms**（第 17 课）；  
4. 最后才拆 CACH 字段（第 18 课）。

不要第一天就把 Part1 第 4–6 章一次性灌完——会把 frame 和 superframe 搅成一锅粥。

## 7. 常见误区（至少五条，对照纠正）

### 误区 1：把 Slot 当成「第二个频点」

- **错**：以为 Slot2 = 另一个 12.5 kHz 频率。  
- **对**：Slot 是**时间车道**；频率规划仍写那个中心频点（中继再加一对上下行）。

### 误区 2：以为 6.25e = 真的 6.25 kHz 信道

- **错**：写材料时写「DMR 信道间隔 6.25 kHz」。  
- **对**：RF 仍是 **12.5 kHz**；6.25e 表示「频谱效率上相当于每路约半个 12.5」。真 6.25 kHz FDMA 是另一类技术故事。

### 误区 3：忽略 2.5 ms，以为整个 30 ms 都在塞 264 bit

- **错**：用 30 ms × 速率硬算，和 264 bit 对不上就怀疑规范。  
- **对**：内容窗约 **27.5 ms**；另约 **2.5 ms** 给 Guard 或 CACH。账要分开算。

### 误区 4：以为用户听得到「30 ms 一卡一卡」的断续

- **错**：「既然时隙只有 30 ms，听感一定像机关枪。」  
- **对**：一突发 payload 可承载约 **60 ms** 压缩语音，再加上播放侧缓冲/平滑，正常听感是连续话音。断续更常是弱信号、错槽、丢同步、干扰——不是「TDMA 设计成卡顿」。

### 误区 5：混淆 TDMA frame（60 ms）与 Voice superframe（360 ms）

- **错**：开会时把「frame」「superframe」混着说，导致对 SYNC 周期理解错乱。  
- **对**：**TDMA frame = 两时隙 = 60 ms**；**Voice superframe = 六突发 A–F = 360 ms**。本课钉前者，后者脸熟即可。

### 误区 6：以为中继「一个时隙坏了，另一个时隙也一定废」

- **错**：TS1 功放故障或配置错误时，断定整站全挂。  
- **对**：两逻辑信道相对独立。可能出现「TS1 全盲、TS2 仍通」——仍要查配置、双工器、时隙使能，而不是只会换整机天线。

### 误区 7（加分）：以为直通模式可以不选 Slot

- **错**：「没有中继就没有时隙。」  
- **对**：直通 TDMA 仍在时间上分车道；Slot 选错一样不通。


### 误区 8：用「模拟信道忙检测」的直觉硬套双时隙

- **错**：以为载波能量在，就等于「整条信道被一个人占满，别人绝对不能说话」。  
- **对**：出站可能两槽都有能量；入站要看**哪一个时隙**忙。CACH / 接入规则会参与礼貌接入（后课）。现场说「信道忙」时，先问清是 **TS1 忙、TS2 忙，还是两个都忙**。

### 误区 9：把「写频默认 Slot1」当成物理定律

- **错**：所有模板出厂都是 Slot1，就永远不改、也不做规划。  
- **对**：默认值只是出厂省事；系统规划可以、也应该把业务拆到两槽。**默认 ≠ 唯一正确**。

## 8. 自测（5–6 题，先闭卷再看简答）

**题 1.** 一个 Timeslot 多长？一个 TDMA frame 多长？由几个时隙组成？  

<details><summary>简答</summary>

Timeslot = **30 ms**；TDMA frame = **60 ms** = **两个**连续时隙（TS1+TS2）。

</details>

**题 2.** 业务突发大约多少毫秒、多少 bit？剩下约 2.5 ms 在入站 / 出站各常做什么？  

<details><summary>简答</summary>

约 **27.5 ms** 承载 **264 bit**。入站约 **2.5 ms Guard**；出站约 **2.5 ms CACH**（CACH 为 **24 bit**，仅出站）。

</details>

**题 3.** 为什么说「一突发 30 ms 窗口里能装约 60 ms 话」？和哪个 payload 数字有关？  

<details><summary>简答</summary>

两侧 payload 合计 **216 bit**，可承载约 **60 ms** 压缩语音；所以听感连续，不是 30 ms 卡一下。细节结构 **108+48+108** 见第 16 课。

</details>

**题 4.** 同事说「我们信道是 6.25 kHz 的」。你怎么用一句话纠正，并指出本课主线是什么？  

<details><summary>简答</summary>

纠正：RF 载波仍是 **12.5 kHz**；**6.25e** 是双时隙带来的效率记账，不是真劈频。本课主线是**时隙/帧时序**，不是频率加餐复述。

</details>

**题 5.** 写频同频同色码同组呼，仍完全无声。优先补查哪一项？频谱仪上更可能看到「半宽载波」还是「时间上的脉冲」？  

<details><summary>简答</summary>

优先查 **Slot/Timeslot 是否写反**。频谱/时间域更应理解成**脉冲占空**，而不是载波宽度变成一半。

</details>

**题 6.** Voice superframe 多长、几个 burst？它和 TDMA frame 有何不同？（脸熟即可）  

<details><summary>简答</summary>

Voice superframe = **6** bursts（A–F）= **360 ms**。TDMA frame 是 **60 ms** 的两时隙包装；超帧是语音层的六连拍，第 17 课深挖。

</details>


**题 7.** 口算：为什么「264 bit ÷ 30 ms」会让你误以为速率对不上？正确窗长应取多少？  

<details><summary>简答</summary>

因为约 **2.5 ms** 不是业务比特窗；内容窗约 **27.5 ms**。264 / 0.0275 ≈ 9600 bit/s，才与约 9.6 kbps 同量级。

</details>

**题 8.** 规划上「一个频点两路」，但网管看 Slot2 长期 Idle。这是射频坏了吗？优先查什么？  

<details><summary>简答</summary>

不一定是射频坏。优先查**写频模板是否几乎全员锁在 Slot1**、中继是否禁用 TS2、业务规划有没有把组拆到两槽。这是**逻辑容量没用上**，回到第 4.8 / 剧本 C。

</details>
