## 0. 开课前：加餐四句话复习（半页，带新例子）

若你已读过 `学习推送/加餐_频率带宽与调制解调.md`，下面四句应能脱口而出。本课**不展开**频率/调制长文，只换成「今天要选 Tier、看标书、对频表」的新例子钉一遍：

| # | 一句话 | 本课用的新例子 |
|---|--------|----------------|
| 1 | **频率** = 信号抖得有多快 | 标书写「DMR Tier II」时，你仍要先问：**用执照上的哪一对频点？** 标准不会替你生成频率表；对不上表，再高级的 Tier 也通不了 |
| 2 | **带宽** = 频谱尺子上占多宽的一条带子 | 三层产品都围绕 **12.5 kHz** 信道规划来设计（Tier II/III 主路径还用 2 时隙换约 **6.25 kHz 等效**）。选 Tier 不是换一套「更宽的车道」，而是换**业务组织方式** |
| 3 | **调制** = 把信息装进适合发射的高频波 | 标书里「符合 ETSI DMR」通常暗示空口主路径按 **4FSK** 装比特。若某方案实际是另一套私有调制，却仍自称「DMR 风格」，验收时不要只看 Logo |
| 4 | **解调** = 从收到的高频波把信息卸下来 | 对频表时：同频 + 同色码 + 同时隙 + **同一 Tier 产品形态**，对方才能按同一套规则卸下突发。跨 Tier、或一边是开放集群一边是厂商私有集群，解调「听得见载波」也不等于「能进同一套呼叫过程」 |

再补一句和本课主线钉死的对照：

- **频率 / 12.5 kHz / 4FSK** 回答：「空口物理门票还在不在？」  
- **Tier I / II / III** 回答：「这是哪一类产品形态、该不该假定互通？」  
- **开放 ETSI 集群 vs 厂商私有集群** 回答：「标书写了 DMR，买到的是不是你以为的那一种？」

若这四句仍糊：先打开加餐文，再回本课。本课主线是：**DMR 正式是什么、三层各自解决谁的问题、现场怎么选与怎么防踩坑**。

## 1. 为什么本课重要（动机）

第 8 课已经讲清：数字化要靠**公开标准**才谈得上多厂商互通。走进阶段 B，你会立刻撞到下一层问题：

- 「我们要上 DMR。」——但客户、标书、销售口中的 DMR，有时指免执照小功率机，有时指执照常规中继，有时指带控制器的集群。  
- 「符合 TS 102 361。」——规范是一套**书架**（TR + Part 1–4），不是一张贴纸。  
- 「三层 Tier 选哪个？」——选错层，后面空口课、业务课、集群课都会学歪。  
- 「都是 DMR，能不能和友邻单位通？」——规范有一句硬话：**三层产品独立工作，跨层不保证互通**。  
- 「标书写了 DMR 集群，厂家报的是 Capacity Plus / XPT / Connect Plus……」——名字里有数字对讲，**不等于**开放 ETSI Tier III。

若只背「DMR = 数字对讲」五个字，后面会卡在同一处：

> **DMR 是 ETSI 公开标准族下的一类产品；它按 Tier 分成三种独立产品形态。说「上 DMR」而不说清 Tier 与是否开放集群，等于只说了族谱、没说户口本。**

本课目标是让你能自己讲清八件事（仍不推公式）：

1. DMR 的正式定义与设计目标（12.5 kHz、2 时隙、6.25 kHz 等效、4FSK、约 30 ms 突发）；  
2. 它「是什么 / 不是什么」（不是所有数字对讲、不是 TETRA/P25、不是自动跨厂万能钥匙）；  
3. **Tier I**：免执照 / 数字 PMR446 类，直通、一体天线、低功率；可有 FDMA 变体；  
4. **Tier II**：执照**常规**，直通或中继，2 时隙 TDMA，专业市场主力；  
5. **Tier III**：执照**集群**，控制器自动派信道，控制信道 vs 业务信道（概念层）；  
6. 三层**互不跨层互通**；II/III 可含同播与非同播；协会重点在 II/III；  
7. 开放 ETSI Tier III ≠ 厂商私有集群（现场最高频混用）；  
8. SFID/MFID 只作一句提醒（细节已在第 8 课，互操作专课在第 14 课）。

第 10 课会专攻「12.5 kHz 与 6.25 kHz 等效」的频谱账；本课到「是什么 + 三层地图」为止。

## 2. 总图 / 故事：一张地图看清 DMR

先把整课装进一张故事图。

```text
【DMR 是什么】
  Digital Mobile Radio
  = ETSI 公开标准系列（TS 102 361 Parts + TR 102 398 设计总览）
  目标：在现有陆地移动执照/规划习惯上，做可负担的数字语音与数据

【物理门票（三层都要记住的骨架）】
  · 信道间隔习惯：12.5 kHz
  · Tier II/III 主路径：2-slot TDMA → 约 6.25 kHz 等效效率
  · 调制：4FSK
  · 典型突发时长：约 30 ms
  （细节：第 10、15 课再钉数字与帧）

【三层产品形态（独立！跨层不保证互通）】
  Tier I  ── 免执照 / 消费·轻商用 ── 直通为主，一体天线，低功率
              （产品定义里不含中继基础设施；可有连续发射 FDMA 变体）
  Tier II ── 执照常规 Conventional ── 直通或中继(BS)，2 时隙专业主力
  Tier III ── 执照集群 Trunking ──── 控制器自动分配信道
              （控制信道调度；业务到业务信道；CSBK Grant 等概念）

【产业焦点】
  DMR Association 主要推动 Tier II & III
  （Tier I 存在，但不是专业专网主战场）

【现场最怕的岔路】
  标书「DMR」 ──┬── 真·ETSI Tier II 常规
                ├── 真·ETSI Tier III 开放集群
                ├── 厂商私有集群（仍可能基于 DMR 空口思路，但过程私有）
                └── 别的数字制式被口头叫成「数字对讲」
```

三句话记牢：

| 层 | 回答的问题 | 典型落点 |
|----|------------|----------|
| **定义层** | DMR 四个字母在标准书架上指什么？ | ETSI TS 102 361 + TR 102 398 |
| **产品层** | 这批货是哪一类形态？ | Tier I / II / III |
| **验收层** | 这场项目实际通不通、通的是什么？ | 同层 + 同配置 + 标准业务（SFID）还是私有扩展 |

第 8 课解决「为什么要有公开标准」；本课解决「标准书架上的 DMR 长什么样、三本户口本怎么分」。

| **ETSI** | 欧洲电信标准化协会；DMR 规范发布方 | 招标书「ETSI」字样 |
| **TS 102 361** | DMR 技术规范系列（分 Part 1–4） | 空口 / 语音 / 数据 / 集群分册 |
| **TR 102 398** | 系统设计总览类技术报告（导读，不是完整条款书） | `00-入门/TR102398_*.pdf`；V1.5.1 |
| **Part 1** | 空中接口（帧、突发、同步、接入等） | V2.7.1；射频/基带必读 |
| **Part 2** | 语音与通用业务 | V2.5.1；个呼组呼过程 |
| **Part 3** | 数据协议 | V1.3.1；短数据 / PDP |
| **Part 4** | 集群协议（Tier III） | V1.12.1；控制信道与 Grant |

| **Tier II** | 执照**常规**；直通或中继；2 时隙 TDMA | 工厂、物业、大多数专业专网 |
| **Tier III** | 执照**集群**；控制器自动派信道 | 大型园区、多组高并发调度 |
| **常规 Conventional** | 信道相对固定分配；用户选信道/组；无「自动派业务信道」的集群控制器 | 「常规中继」「写死频点+时隙」 |
| **集群 Trunking** | 控制器动态分配业务信道 | 「控制信道」「猎站」「登记」 |
| **控制信道 / 业务信道** | 集群里：信令调度 vs 真正通话的信道 | Tier III 总图核心 |
| **BS（基站/中继）** | 基础设施侧设备；常规里常作中继转发 | Tier II 中继双时隙 |
| **MS（移动台）** | 手持/车载终端 | 「写频」「Radio ID」 |

| **6.25 kHz 等效** | 用 2 时隙在 12.5 kHz 上逼近「每路半条信道」的效率说法 | 频谱效率宣传、窄带政策对照 |
| **4FSK** | DMR 约定的主要数字调制方式 | 「数字机」「空口听不清」时的物理层关键词 |
| **约 30 ms 突发** | 典型 TDMA burst 时长量级 | 以后读帧结构课的时间尺子 |
| **同播 Simulcast** | 多站点同频同时发、扩大连续覆盖的一种工程形态 | Tier II/III 都可能有；本课只记「存在」 |
| **开放标准集群** | 按 ETSI Part 4 实现的 Tier III | 「标准集群」「ETSI Trunking」 |
| **厂商私有集群** | 厂家自有呼叫/分配过程（如 Capacity Plus、XPT、Connect Plus 等常见名） | 标书最大坑之一 |
| **SFID / MFID** | 标准特性集 / 厂商特性集（第 8 课已讲） | 本课只提醒：通不通还要看特性集边界 |
| **IOP** | 互操作测试/认证类活动 | 「跨厂联调报告」 |

## 4. 现场对照：选 Tier、看标书、对频表

### 4.1 三十秒决策树（先选层，再谈细节）

```text
需要免执照、小范围、尽量省事？
  └─ 倾向 Tier I（直通、一体天线、低功率；别指望专业中继基础设施）

需要执照专网、固定信道/组、中继覆盖，但并发组数不算极端？
  └─ 倾向 Tier II（常规：直通或中继；专业主力）

需要自动分配信道、多组高并发、登记/漫游/统一控制？
  └─ 倾向 Tier III（开放 ETSI 集群）——并额外确认：不是厂商私有集群套壳
```

### 4.2 招标 / 选型对照表

| 你会看到的词 | 建议你追问 |
|--------------|------------|
| 「支持 DMR」 | **哪一 Tier？** 常规还是集群？声称符合哪几册 TS（Part 1–4）？ |
| 「数字集群」 | 是 **ETSI Tier III（Part 4）**，还是 Capacity Plus / XPT / Connect Plus 等**私有**方案？跨厂要不要通？ |
| 「双时隙 / 6.25 等效」 | 是否明确 **12.5 kHz 载波上 2-slot TDMA**？直通与中继场景分别怎么用两个时隙？ |
| 「可与某某品牌互通」 | 互通的是**同层标准业务**还是私有功能？有无 IOP / 联调报告？ |
| 「模拟兼容 / 双模」 | 迁移期很有用，但**不等于**已经选定 Tier；双模机仍要写清数字侧是 II 还是 III |
| 「同播网」 | Tier II 或 III 都可能做同播；同播是**覆盖工程形态**，不是第四个 Tier |

### 4.3 对频表 / 开通检查清单（同层前提下）

在已经确认「双方都是同一 Tier 产品形态」之后，才轮到这些：

| 检查项 | 为什么 |
|--------|--------|
| 频率（上下行） | 物理门票 |
| 色码 Colour Code | 同频系统隔离（细节后续课） |
| 时隙 1 / 2 | TDMA 两路选哪条 |
| 本机 ID / 组号 / 呼叫类型 | 第 7 课的信封 |
| 直通还是中继（Tier II） | 模式错了等于两个世界 |
| 控制信道参数（Tier III） | 找不到控制信道就登不上网 |
| 要通的功能是否 SFID 标准业务 | 私有菜单跨厂默认不通 |

### 4.5 SFID / MFID 一句提醒（不重讲第 8 课）

标准业务走 **SFID**；厂商扩展走 **MFID**。  
同层、同频、同色码、同时隙，若一边在用私有扩展当「必通功能」，跨厂仍可能失败。细节回看第 8 课；专课在第 14 课。

## 5. DMR 是什么（展开版，仍白话）

### 5.1 正式说法

**DMR（Digital Mobile Radio）** 是由 **ETSI** 发布的专业数字移动无线电标准。规范主体是技术规范系列 **TS 102 361**（Part 1–4），并用技术报告 **TR 102 398** 做系统设计总览（帮助理解「为什么这样设计」；与 TS 冲突时以 TS 为准）。

它面向**现有陆地移动业务频段**的数字化，而不是另开一套与执照规划无关的「新宇宙」。

### 5.2 设计目标（现场可复述的五句）

1. **频谱兼容**：落在常见 **12.5 kHz** 信道间隔习惯上，尽量少推倒重来执照与邻道规划。  
2. **效率**：Tier II/III 主路径用 **2 时隙 TDMA**，在同一 12.5 kHz 载波上支撑两路，达到约 **6.25 kHz 等效**效率说法。  
3. **可实现、可负担**：相对复杂集群制式，强调低复杂度、适合专业对讲升级。  
4. **业务**：语音、短数据、分组数据等；集群能力在 Tier III / Part 4。  
5. **开放**：公开空口与过程，使多厂商实现与基本业务互通成为可能（仍须同层、同配置、标准特性集）。

### 5.3 技术骨架（本课记住量级即可）

| 项目 | 记住这个数/词 | 以后哪课加深 |
|------|----------------|--------------|
| 信道间隔 | **12.5 kHz** | 第 10 课 |
| 多址（II/III 主路径） | **2-slot TDMA** | 第 5、15 课 |
| 效率说法 | **6.25 kHz 等效** | 第 10 课 |
| 调制 | **4FSK** | 第 4 课已有直觉；实现细节后续 |
| 典型突发 | 约 **30 ms** | 第 15–16 课 |
| 文档 | TR 102 398；Part1–4 上表版本 | 第 11 课 |

### 5.4 DMR「不是」什么（边界清单）

| 不是 | 为什么要强调 |
|------|----------------|
| 不是「所有数字对讲的统称」 | TETRA、P25、NXDN、dPMR、PDT 等是不同制式 |
| 不是「贴 Logo 就跨厂必通」 | 还要 Tier、配置、SFID/私有、加密等 |
| 不是「只有一种产品」 | 至少三层 Tier，形态差很大 |
| 不是「有了 DMR 就不用管频率表」 | 标准不管你单位填哪个频点 |
| 不是「厂商私有集群的别名」 | 私有方案可能借用 DMR 空口思路，但呼叫过程可以完全私有 |

### 5.5 和阶段 A 的衔接（一句话）

阶段 A 给你的是：**频率/带宽/调制、TDMA、中继、个呼组呼、为什么要公开标准**。  
阶段 B 从本课开始，把这些零件装进名为 **DMR** 的标准产品地图里。

## 6. Tier I：免执照直通世界

### 6.1 它解决谁的问题

- 小店、仓库一角、临时活动、轻量协作；  
- 希望**少谈执照、少谈基站机房**；  
- 接受覆盖有限、功率受限、功能相对简单。

### 6.2 产品定义里要钉死的点

| 要点 | 白话 |
|------|------|
| **Licence-exempt / 数字 PMR446 类** | 走免执照或等效监管类别（以你地法规为准） |
| **一体天线（integral antenna）** | 通常不可外接高增益天线「硬抬覆盖」 |
| **直通为主** | 终端互传；**Tier I 产品定义不含中继基础设施** |
| **低功率** | 公开产业材料常引用约 **0.5 W** 量级上限（具体以当地法规与设备认证为准） |
| **FDMA 变体** | 按 TR 102 398 / 手册：Tier I **可采用连续发射的 FDMA 变体**（与 II/III 主路径的 2 时隙 TDMA 不是同一套「日常专业网」图像） |

### 6.3 现场口诀

> **Tier I = 数字版「小功率直通对讲」户口本；别拿它的指标去验收工厂中继网。**

### 6.4 和协会焦点的关系

DMR Association 产业推动重点在 **Tier II & III**。  
Tier I 存在且有标准位置，但你做专业专网售前/工程时，日常词汇里的「上 DMR」十有八九指 II 或 III。

## 7. Tier II：执照常规，专业主力

### 7.1 它解决谁的问题

- 已有（或将申请）陆地移动**执照**；  
- 需要比 Tier I 更大的覆盖与更专业的终端/中继生态；  
- 信道与通话组相对可规划：用户选信道/组，**不需要**「控制器自动派业务信道」；  
- 典型：工厂、物业、园区常规网、交通现场常规中继等。

### 7.2 产品定义里要钉死的点

| 要点 | 白话 |
|------|------|
| **Licensed conventional** | 执照常规系统 |
| **直通或中继（BS）** | 可 DMO 式直通，也可经基站/中继转发 |
| **2-slot TDMA @ 12.5 kHz** | 同一载波两个时隙；中继协调下常见「一路通话占一时隙」 |
| **专业市场主力** | 多数「标准 DMR 专网」从这里起步 |
| **可含同播 / 非同播** | 覆盖工程可选；不是另开 Tier |
