## 8. 术语表（本篇约 28 词）+ 易错观念

| 术语 | 一句话 | 易错 |
|------|--------|------|
| **CHAN** | 12 bit 逻辑房号 | 当成 MHz |
| **门牌表** | 房号→频率的写频计划 | 以为 Grant 自带 MHz（4095 除外） |
| **固定计划** | 公式算频率 | SEP 写错会系统性跑偏 |
| **灵活计划** | 逐行 Tx/Rx/CC | 缺行 → Grant 后掉线 |
| **CHAN=0** | 常=无效；P_CLEAR 例外回老 TSCC | 一律当无效 |
| **CHAN=4095** | 看绝对频率续块 | 当坏值丢掉 |
| **SEP** | 固定计划信道间隔 | 与「DMR 12.5 kHz 车道」口头混淆 |
| **CC / Colour Code** | 油漆色身份 | 有能量就当本系统 |
| **Hunt** | 找并确认 TSCC | 和登记失败混称 |
| **Resume** | 回上次确认 TSCC | — |
| **Commanded** | 单信道直调（记忆/MOVE/CLEAR） | 开机空转旧号当故障 |
| **Short Hunt** | 扫短列表 | — |
| **Comprehensive** | 扫全范围兜底 | 忽略 Comp_Flag 抑制 |
| **验证** | SYScode 等：是不是我家 | 听到同步就当验证过 |
| **确认** | 质量够不够用 | 与验证顺序颠倒 |
| **确认前不发射** | Annex D / 6.3 铁律 | 猎站阶段乱发 |
| **TSCC** | 控制信道前台 | — |
| **Payload** | 业务信道客房 | — |
| **贴纸A/B/C** | 猎站/登记/Grant无声 | 贴错开错单 |
| **脱敏检查表** | 站点\|CHAN\|计划\|CC\|备注 | 填真实批复 MHz 入库 |
| **缺行演练** | 灵活缺 CHAN N 的分诊训练 | 当成偶发硬件故障 |
| **C_MOVE / P_CLEAR** | 点名去哪条控 | 忽略 Cont 字段 |
| **Ann_WD_TSCC** | 广播加减短列表 | 短列表「自己变了」不知查广播 |
| **Vote_Now / 邻站** | 优选/邻站提示 | 厂商策略当标准唯一算法 |
| **手册01三问** | 登记分诊 | 无 TSCC 时误用 |
| **手册02四问** | Grant无声分诊 | 不回填 CHAN 表 |
| **T_Nosig 直觉** | 长时间解不出控 → 再猎 | 数值以本网/厂商为准，本篇不写死 |

**易错观念对照**

| 错念 | 纠正 |
|------|------|
| 搜网 = 注册失败 | 先问在不在 TSCC |
| 有能量 = 自家台 | 先验证 SYScode/CC |
| 4095 = 坏值 | 绝对续块暗号 |
| Grant 了没声 = 功放坏 | 先门牌/CC/时隙 |
| 来回蹦 = 天线差 | 先短列表/邻站策略 |
| Stun 后还搜网 = 没禁上 | 手册03：常是设计 |

**题 12.（加分）** Stun 后终端仍猎站，应引用哪本手册？本篇是否应开「猎站失败」单？

### 参考答案

1. **不是第 41 课。** 手册模式第 4 篇；服务运维 **Week‑3**：CHAN/Hunt 脱敏检查表。  
2. ①在猎站还是已在TSCC → ②Hunt阶段指纹 → ③CHAN计划与三段取值 → ④边界贴纸。证据例：SYScode、Aloha（或稳定本网控信道解码）。  
3. A猎站失败；B登记失败（手册01）；C Grant无声（手册02）。无 Reason/无 RAND → **贴纸 A**（先别开01）。  
4. 0：常无效；P_CLEAR 的 0 → 回上次确认 TSCC。300：逻辑房号查表。4095：看绝对续块。  
5. 缺行：常**仅**该 CHAN 受害。SEP 错：大号**系统性**跑偏。  
6. Resume 回老控；Commanded 受令/记忆单号；Short 扫短表；Comp 扫全范围。开机空转旧控 ≈ **Commanded 记忆**。  
7. 未确认身份与质量就发射会干扰/违规接入；铁律：**确认前不得发射**。  
8. 手册02：真Grant？CHAN/时隙/门牌？Payload身份？最后射频。根因回填本表 **CHAN/计划类型/备注(缺行)**。  
9. `站点|CHAN|计划类型|CC|备注`。真实批复频率属受控信息，学习推送/公开仓脱敏。  
10. **先**短列表/邻站/Vote_Now 策略对齐，再谈覆盖空洞。  
11. 规范接法：回到登记前猎站阶段。工单两段写：登记剧本 + 随后 Hunt 指纹。  
12. 手册03；一般**不应**当猎站失败单，先核业务是否已停。

## 11.7 常见问法速查（FAQ 式）

**Q1：搜网是不是就是注册失败？**  
A：不一定。先问在不在 TSCC；不在 → 贴纸 A。

**Q2：灵活缺行会不会没有 Grant？**  
A：常常**有** Grant 票样，但进不去 → 掉回 TSCC。按手册02+本表缺行。

**Q3：4095 要不要当噪声滤掉？**  
A：**不要。** 它表示绝对频率续块。

**Q4：检查表能不能写真实频率方便夜班？**  
A：**不能写进学习推送/公开仓。** 真实批复只留在受控内部系统。

**Q5：本篇要不要会手算 fbase 公式、手拆 C_SYScode？**  
A：值班检查表**不要求**重做第36/37课作业；会认三段取值与四阶段指纹即可。要深挖再回原课。

**Q6：和手册02如何分工？**  
A：手册02管「Grant无声四问」流程；门牌缺行/SEP/CC 根因**回填本篇主表**。
