## 0. 开课前：加餐四句话复习（带新例子）

若你已读过 `学习推送/加餐_频率带宽与调制解调.md`，下面四句应能脱口而出。本课**不照抄加餐**，只换场景再钉一遍：

| # | 一句话 | 本课用的新例子 |
|---|--------|----------------|
| 1 | **频率** = 信号抖得有多快 | 写频里填 `460.125 MHz`：载波大约每秒抖 **4.60125 亿次**——这是尺子上的**位置**，不是音量 |
| 2 | **带宽** = 频谱尺子上占多宽的一条带子 | 你讲话时发射能量会在中心频率左右「铺开」一小段；铺太宽会刮到邻道 |
| 3 | **调制** = 把信息装进适合发射的高频波 | 仓库里按 PTT：声码器先变比特，再让射频载波按约定方式「变花样」飞出去 |
| 4 | **解调** = 从收到的高频波把信息卸下来 | 对方电台先认出「这是哪种抖法」，再还原成比特、再变成喇叭里的声音 |

再补一个和本课直接相关的对照（加餐里提过，这里钉死）：

- **信道间隔**更像高速公路「车道中心线之间隔多远」；  
- **占用带宽**更像「你的车身实际有多宽」。  
- 写频软件里常见的 **12.5K / 25K**，多数时候指的是**间隔**，不是你的发射频率本身。

若这四句仍糊：先打开加餐文读「频谱尺子」和「车道/车身」两段，再回本课。本课主线是：**频点从哪来、波长怎么估、VHF/UHF 怎么选、12.5 kHz 栅格怎么理解、以及「6.25 kHz 等效」到底在说什么**。

## 1. 为什么本课重要（写频里的 MHz 与 12.5K）

打开任意一款常见写频软件，你几乎一定会看到两类数字：

1. **发射 / 接收频率**：例如 `460.125000`，单位是 **MHz**。  
2. **信道间隔 / Channel Spacing**：下拉里常见 `12.5 kHz`、`25 kHz`，有的机型还会看到与窄带相关的选项。

很多人日常操作是：同事给一张频率表 → 照着填 → 通了就算完。出问题才发现：

- 填成了 `460.125`，邻台却是 `460.1375`——差的正好是 **12.5 kHz**；  
- 自己以为「间隔设成 25K 更稳」，结果和全网 12.5K 规划错位；  
- 听到「DMR 是 6.25 kHz 等效」就以为要把频率写成差 6.25 kHz 的两个频点。

本课目标是让你能自己讲清五件事：

> 1. 频率和波长怎么互相换算（现场估天线、估传播直觉）；  
> 2. VHF / UHF 大概在尺子哪一段、对讲常见用哪一块；  
> 3. **12.5 kHz** 是「相邻信道中心差多少」，不是「我的发射频率」；  
> 4. 它和**占用带宽**不是同一个词；  
> 5. DMR 的 **6.25 kHz 等效** = 在一条 12.5 kHz 规划里用 **2 时隙 TDMA** 跑两路，**不是**把频率切成两半。

这些词后面会反复出现在 Part 1、中继规划、集群信道表里——地基打牢，后面少背黑话。

## 2. 总图：从频谱尺子到你的一条发射带子

先把整课装进一张故事图：

```text
  【频谱尺子】低频 ←————————————————————————→ 高频
                    │
                    │ 监管/规划切出「频段」（如 VHF、UHF）
                    ▼
              ┌──────────── 某段 UHF 对讲常用区 ────────────┐
              │  … | ch n-1 |  ch n  | ch n+1 | …           │
              │       ▲         ▲         ▲                 │
              │    中心差    你的信道    中心差               │
              │   12.5 kHz   中心 f    12.5 kHz              │
              └─────────────────────────────────────────────┘
                              │
                              ▼
                    你发射时实际占的「带子」
                    （占用带宽，必须大体落在自己车道里）
```

读图顺序（建议朗读一遍）：

1. **频谱尺子**：所有频率从低到高排开。  
2. **频段**：尺子上很大的一段区间（VHF、UHF…），决定天线长短、穿墙/绕射大致脾气。  
3. **信道栅格**：在执照/规划允许的区间里，按固定间隔（常见 12.5 kHz）画出一条条「车道」。每条车道有一个**中心频率**——就是你写频填的那个 MHz。  
4. **你的发射**：不是无限细的一根针，而是中心附近一条有宽度的带子。带子太宽 → 邻道干扰；中心写错 → 站错车道。

DMR 专业模式要做的事，可以粗暴记成：

> 在**已经按 12.5 kHz 规划好的车道**里，用数字调制 + **时间上切两刀（2 时隙）**，让同一条车道尽量顶两路通话的效率——宣传口径就叫 **6.25 kHz equivalent（等效）**。

「等效」两字很重要：频率尺子上的车道宽度往往仍是 12.5 kHz；省出来的是**频谱利用效率**，不是再画一条差 6.25 kHz 的新物理频点（细节见第 7 节）。

## 3. 白话术语表（本课必会）

| 术语 | 白话 | 现场你怎么碰上 |
|------|------|----------------|
| **频率 f** | 抖多快；尺子上的位置 | 写频：`RX/TX Frequency` |
| **波长 λ** | 一个完整「抖」在空间里占多长 | 估天线、估绕射粗直觉 |
| **频段** | 尺子上很大一截的名字（VHF/UHF…） | 选型：买 V 段机还是 U 段机 |
| **频点 / 中心频率** | 某条信道车道的中心刻度 | 频率表上的 `460.125` |
| **信道间隔** | 相邻车道**中心**差多少 | 软件：`12.5 kHz` / `25 kHz` |
| **占用带宽** | 你发射实际铺多宽 | 合规测试、邻道抑制相关 |
| **12.5 kHz** | 陆地移动里极常见的一种间隔 | 绝大多数现代窄带规划 |
| **6.25 kHz 等效** | 效率口径：12.5 kHz 里两路 | DMR 卖点 / 协会文案 |
| **TDMA 时隙** | 同一频率上按时间轮流 | 写频：Slot 1 / Slot 2 |

口诀：

> **位置看频率，宽度看带宽/间隔，快慢轮流看时隙。**

## 4. 频率与波长：λ ≈ 300 / f(MHz)

### 4.1 公式怎么来的（只记用法）

电磁波在空气里速度大约等于光速：约 \(3\times10^8\) m/s。  
波长（米）≈ 光速 / 频率。把频率用 **MHz** 表示时，工程上常记：

\[
\lambda(\text{米}) \approx \frac{300}{f(\text{MHz})}
\]

你不需要推导；需要会**心算几个现场数字**。

### 4.2 算两笔现场账

| 频点（约） | 算法 | 波长约 | 直觉 |
|------------|------|--------|------|
| **150 MHz**（VHF 对讲常见区附近） | 300÷150 | **≈ 2 m** | 「两米波」量级；半波振子天线大约 1 m 量级（示意） |
| **460 MHz**（UHF 对讲常见区附近） | 300÷460 | **≈ 0.65 m** | 天线可以短一截；穿墙/绕射脾气和 VHF 不同 |

再练两个（自己算一遍）：

- **400 MHz** → 300÷400 = **0.75 m**  
- **160 MHz** → 300÷160 ≈ **1.9 m**

### 4.3 波长告诉你什么（不讲传播公式）

- **天线尺寸**大致和波长同量级相关：频率越高，天线往往可以做得更短（还有匹配、效率等细节，以后再说）。  
- **绕射 / 穿障碍**的脾气会变：低频（波长更长）往往更「绕得过一点」；高频更「直、更吃遮挡」——这是选型时的粗指南，不是绝对定律。  
- **不要**用波长去解释「数字音质好不好」：音质首先是声码器与链路质量的事。

类比：波长像「步幅」——步子大的人（低频）有时更容易绕过路边障碍的直觉；步子密的人（高频）转身灵活、设备好做小，但密林（城市钢筋）里可能更容易被挡住。类比有限，别过度引申。

## 5. 频段：VHF、UHF 与对讲常见区间

### 5.1 先记国际粗坐标（ITU 习惯口径）

| 名称 | 频率范围（记数量级） | 波长量级直觉 |
|------|----------------------|--------------|
| **VHF**（甚高频） | **30–300 MHz** | 约 10 m → 1 m |
| **UHF**（特高频） | **300–3000 MHz** | 约 1 m → 0.1 m |

对讲机行业口头说的「V 段 / U 段」，通常落在上面大区间里的**执照与产品常用子区间**（各国规划不同，下表只建立直觉，不以某国执照表为准）：

| 口头说法 | 常见数量级（示意） | 你工作中 |
|----------|--------------------|----------|
| VHF 对讲 | 如 136–174 MHz 一带产品很常见 | 开阔地、郊区、部分专网 |
| UHF 对讲 | 如 400–470 MHz 一带产品很常见 | 楼宇、城区、室内穿透讨论多 |

具体能用哪一段频率，以**当地无线电管理机构执照 / 单位频率表**为准——本课只教坐标感，不教「随便找个空频点就用」。

### 5.2 传播差异白话（选型直觉）

把「选 V 还是选 U」想成选交通工具，而不是选吉祥数字：

| 场景直觉 | 常更倾向 | 原因（极简） |
|----------|----------|--------------|
| 开阔地、郊野、沿公路 | 常讨论 VHF | 波长更长，绕射/覆盖在部分场景更「省心」 |
| 城区楼宇、室内、钢筋多 | 常讨论 UHF | 天线短、设备紧凑；对障碍的行为与 V 不同，需结合实测 |
| 已有中继/全网都是某段 | **跟全网** | 互通优先于「理论哪个更好」 |

现场金句：

> 频段选择 = 执照允许 + 地形场景 + 全网已有设备；不是「UHF 更新所以更好」。

### 5.3 和 DMR 的关系

DMR 空口标准本身是**中立于「你站在 V 还是 U」**的一套数字规则：同样的 12.5 kHz 规划思维、同样的 2 时隙故事，可以落在不同频段产品上。  
你写频时填的 MHz，是**物理车道位置**；色码、时隙、地址是**这辆车上的通行证与座位号**——别混层。

## 6. 信道间隔 12.5 kHz：从哪来、是什么、不是什么

### 6.1 历史直觉：频谱变贵，车道变窄

陆地移动通信早期，不少规划用 **25 kHz** 作为相邻信道中心间隔。后来用户变多、频谱越来越「贵」，监管与标准推动**窄化**：在同样一段频谱里多排车道。于是 **12.5 kHz** 成为极常见的窄带间隔。

你可以记成：

```text
以前常见：  |----25 kHz----|----25 kHz----|
后来常见：  |--12.5--| --12.5--| --12.5--| --12.5--|
```

同一段尺子，间隔减半 → 可规划的信道数大约能翻倍（理想情况）。代价是：每辆「车」必须更守规矩——占用带宽、邻道抑制等指标要跟上，否则会刮蹭。

### 6.2 精确定义（请背下）

> **信道间隔（channel spacing）** = 相邻两个合法信道**中心频率**之差。

例如规划以 12.5 kHz 为栅格时，若有一条信道中心是 `460.125 MHz`，则相邻信道中心往往是：

- `460.125 + 0.0125 = 460.1375 MHz`  
- 或 `460.125 − 0.0125 = 460.1125 MHz`

注意单位换算：

| 写法 | 等于 |
|------|------|
| 12.5 kHz | 0.0125 MHz |
| 25 kHz | 0.025 MHz |
| 6.25 kHz | 0.00625 MHz |

写频界面有时显示很多位小数，就是为了把 0.0125 这种步进表达清楚。

### 6.3 间隔 ≠ 占用带宽（本课最容易错的点）

| | 信道间隔 | 占用带宽 |
|--|----------|----------|
| 像什么 | 车道中心线间距 / 规划栅格 | 车身宽度 / 你实际铺开的频谱 |
| 谁定 | 监管规划 + 网络设计 | 调制方式、滤波、功率谱形状等 |
| 写频里 | 常直接选 12.5K / 25K | 通常不让你填一个「占用带宽=xx」日常项 |
| 搞反会怎样 | 整网栅格错位、与邻台错开方式乱掉 | 合规不合格、邻道干扰投诉 |

加餐用过「车道 vs 车身」；这里再换一个比喻：

> 间隔是**乐谱上规定小节线隔多远**；占用带宽是**你拉小提琴时音实际抖开多宽**。小节线间距标准化了，不代表你可以把音糊到隔壁小节。

### 6.4 DMR 为什么总提 12.5 kHz

ETSI DMR 的设计语境，就是面向**既有 12.5 kHz 信道规划**做数字化，并追求更高频谱效率（协会常说的 6.25 kHz equivalent）。  
所以你在资料库、产品彩页里反复看到 12.5 kHz——它首先是**规划坐标系**，其次才联想到 TDMA 效率故事。

## 7. 完整例子：写频 460.125 与邻居 460.1375

### 7.1 一张迷你频率表

假设某专网常规信道（数字虚构，仅教学）：

| 信道名 | 中心频率 (MHz) | 间隔规划 | 备注 |
|--------|----------------|----------|------|
| CH1 | 460.1250 | 12.5 kHz | 你的工作信道 |
| CH2 | 460.1375 | 12.5 kHz | 相邻信道 |
| CH3 | 460.1500 | 12.5 kHz | 再隔壁 |

验算：

- 460.1375 − 460.1250 = **0.0125 MHz = 12.5 kHz** ✓  
- 460.1500 − 460.1375 = **12.5 kHz** ✓  

### 7.2 正确通联最小集合（直通示意）

双方要对上至少：

1. **同一中心频率**（例如都是 460.1250）；  
2. **同一套数字身份约定**（色码等——下几课展开）；  
3. **同一时隙**（若使用时隙业务）；  
4. 理解全网按 **12.5 kHz** 栅格规划（避免私自按 25 kHz「跳格子」）。

### 7.3 错间隔会怎样（排障故事）

**故事 A：把邻道当同道**  
新手把 CH2 的 `460.1375` 错看成「和 460.125 差不多」，两台机器各写一个——结果互相听不见（或只听到很弱的泄漏/干扰）。  
本质：站在了**相邻车道**，不是同一车道。

**故事 B：软件间隔选 25K，频率表却是 12.5 栅格**  
有的软件里「信道间隔」会影响旋钮步进、扫描步进或信道列表生成方式。若你按 25 kHz 步进去「下一个信道」，可能直接跳过合法的 12.5 邻道，或生成与执照表不一致的列表。  
本质：**栅格尺子拿错了**。

**故事 C：以为改间隔能提高音质**  
把 12.5 改成 25「听着更宽」——在数字 DMR 里，音质首先不靠这么改；还可能让你与全网规划不一致。  
本质：把**规划参数**当成了**音效旋钮**。

**故事 D：近距离大功率邻道**  
频率都对，但旁边车道有很大功率电台，你的接收机被「糊边」——表现为误码、断续、静噪异常。  
本质：这是**占用带宽 / 邻道干扰 / 阻塞**类物理问题，优先查射频环境，而不是先改 ID。

### 7.4 和「调制 / 解调」怎么接回去

在 CH1 上按 PTT：

1. 信息经处理后变成比特流；  
2. **调制**把比特装到约 460.125 MHz 的载波「抖法」上；  
3. 能量在 460.125 附近铺成一条窄带（占用带宽须守规矩）；  
4. 对方在同一频点上**解调**卸货。  

若对方写在 460.1375：解调器拧在错误刻度上——卸不下来你的货（或只收到干扰残渣）。

## 8. 预告：6.25 kHz 等效 —— 不是把频率切两半

### 8.1 一句正确、一句错误

| 说法 | 对错 |
|------|------|
| 「DMR 可在 12.5 kHz 信道上提供两路语音，频谱效率相当于 6.25 kHz 一路」 | ✓ 效率/等效口径 |
| 「所以要把 12.5 kHz 频率再切成两个差 6.25 kHz 的频点」 | ✗ **错** |
| 「两路是靠两个时隙轮流占用同一载波」 | ✓ TDMA 直觉 |
| 「时隙 1 用 460.125，时隙 2 用 460.13125」 | ✗ **错**（那是又在频率上切） |

### 8.2 图：频率一切 vs 时间两刀

```text
【错误想象：频率切两半】
|-------- 12.5 kHz --------|
|---6.25---|---6.25---|     ← DMR 不是这么干的

【正确直觉：同一 12.5 kHz 载波，时间切两刀】
频率：======== 12.5 kHz 规划车道（同一中心频率）========
时间：  [时隙1][时隙2][时隙1][时隙2][时隙1][时隙2]...
         用户A  用户B  用户A  用户B   ...
```

后面空口课会碰到：**每个时隙约 30 ms** 量级的时间结构（此处只作前瞻，本课不展开突发比特）。你现在只要记住：

> **6.25 kHz equivalent** 是「效率换算口号」；物理规划车道常常仍是 **12.5 kHz**；第二路来自 **TDMA 时隙**，不是第二个差 6.25 kHz 的写频频点。

协会公开材料（本课外链 4）正是用白话讲这个卖点——读外链时对照本节图。

## 9. 现场对照表（写频软件字段）

把软件界面翻译成本课语言：

| 写频 / 现场字段（常见叫法） | 本课落点 | 设错时典型现象 |
|-----------------------------|----------|----------------|
| RX / TX Frequency（MHz） | 信道中心频率；尺子位置 | 完全不通；或通到别人网 |
| Channel Spacing 12.5K / 25K | 栅格 / 步进 / 规划间隔 | 信道列表与执照表对不齐 |
| Band / VHF / UHF（机型） | 频段能力 | 根本写不进某段频率 |
| Color Code | 解调后的系统识别（非频率） | 有信号但不听你的话 |
| Slot / 时隙 1·2 | 时间切片（非频率切片） | 同频同色码仍不通 |
| Power | 力气，不是频率 | 覆盖差或干扰别人 |
| 中继差频 / 偏移 | 上行下行两个中心频率关系 | 能收中继但发不进、或反向 |

排障口诀（建议贴显示器旁）：

1. 先问：**频点（位置）对不对？间隔栅格是否和全网一致？**  
2. 再问：**时隙 / 色码 / 地址（通行证）对不对？**  
3. 最后问：**是不是被邻道/阻塞等射频问题糊了？**

## 10. 常见误区（本课专治）

1. **「12.5 kHz 就是我的发射频率」**  
   错。发射频率是 460.xxx MHz 那种；12.5 kHz 通常是间隔。

2. **「信道间隔 = 占用带宽」**  
   错。一个是车道中心距，一个是车身宽。

3. **「波长算出来是为了调音质」**  
   错。波长服务天线与传播直觉；音质看链路与声码器。

4. **「UHF 一定比 VHF 先进」**  
   错。场景与执照决定；先进不先进不看字母。

5. **「6.25 kHz 等效 = 写两个差 6.25 kHz 的频点」**  
   错。是同一 12.5 kHz 载波上的两时隙效率口径。

6. **「数字对讲不用管邻道，因为有色码」**  
   错。色码不消除物理干扰；邻道过强照样打坏解调。

7. **「把间隔改成 25K 就能减少干扰」**（在全网 12.5 规划下）  
   常常适得其反：你与规划错位，反而引入奇怪的邻道关系。改干扰应查功率、天线、距离、滤波与频谱净化，而不是私改全网栅格。
