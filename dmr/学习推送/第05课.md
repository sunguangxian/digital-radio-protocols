## 0. 开课前：加餐四句话复习（带新例子）

若你已读过 `学习推送/加餐_频率带宽与调制解调.md`，下面四句应能脱口而出。本课**不照抄加餐与第 2–4 课**，换成「中继台上两路呼叫同时占着同一个 12.5 kHz 频点」的场景再钉一遍：

| # | 一句话 | 本课用的新例子 |
|---|--------|----------------|
| 1 | **频率** = 信号抖得有多快 | 写频仍写一个中心频点，例如 `460.125 MHz`。双时隙并不是把频点改成两个，而是**同一频点上轮流说话** |
| 2 | **带宽** = 频谱尺子上占多宽的一条带子 | RF 载波规划仍是 **12.5 kHz** 这一整条带子。所谓「6.25 kHz 等效」是**频谱效率的记账说法**（一路话只占一半时间），**不是**把载波从中间劈成两条 6.25 kHz 的真频带 |
| 3 | **调制** = 把信息装进适合发射的高频波 | 装车方式仍是第 4 课的 **4FSK**。多址问的是：装好的车，**谁先走、走哪条道**——频率道、时间片、还是「暗号码」 |
| 4 | **解调** = 从收到的高频波把信息卸下来 | 接收机先对齐时隙节拍，再在自己的 30 ms 窗口里做 4FSK 判决。时隙对错了，就像拧错电台：解调再努力也不是你要的那一路 |

再补一句和本课主线钉死的对照：

- **模拟常规台**：一个 12.5 kHz 频点上，同一时刻通常只能撑**一路**对讲（别人要等信道空出来）。  
- **DMR 双时隙**：还是这个 12.5 kHz 频点，靠 **TDMA** 切成两个 30 ms 时隙，可以撑**两路彼此独立**的业务（语音或数据）。

若这四句仍糊：先打开加餐文，再回本课。本课主线是：**多址在分什么资源、三种经典分法各占什么、DMR 落在哪一种、6.25 kHz 等效到底什么意思**。

## 1. 为什么本课重要（动机）

现场与文档里你会反复撞到这些说法：

- 「我们是双时隙，Slot 1 / Slot 2。」  
- 「一个频点顶两个信道。」  
- 「6.25 kHz 等效（6.25e）。」  
- 「和 dPMR / NXDN 那种真切 6.25 kHz FDMA 不一样。」  
- 「时隙要对齐，不然直通模式会乱。」

若只背「DMR = TDMA」五个字，后面读写频软件、跟规划同事谈容量、看频谱仪、读 ETSI Part1 的时隙图，都会卡在同一处：

> **多人同时要说话时，系统到底在分「频率」「时间」还是「码」？DMR 的「两路」分的是哪一种？**

本课目标是让你能自己讲清八件事（仍不推公式）：

1. **多址（Multiple Access）** 在解决什么问题；  
2. **FDMA / TDMA / CDMA** 各自「切」的是什么维度；  
3. 为什么模拟对讲看起来像「一个频点一路人」——那是 FDMA 味道；  
4. DMR 为什么选 **2-slot TDMA**，时隙为什么是 **30 ms**，一帧为什么是 **60 ms**；  
5. **物理信道** vs **逻辑信道**（一个 12.5 kHz 载波上长出两路逻辑业务）；  
6. **6.25 kHz 等效**为何不是「载波变窄了一半」；  
7. CDMA 在本课只要求「脸熟」——专业对讲主流故事不靠它；  
8. 常见误区：把 Slot 当成第二个频点、把 6.25e 当成真 6.25 kHz 信道间隔、以为两路可以完全不需要同步。

第 6 课才会专讲双工 / 半双工 / 中继 / 直通；本课到「多址地图 + DMR 落点」为止。

## 2. 总图 / 故事：会议室里三种排座法

先把整课装进一张故事图。想象一间只能共用一套音响的会议室，很多人要讲话：

```text
问题：多人要共用有限的「通信资源」，又尽量别互相搅局
              │
    ┌─────────┼─────────┐
    ▼         ▼         ▼
  FDMA      TDMA      CDMA
 分房间     轮流麦     同场不同语
（分频率） （分时间） （分码字）
    │         │         │
    └────┬────┘         │
         ▼              │
   专业对讲常见组合      │
   （频点规划 + 时隙）   │
         │              │
         ▼              ▼
   ★ DMR 主流落点：     3G 蜂窝等故事
   12.5 kHz 载波上的    （本课只脸熟）
   2-slot TDMA
```

三句话记牢：

| 名字 | 切什么 | 会议室比方 |
|------|--------|------------|
| **FDMA** | 频率 | 每人进不同房间（不同频点/子带），可以同时大声说 |
| **TDMA** | 时间 | 同一房间、同一套麦，严格按秒表轮流说；轮得够快，听感像「同时」 |
| **CDMA** | 码 | 同一房间同时说，但每人用不同「语言/暗号」；听者只解自己的码 |

DMR 的广告语「一个 12.5 kHz 顶两路」——分的是**时间**，不是把频点撕成两半。

## 3. 白话术语表

| 术语 | 白话 | 现场你会碰到 |
|------|------|----------------|
| **多址 / Multiple Access** | 多人怎样共享同一套无线资源还不至于完全搅成粥 | 容量规划、信道忙闲、「为什么加不进第三路」 |
| **FDMA** | Frequency Division Multiple Access：按**频率**切信道 | 模拟常规：一个频点一路；NXDN/dPMR 一类真 6.25 kHz 切分也属 FDMA 家族 |
| **TDMA** | Time Division Multiple Access：按**时间片（时隙）**切信道 | DMR、TETRA、GSM、P25 Phase 2 等 |
| **CDMA** | Code Division Multiple Access：按**扩频码**区分用户 | 3G 蜂窝常见；专业对讲入门阶段少直接撞到 |
| **信道间隔 12.5 kHz** | 相邻合法载波中心隔多远（规划尺子） | 写频、执照、邻道 |
| **占用带宽** | 你实际发射能量铺多宽 | 频谱仪上看；别和「等效」混谈 |
| **时隙 Timeslot / Slot** | TDMA 的基本时间块；DMR 里 **30 ms**，编号 1 或 2 | 写频里的 Slot、中继灯、抓包时隙号 |
| **TDMA frame** | 两个连续时隙；DMR 里 **60 ms** | 「一帧两隙」 |
| **物理信道** | 实实在在的 RF 资源：某个中心频率上的那条 12.5 kHz 载波 | 「这个频点」「这个中继信道」 |
| **逻辑信道** | 在物理信道上划出来的独立业务路径；DMR 里常 = 某一个时隙上的话/数 | 「Slot1 跑安保组，Slot2 跑工程组」 |
| **6.25 kHz 等效（6.25e）** | **效率记账**：两路业务共享 12.5 kHz ⇒ 平均一路对应 6.25 kHz 频谱「份额」 | 标书、白皮书、和监管「窄带等效」对话；**不是**真切成 6.25 kHz 载波 |
| **同步** | 大家对表：谁在哪个时隙该说话 | 中继提供节拍；直通双时隙更吃同步 |

## 4. FDMA：按频率分房间

### 4.1 机制

把可用频谱切成一条条「车道」（频点或子带）。用户 A 占车道 1，用户 B 占车道 2。他们可以**同时**发射，靠滤波器把邻道挡开。

```text
频谱尺子：
──[ 信道A 12.5k ]──[ 信道B 12.5k ]──[ 信道C 12.5k ]──
     ▲                  ▲
   一路对讲            另一路对讲
   （可同时进行）
```

模拟常规对讲的日常感受，大体就是 FDMA 味道：**换信道 = 换频点**；一个频点被占用，同组别人往往要等。

### 4.2 优点与代价（直觉级）

- **优点**：概念直观；接收端用滤波器「拧台」即可；模拟时代就成熟。  
- **代价**：每多一路独立通话，通常就要**多占一段频谱**（或多套射频前端）。邻道要留保护，滤波器做窄也有代价。  
- **和「真 6.25 kHz FDMA」**：有些数字体制把原来 12.5 kHz 的「房间」再纵向切成更窄的子信道。理论上也能「两路塞进 12.5 kHz」，但执照规则、邻道干扰、合路器、振荡器漂移等工程问题会冒出来——DMR 协会白皮书里对此有专门对比（见推荐阅读）。

### 4.3 现场对照

- 写频软件里一长串「信道 = 频率」：FDMA 规划的遗产。  
- 「这个频点被占了，换个信道」：还是在换频率房间。  
- 频谱仪上并排两根独立载波：更像两路 FDMA，而不是一个载波上的两个时隙。

## 5. TDMA：按时间轮流麦

### 5.1 机制

**同一频率**上，把时间切成固定小片。用户 A 只在自己的片里发射，用户 B 在另一片里发射。片切得够短、轮得够快，人耳会觉得「两边都在连续通话」。

```text
同一 12.5 kHz 载波上的时间轴：

| Slot1 30ms | Slot2 30ms | Slot1 30ms | Slot2 30ms | ...
|  A 在说    |  B 在说    |  A 在说    |  B 在说    |
|<-------- 一帧 60 ms -------->|
```

关键数字（先死记，后面课会拆突发内部）：

| 项 | DMR 典型值 |
|----|------------|
| 时隙长度 | **30 ms** |
| 一帧（两时隙） | **60 ms** |
| 时隙编号 | **1** 或 **2** |
| RF 载波宽度规划 | 仍是 **12.5 kHz** |
| 调制 | 仍是 **4FSK**（第 4 课） |

电影比方（Tait 学院也爱用）：电影一秒钟几十帧静图，眼睛觉得在动。TDMA 是「时间上的快速切换」，听感连续，物理上却是你发我停、我发你停。

### 5.2 为什么必须「对表」

若 A 以为现在是 Slot1、B 也以为是 Slot1，两车会撞在同一时间片上。所以 TDMA **强依赖同步**：

- **有中继（BS）时**：基站出站常持续发射，并在突发之间塞 **CACH** 等，帮终端对齐「现在是哪一隙」。  
- **直通双时隙**：没有基站当鼓手时，终端之间要对齐，标准与实现更折腾（细节留给后面空口课）。

### 5.3 现场对照

- 写频：同一频率填两次，分别勾 Slot1 / Slot2。  
- 中继面板：两路呼叫指示可能同时亮——频谱仪上往往仍是**一根** 12.5 kHz 量级的数字载波在闪烁式工作，而不是两根并排细载波。  
- 手台电池：你只在自己的时隙发射，另一半时间发射机可歇着——这是 TDMA 省电叙事的来源之一（具体百分比因占空比而异，别背死一个数）。

## 6. CDMA：同场不同语（本课只需脸熟）

### 6.1 机制（极简）

大家可以**同一频段、同一时间**发射，但各自乘上不同的扩频码。接收端用「自己的码」去相关，把别人的能量当成可容忍的噪声背景。

会议室比方：所有人同时讲话，但每人说不同语言；你只懂中文，就只听得懂中文那一路——前提是声音别大到把整场淹没（功率控制很重要）。

### 6.2 和 DMR 入门的关系

- 3G 蜂窝（WCDMA 等）故事里 CDMA 很出名。  
- **DMR 专业层主流空口不是靠 CDMA 来切两路业务的**。你在 DMR 写频/抓包里日日相对的是 **时隙 + 频点 + Colour Code** 等，不是扩频码多址。  
- 本课要求：听到 CDMA 能归类到「分码」，并知道**别把 Colour Code 误叫成 CDMA**（Colour Code 是同频系统区分用的短标识，后面课再讲）。

## 7. DMR 落点：12.5 kHz 上的 2-slot TDMA

### 7.1 一张图钉死

```text
物理层资源（执照/规划看见的）：
        一个 RF 载波 · 信道间隔 12.5 kHz · 4FSK 调制
                         │
                         ▼
              ┌──────────────────────┐
              │   2-slot TDMA 切分    │
              │  Slot1 (30ms) 一路逻辑 │
              │  Slot2 (30ms) 另一路逻辑│
              └──────────────────────┘
                         │
         ┌───────────────┴───────────────┐
         ▼                               ▼
   逻辑信道 A：语音/数据/信令         逻辑信道 B：另一路独立业务
   （例如安保组呼）                   （例如工程个呼或 GPS 数据）
```

所以：

- **物理信道**：那条 12.5 kHz 载波（硬件、天线、合路器常按这个想）。  
- **逻辑信道**：某一个时隙上跑的那条「业务小路」。  
- 两路可以完全不相干：一组语音、一路数据；或两组语音。标准允许两隙内容彼此独立，只要时间同步还在。

### 7.2 「6.25 kHz 等效」到底在说什么

官方与厂商常用说法（精神一致）：

> 每一路业务只占用一半时间 × 仍然在 12.5 kHz 宽的载波上活动 ⇒ 频谱效率记成 **每路 6.25 kHz 等效**。

请并列记住三句「是 / 不是」：

| 说法 | 对吗？ |
|------|--------|
| 「DMR 用 12.5 kHz 信道间隔」 | **对**（规划/执照常见） |
| 「DMR 两路 ⇒ 6.25 kHz 等效效率」 | **对**（效率记账） |
| 「所以空中真的是 6.25 kHz 宽的两根细载波」 | **不对** |
| 「写频要把中心频率改成 ±3.125 kHz 两个点」 | **不对**（那是在想真 FDMA 切分） |

类比：一条 3.5 米宽的车道，两辆车**交替**通过，可以说「平均每辆车只占用半个车道的时间份额」——但车道并没有被水泥墙劈成两条 1.75 米的窄道。

### 7.3 和真 6.25 kHz FDMA 方案的直觉对比

| 维度 | DMR（2-slot TDMA） | 真 6.25 kHz FDMA（示意） |
|------|--------------------|---------------------------|
| 频谱怎么切 | **时间**切两半 | **频率**切两半 |
| 中心频点 | 常可沿用原 12.5 kHz 执照频点 | 往往涉及更窄信道的规划/执照 |
| 频谱仪观感 | 仍像 12.5 kHz 量级数字载波（时分活跃） | 更可能看到更窄或并排子载波 |
| 中继硬件直觉 | 一个中继可撑两路逻辑业务 | 两路常意味着更多射频/合路考量 |
| 同步 | 时隙要对齐 | 两子信道相对独立，但邻道/近远干扰更敏感 |

细节工程利弊以厂商白皮书与当地执照为准；本课只要建立「**切的维度不同**」这根筋。

### 7.4 和前几课怎么串

```text
第2课  频率/12.5 kHz 车道
第3课  声音 → 比特（声码器等）
第4课  比特 → 4FSK 骑上载波
第5课  同一载波上 → 用 TDMA 排两路「谁先发」   ← 你在这里
第6课  双工/半双工/中继/直通（谁听谁说的方向问题）
```

声码器要把话音压到能塞进**一个时隙**的载荷预算里（半速率量级的故事）；所以「双时隙」和「声码器码率」是配套设计，不是偶然。

## 8. 完整例子：写频与排障对照

### 例子 A · 一个中继频点两路组呼

- 上行 `450.000 MHz`，下行 `460.000 MHz`（数字仅示意）。  
- 信道间隔 **12.5 kHz**。  
- 安保组：Colour Code=1，**Slot 1**，组呼 ID=101。  
- 工程组：Colour Code=1，**同一对频率**，**Slot 2**，组呼 ID=202。

发生什么：

1. 物理上还是这一对 12.5 kHz 中继频率。  
2. 时隙 1 上跑安保，时隙 2 上跑工程——两路可同时进行。  
3. 手台 A 只解 Slot1 + 组 101；手台 B 只解 Slot2 + 组 202。  
4. 频谱仪在中继出站侧，常见是**连续的数字载波**（基站常持续发），内部用时隙与 CACH 组织两路。

### 例子 B · 同事说「再加第三路，还是这个频点」

你的判断清单：

1. 一个 12.5 kHz DMR 载波的 TDMA 结构是 **2** 时隙，不是随意 N 时隙。  
2. 第三路独立话音通常要：**另一个频点（另一个物理信道）**，或改业务策略（排队、集群分配、合并组等）。  
3. 别回答「再切一个 6.25 出来就行」——除非你们谈的是另一种体制/执照，而不是标准 2-slot DMR。

### 例子 C · 「6.25e」写进标书

客户问：「你们是不是 6.25 kHz 系统？」

稳妥答法：

> 我们是 **12.5 kHz 信道上的双时隙 TDMA**，频谱效率达到 **每话路 6.25 kHz 等效**；空中占用仍按 12.5 kHz 数字载波理解，并不是把载波劈成两个真 6.25 kHz FDMA 信道。

这句话能同时安抚「要效率」和「要兼容既有 12.5 kHz 执照」两拨人。

## 9. 常见误区

1. **「Slot2 = 另一个频点」**  
   错。Slot 是时间片；频点可以完全相同。

2. **「6.25 kHz 等效 = 信道间隔变成 6.25 kHz」**  
   错。等效是效率描述；DMR 专业层仍常在 12.5 kHz 间隔规划里工作。

3. **「TDMA 不需要同步，大家自己发就行」**  
   错。时隙错位 = 碰撞或解错路。中继存在时，把它当成节拍器来理解。

4. **「CDMA 就是 Colour Code」**  
   错。Colour Code 短小，用来区分同频系统；不是扩频多址那套。

5. **「有了双时隙，邻道干扰就消失了」**  
   错。你仍占着 12.5 kHz 量级的发射带宽故事；成型滤波、功放、杂散、邻道功率比该测还测（第 4 课）。

6. **「FDMA 过时了，DMR 完全不用频率划分」**  
   错。你的网里仍然有大量**频点规划（FDMA 味道）**；DMR 是在每个 12.5 kHz 载波**内部**再叠一层 TDMA。现实几乎总是 **FDMA（频点）× TDMA（时隙）** 的组合拳，就像 GSM 也是「先分频再分时」。

7. **「直通模式和中继模式的时隙故事完全一样」**  
   过于绝对。直通、单频、双频中继的定时细节不同（入站 guard、出站 CACH、偏移等）。本课先建立 30 ms / 双隙骨架；细时序留给阶段 C。

## 10. 自测（4–6 题）

**题 1（判断）**  
DMR 双时隙是把一个 12.5 kHz 载波从频率上劈成两个 6.25 kHz 子载波。对 / 错？

**题 2（单选）**  
下列哪一项最准确描述 DMR 专业层主流多址？  
A. 纯 CDMA  
B. 12.5 kHz 载波上的 2-slot TDMA  
C. 每用户独占无限带宽  
D. 只分频、不分时

**题 3（填空）**  
DMR 一个时隙约 ______ ms；两个时隙构成一帧约 ______ ms。

**题 4（单选）**  
「6.25 kHz 等效」更准确是指：  
A. 写频必须填两个相差 6.25 kHz 的频点  
B. 频谱效率记账：两路共享 12.5 kHz ⇒ 每路相当于 6.25 kHz 份额  
C. 最大频偏是 6.25 kHz  
D. 声码器采样率是 6.25 kHz

**题 5（简答）**  
用会议室比方各一句解释 FDMA、TDMA、CDMA。

**题 6（综合）**  
同事指着频谱仪说：「我只看见一根载波，怎么可能有两路通话？」请用本课语言解释，并指出他还应在写频/信令里确认哪两个字段级线索（时隙相关）。

### 参考答案

1. **错。**（时间上切两隙；载波规划仍是 12.5 kHz。）  
2. **B。**  
3. **30；60。**  
4. **B。**  
5. FDMA：不同房间同时说。TDMA：同一房间按秒表轮流说。CDMA：同一房间同时说但语言（码）不同。  
6. 两路是时分复用在同一物理载波上，频谱仪不一定显示成两根并排细峰。应确认双方是否占用 **Slot1/Slot2**，以及业务地址（组呼/个呼等）是否不同；中继出站还可能持续发射从而看起来「一直有载波」。
