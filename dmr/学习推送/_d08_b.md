## 8. 完整例子（三条故事，建议对照你单位）

### 例子 A · 物业公司：模拟拥挤 → 标准数字常规

- **原状**：一栋楼两部模拟中继，对讲组抢信道，边缘区沙沙响。  
- **诉求**：容量翻倍、音质稳一点、以后要短信/定位。  
- **标准化发挥的作用**：选 **Tier II** 路径，在**原 12.5 kHz 执照结构**上上数字中继；终端可多品牌竞标，要求 **SFID 标准组呼**互通并做联调。  
- **若无标准**：只能买「某厂全家桶」，三年后扩容被报价卡住。

### 例子 B · 应急演练：两个部门「都是 DMR」却不通

- **现象**：双方都亮着数字信号灯，却互不打通。  
- **排查顺序**：  
  1. 频率 / 色码 / 时隙是否一致；  
  2. 组号与呼叫类型是否一致（第 7 课）；  
  3. 是否一边在 **Tier III 集群业务信道**、一边在 **Tier II 常规**硬抠；  
  4. 要通的功能是不是某家 **MFID 私有**；  
  5. 是否开了互不兼容的加密。  
- **教训**：「DMR」三个字母只说明族谱；**配置与特性集**才决定这场演练成不成功。

### 例子 C · 「听得见数字、听不见模拟」的迁移周

- **现象**：双模机在数字信道清晰，切回模拟信道有人听不见。  
- **解释**：不是标准坏了，而是**两套世界并存**——模拟仍靠亚音与模拟静噪；数字靠色码/时隙/寻址。迁移周最怕「以为一个旋钮解决两个世界」。  
- **标准化帮助你的点**：至少数字侧有一份共同说明书；模拟侧继续用老规则，直到你主动关掉它。

## 9. 数字优势里，哪些该感谢「标准选型」？

把「数字的好处」拆开，避免神话。

| 好处（常见宣传） | 更主要来自 | 一句话限制 |
|------------------|------------|------------|
| 同 12.5 kHz 两路话 | **TDMA 标准选型** + 中继时隙协调 | 直通场景下「两路完全独立」的条件更苛刻 |
| 边缘音质更稳 | **数字化 + FEC 等** | 门限以下可能突然无声（断崖） |
| 电池更耐用（常见说法） | TDMA 发射占空比等 | 也取决于屏幕、定位、发射功率策略 |
| 短数据 / 定位 / 控制类业务 | **标准业务 + 厂商应用** | 应用层仍可能私有 |
| 多品牌可选 | **公开标准 + 市场** | 仍须验收 IOP 与私有边界 |
| 平滑占频谱 | **对齐现有信道规划的设计目标** | 执照与合路工程仍要做 |

DMR Association 等公开材料常强调：用 2 时隙 TDMA 在**既有 12.5 kHz** 上做到约 **6.25 kHz 等效**，并减少「另开 6.25 kHz FDMA 邻道」带来的规划冲击——这是**标准路线选择**，不是「数字」两个字自动长出来的。

## 10. 常见误区

1. **「上了数字就等于标准化了」**  
   错。私有数字协议也是数字。要看是否公开空口、是否按 ETSI 分册实现、验收测的是什么。

2. **「贴了 DMR Logo，任意两台一定互通」**  
   错。还要 Tier、模式、频率色码时隙、地址与呼叫类型、是否标准业务、加密与系统归属。

3. **「标准化以后厂商没差异了」**  
   错。射频指标、结构可靠性、人机界面、调度生态、集群规模、私有增值，差异巨大。标准管的是**共同语言的底线**。

4. **「SFID / MFID 是工程师废话，写频用不到」**  
   危险。当你在抓包或读规范时，FID 决定「这是标准剧本还是厂商剧本」；排「能连上厂家服务器却跨厂不通」时非常关键。

5. **「跨 Tier 也能通，都是 DMR」**  
   与规范表述冲突。三层产品**独立**，跨层**不保证**互通。工程上若出现「碰巧能通」，当作特例，不要写进默认假设。

6. **「数字一定比模拟覆盖更远」**  
   过度简化。常见优势是**可用音质在覆盖区内更一致**；比较覆盖要用约定指标与实地测试，不能只看宣传页。

7. **「标准化会阻碍创新」**  
   标准用 MFID 明确给厂商留扩展位；创新可以发生在扩展与产品层，但不要把扩展伪装成「跨厂必通」。

8. **「我们内部只用一家，所以不需要标准」**  
   仍建议要。备件替代、扩容招标、人员流动、与上级/友邻联动、长期维护成本，都会回到「有没有共同语言」。

## 11. 自测（建议先闭卷写，再对答案）

1. **判断**：数字化本身就能保证不同厂商终端互通。对 / 错？  
2. **选择**：DMR 标准化的重要频谱目标之一是：  
   A. 强制所有用户改用全新 25 kHz 信道规划  
   B. 尽量在现有 12.5 kHz 规划内数字化，并追求约 6.25 kHz 等效效率  
   C. 取消执照制度  
3. **填空**：标准默认特性集简称 ______；厂商特性集简称 ______。标准 Part 2 业务应通过 ______ + 对应 FLCO 暴露，才谈空口互操作。  
4. **简答**：为什么说「三层 Tier 跨层不保证互通」对选型很重要？  
5. **排障**：两个单位都说自己是 DMR，同频却不通。除了频率，请再列出至少四项应核对的点。  
6. **对照**：用两句话区分「公开标准带来的好处」和「某厂商私有功能带来的好处」。

### 参考答案

1. **错。** 互通依赖公开空口与共同配置；私有数字可以完全不通。  
2. **B。**  
3. **SFID；MFID；SFID。**  
4. 因为标书若只写「DMR」却混用 Tier II 常规与 Tier III 集群预期，可能买来无法按「天然互通」验收的系统；规范把三层写成独立产品形态。  
5. **色码、时隙、组号/个号与呼叫类型、Tier/工作模式（常规 vs 集群）、是否私有功能/加密、接收组与本机 ID 等。**（答出四项合理即可。）  
6. **公开标准**：多家可以实现同一套基本空口与业务，便于竞争与协作。**私有功能**：体验或能力可能更强，但默认不能当跨厂必通条件。
