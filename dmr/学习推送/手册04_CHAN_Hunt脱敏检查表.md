## 1. 为什么要写这篇手册（动机 + 现场对话）

第 36 课把「CHAN 是房号不是 MHz」钉牢；第 37 课把「Hunt 四阶段 + 验证先于确认先于发射」钉牢；第 40 课运维 Week‑3 只要你交付一样东西：

> **与网优对齐一张脱敏表：`站点 | CHAN | 计划类型 | CC | 备注`。**

手册 01 专治「登不上」；手册 02 专治「Grant 了没声」；手册 03 专治管理类投诉话术；本篇专治另一类更高频的**搜网 / 切站 / 新载频**工单——协议你会背，值班却卡在边界：

> 「手台一直转圈搜网，是覆盖差还是写频错了？」  
> 「新开了载频，老手台一被派上去就掉回控制信道——跟 Grant 无声是一回事吗？」  
> 「工单写『注册失败』，空口其实根本没摸到自家 TSCC。」

现场你一定听过这些对话：

- 用户：「开机一直搜网，发不出去。」——你若立刻改登记参数，可能漏问第一句：**它到底在猎站，还是已经守上 TSCC 却登不上？**（猎站失败 ≠ 登记失败，贴纸见 §2.3）  
- 网优：「新加了一台载频 CHAN=`N`（脱敏占位），老批次一被分到就失败。」——**灵活计划缺行**的经典指纹（第 36 课 / 手册 02）；先查写频有没有这一行，再查射频。  
- 写频员：「这批手台 SEP 我写成了 6.25，网络按 12.5 配的。」——固定计划公式里间隔乘 `(CHAN−1)`，**大号 CHAN 系统性跑偏**（第 36 / 40 课）。  
- 运维：「用户说登不上，Reason 都没有。」——空口身份都没对齐时，**不会有登记 Reason**；先看有没有解码到自家 SYScode / Aloha。  
- 路测：「两个相邻站之间来回蹦，场强两边都不差。」——猎站短列表 / 邻站公告 / Vote_Now 策略与写频不一致时的指纹（第 37 / 40 课）；不是「天线坏了」。  
- 监听员：「看见 Grant 了又掉回 TSCC。」——门牌缺行或 CC 不对时，**像手册 02，但根因在本篇检查表的 CHAN 行**。  
- 班长：「把旧控制信道拆了，手台每次开机还先去旧号空转一下。」——**记忆里的「最近确认 TSCC」** 仍在；Commanded 失败才进 Short（第 37 课）。  
- 测试：「分析仪上信道号是 4095，是不是坏值？」——**4095 = 看绝对频率续块**，不是坏值（第 36 课；本篇检查表要有一行勾选）。

培训台如果只背「CHAN 就是信道号、Hunt 就是搜网」八个字，值班会卡在同一处：

> **会背名词 ≠ 会填检查表。**  
> 分诊 = 每次工单强制按检查表顺序问：  
> **① 在猎站还是已在 TSCC？**（SYNC / CC / SYScode 证据）  
> **② Hunt 阶段指纹？**（上次 TSCC / 受令 / 短列表 / 综合）  
> **③ CHAN 计划类型与三段取值？**（固定 vs 灵活；0 / 1…4094 / 4095）  
> **④ 边界贴纸贴对了吗？**（猎站失败 / 登记失败·手册01 / Grant无声·手册02）  
> 四问答不清，不许升级为「覆盖差」或「换天线试试」。

本篇目标：能画出 Hunt vs 登记 vs Grant 无声三边界；会用脱敏检查表接单；会用「缺行 / SEP 漂移 / 相邻站来回蹦」三类指纹对齐网优；能填完《本网 CHAN/Hunt 脱敏检查表》；自测过关后，回库翻第 36 / 37 / 40 课与 `鉴权与AnnexC频率.md`、`AnnexD猎站Hunt.md` 把本网检查项补进表——**不重做第 36 课公式作业、不重拆第 37 课 C_SYScode**。

**本篇硬禁令（写进脑子）**：不发明 ETSI 条款号（入口锚点以资料库 `04-集群协议/鉴权与AnnexC频率.md`、`AnnexD猎站Hunt.md`、`Announcement与其余枚举.md`、第 36 / 37 / 40 课、手册 01 / 02 / 03 已有编号为准）；**不重 dump 固定计划全参数表 / CG_AP 字节手拆**（第 36 课）；**不重 dump Hunt 完整状态机 / Fig D.1 / C_SYScode 手拆**（第 37 课）；**不重 dump Grant 全变体 / Reason 全表 / Stun·DGNA·UDT**（手册 01–03 / 第 33–34 / 39 课）；**不写真实批复频点、真实站点号、真实用户个号进公开仓库**（一律用占位符 / 脱敏）；不把厂商中文提示当成 ETSI 正式名；不发明电平门限数值（规范门限单位由厂商自定）；本篇不写下一篇手册正文。

## 2. 总图 / 故事：三张边界贴纸

### 2.1 一句话：先问「人在哪」，再问「房号对不对」

继续旅馆比喻（第 31–40 课 + 手册 01–03）：

| 旅馆 | 空口 | 本篇工单常卡在哪 |
|------|------|------------------|
| 找导游集合点 | **Hunt** | 一直转圈 = 还没找到自家前台 |
| 牌子上写的团名 | **C_SYScode 验证** | 听到能量 ≠ 是自己的团 |
| 看清导游再说 | **确认（质量）** | 确认前**不得发射** |
| 前台办入住 | **登记**（手册 01） | 已在前台却登不上 ≠ 还在找前台 |
| 房卡小票上的房号 | **CHAN** | 房号不是 MHz；表缺行进不去客房 |
| 客房没声 | **Grant 无声**（手册 02） | 有 Grant 但门牌/CC/时隙错 |
| 临时禁房卡权限 | **Stun**（手册 03） | Stun 后仍可猎站/登记——别误判 |

口诀：**先判边界贴纸 → 再填检查表行 → 最后才谈覆盖与射频。**  
把「猎站失败」写成「注册失败」，或把「灵活计划缺行」写成「功放坏了」，是本篇最常见的两大口误。

| 你想确认的事 | 成功长什么样 | 失败 / 假故障长什么样 |

## 3. 核心交付：脱敏 CHAN / Hunt 检查表工作流

### 3.1 四问工作流（每次工单照念）

把第 40 课口诀展开成可勾选的四问：

```text
  第1问 · 在猎站，还是已经在 TSCC？
     证据：能否稳定解码本网 TSCC 相关信令（SYScode / Aloha 等）？
           Colour Code 是否像「自家油漆色」？
     还在猎站 ──────────────► 进第2问（Hunt 指纹）
     已在 TSCC ─────────────► 若主题是「登不上」→ 转手册01
                               若主题是「有Grant没声」→ 转手册02（并回填本表CHAN行）

  第2问 · Hunt 阶段指纹是哪一段？
     上次确认 TSCC（Resume） / 受令或记忆（Commanded） /
     短列表（Short） / 综合扫描（Comprehensive）
     ※ 运维不要求背状态机，只要能问「它在空转旧号？扫短表？还是全范围慢慢扫？」

  第3问 · CHAN 计划与三段取值对了吗？
     计划类型：固定（公式）还是灵活（逐行）？
     出问题的 CHAN 是 0 / 1…4094 / 4095？
     写频表里有没有这一行？SEP / CC 与网络是否一致？（脱敏勾选，不写真实MHz）

  第4问 · 边界贴纸贴对了吗？结案前强制自检
     □ 猎站失败（本篇）  □ 登记失败（手册01）  □ Grant无声（手册02）
     贴错贴纸 = 开错单 = 浪费下一班时间
```

**结束条件**：四问都有证据（空口 / 可靠解码日志 / 写频版本号，均脱敏）写入工单，才能谈「覆盖差」或「换天线」。只有中文「搜不到台 / 没信号」六个字 = 线索不足。

### 3.2 决策树（口述版）

```text
  工单进来：「搜网 / 登不上 / 新载频掉线 / 来回蹦」
        │
        ▼
  能解码自家 TSCC 吗？
     │
     ├─ 否 ──► 贴纸A（猎站）──► 第2问阶段指纹 ──► 第3问写频/CHAN表
     │              │
     │              └─ 短列表无自家TSCC？记忆旧号？CC/SYScode不对？综合被抑制？
     │
     └─ 是 ──► 主题是登记？
                  ├─ 是 ──► 贴纸B ──► 手册01三问（本篇停笔，只在表头注明「已转01」）
                  └─ 否，主题是呼叫无声 / 掉回TSCC？
                            └─ 贴纸C ──► 手册02四问
                                  └─ 尤其核：灵活缺行 / 固定SEP / CC / 4095续块
```

### 3.3 检查表行模板（脱敏 · 与网优共用）

第 40 课原文要求维护：

> `站点 | CHAN | 计划类型 | CC | 备注`（勿外泄真实批复频率）

本篇把它扩成值班可填版（**公开材料只允许占位符**）：

| 字段 | 填什么 | 禁止填什么 |
|------|--------|------------|
| **站点** | `站A` / `站B-东` / `临时站-演练` | 真实批复站名/站号明文入库 |
| **CHAN** | 逻辑号如 `23` / `161` / `4095` | 把真实 MHz 写进学习推送仓 |
| **计划类型** | `固定` / `灵活` / `绝对续块` | 「不知道」却结案 |
| **CC** | `0`…`15`（本网实际值可内部存，公开用 `CC=?`） | 与真实站绑定的可识别组合外泄 |
| **角色** | `TSCC` / `Payload候选` / `已撤控` | — |
| **备注** | 缺行？SEP存疑？旧记忆？BCAST加减？ | 真实用户个号、真实批复文号 |

### 3.4 日志三联单（Hunt/CHAN 版）

| 栏 | 要写 | 好例子（脱敏） | 坏例子 |
|----|------|----------------|--------|
| **终端侧** | 型号/写频包版本；个号末几位脱敏；猎站列表版本；计划类型 | 「机型X，写频包 2026-09-b；灵活计划；短列表含站A/站B」 | 「用户说没信号」 |
| **空口侧** | 能否解 SYScode/Aloha；所见 CHAN；有无 Grant；掉回 TSCC 否 | 「无稳定 Aloha；偶见能量；无登记 RAND」 | 「覆盖差」 |
| **网络侧** | 站点标识脱敏；近期是否新开载频/拆旧控；MassReg/改写频窗 | 「站B 本周新开 Payload CHAN=N；旧TSCC已撤」 | 「系统有问题」 |

三联单填齐且四问指向同一贴纸之后，才进入 §5 深潜与 §6 现场对话。

## 4. 深潜：检查表背后的五颗钉子（只取运维用）

### 4.1 CHAN 三段取值（检查表必勾）

| 12-bit 值 | 运维一句话 | 检查表怎么勾 |
|-----------|------------|--------------|
| **0** | 多数 PDU 里 = 无效/未分配；**P_CLEAR 例外**：回上次确认的 TSCC | 若工单扯到「清业务后回前台」，单独备注「P_CLEAR 的 0」 |
| **1…4094** | 逻辑房号 → 查写频门牌表（固定公式或灵活逐行） | 核：该行存在吗？CC 对吗？ |
| **4095（0xFFF）** | **不是坏值** = 看绝对频率续块（CG_AP / MV_AP / …） | 核：解码器有没有丢第二块？ |

口诀：**房号不是 MHz；4095 是「看背面」。**

### 4.2 固定 vs 灵活：两种「缺」长得不一样

| | 固定计划 | 灵活计划 |
|--|----------|----------|
| 门牌怎么来 | `f ≈ fbase + (CHAN−1)×间隔`（第36课公式，本篇不重算） | 每个 CHAN 一行 Tx/Rx/CC |
| 典型故障指纹 | **SEP/fbase/双工分裂写错** → 大号 CHAN **系统性跑偏** | **缺某一行** → 只有被派到该 CHAN 才失败 |
| 检查表动作 | 勾「SEP/参数存疑」；对照同批次写频 | 勾「缺行」；抽 2 台老手台读写频看有无该 CHAN |
| 和手册02关系 | 表现为 Grant 无声 / 掉回 TSCC | 同左；缺行演练是第40课网优作业 |

**缺行演练（运维×网优对齐，脱敏）**：

```text
  网络：新开 Payload，逻辑号 CHAN = N（占位）
  老手台写频：灵活计划无 N 这一行
  空口：仍可能收到 Grant（票样真）
  终端：改不了频 / 进不去 → 掉回 TSCC
  ※ 这是手册02现象 + 本篇检查表根因；先补行或改派，不先换天线
```

### 4.3 SEP 漂移指纹（固定计划）

固定计划间隔写错时：

- 小号 CHAN 可能「看起来还能凑合」；  
- **CHAN 越大，偏差越大**（乘的是 `CHAN−1`）；  
- 现场像「大信道全军覆没、小信道偶发正常」——检查表备注写「SEP 系统性」，不要写成「个别天线」。

### 4.4 Hunt 四阶段（运维指纹版，不 dump 状态机）

| 阶段 | 英文线索 | 值班怎么认 | 失败常去哪 |
|------|----------|------------|------------|
| **a** | Resume | 刚出业务，应很快回老 TSCC | 验证失败 → Short |
| **b** | Commanded | 开机先去旧号空转；或 C_MOVE/P_CLEAR 点名 | 失败 → Short |
| **c** | Short Hunt | 较快扫「常用 TSCC」短列表（可被 BCAST 加减） | 失败 → Comprehensive（除非抑制） |
| **d** | Comprehensive | 慢、扫 Low…High 全范围；可被 Comp_Flag 关掉 | 关掉则困在 Short |

运维口头四问补充句：

> 「它是在空转一个旧控制信道号，还是在一张短表里打转，还是明显在全范围慢慢搜？」

### 4.5 验证 → 确认 → 才发射（铁律）

```text
  听到能量 / 同步   ≠  通过验证
  验证（SYScode 等）通过  ≠  已确认可用
  确认质量够用之前  →  不得发射（登记/业务请求都不行）
```

现场含义：

- 「扫频仪上有个台在响，手台不上」——可能**验证没过**（别家网 / 无授权 / SYS_AREA 曾被拒）。  
- 「解出一点牌子又不动」——可能**确认门限不够**（质量不够用）。  
- 「乱发射干扰」——违反铁律；检查表备注「确认前发射」属终端/实现异常，不是覆盖问题。

登记失败与猎站（第 37 / Annex D）：登记被拒/超时 → **回到登记前所处的猎站阶段**，不是盲目从 Short 重开。贴纸 B 结案后若仍掉站，再回贴纸 A 看阶段指纹。

### 5.1 网管 / 用户中文 → 先贴哪张贴纸

| 「两个站来回蹦」 | A + 短列表/邻站策略 | 短列表是否两边都「太像家」；Vote_Now/邻站公告 |

### 5.2 值班对话脚本（可直接照着说）

#### 对话 A · 「一直搜网」

- 用户：「开机一直转圈，发不出去。」  
- 你：「好。我们先分清：是**还在找控制信道**，还是**已经找到了但登记失败**。你那边网管/分析有没有看到这台机解出过本网的系统码或 Aloha？」（第1问）  
- 用户：「没有，就一直搜。」  
- 你：「那先走猎站检查表，不先改登记权限。写频包版本？短列表里有没有本站控制信道逻辑号？最近有没有拆过旧控制信道？」（第2–3问）

#### 对话 B · 「注册失败」其实没摸到 TSCC

- 坐席：「工单写注册失败。」  
- 你：「Reason 码值是多少？有没有登记类 C_RAND？」（手册01三问）  
- 坐席：「……没有码，也没有 RAND。」  
- 你：「没有码就不要开登记剧本。先按贴纸 A：它可能根本没守上自家 TSCC。把空口证据补上再决定转不转手册01。」

#### 对话 C · 新载频一派就掉

- 网优：「新载频 CHAN=`N`，老机一上去就掉回控制信道。」  
- 你：「Grant 票样有吗？」（手册02①）  
- 网优：「有 Grant。」  
- 你：「计划类型是灵活还是固定？抽两台老机看写频里有没有逻辑号 `N` 这一行、CC 是否一致。先做缺行/参数核对，再谈覆盖。」（本表第3问）

#### 对话 D · 相邻站来回蹦

- 路测：「两个站之间来回切，场强都不差。」  
- 你：「短列表是不是两个站的 TSCC 都写得很『优先』？邻站公告 / Vote_Now 本网策略最近改过吗？先对写频与公告，再判『覆盖空洞』。」

#### 对话 E · 「4095 是坏值吗？」

- 新人：「分析仪显示 4095，是不是解码错了？」  
- 你：「4095 是约定暗号：绝对频率在续块。先看第二块在不在，别当坏值清掉。」

### 5.3 「先信令 / 写频，后覆盖 / 射频」反例集

| 一上来就做的动作 | 为何常错 | 应先做 |
|------------------|----------|--------|
| 一听「搜不到」就测驻波 | 多数是列表/记忆/验证 | 第1–2问 |
| 一听「注册失败」就改鉴权 | 可能还在猎站 | 有无 SYScode/RAND |
| 一听「新载频掉线」就加功放 | 常是缺行/SEP/CC | 读写频有无该 CHAN |
| 一听「来回蹦」就改天线方位 | 常是短列表/邻站策略 | 对表与公告 |
| 把 4095 当噪声滤掉 | 丢掉绝对频率续块 | 核对 MBC 第二块 |

## 6. 工作实例（8 个厚例，均脱敏）

### 例 1 · 开机死循环搜网：短列表没有自家 TSCC

**现象**：新写频批次开机一直转圈。  
**四问**：① 无稳定 Aloha；② 像 Short 打转；③ 短列表缺本站 TSCC 逻辑号；④ 贴纸 A。  
**动作**：补短列表 / 或确认 BCAST Ann_WD 是否误撤；不改登记 Reason 剧本。  
**收工**：能解 SYScode 后，若仍登不上再转手册01。

### 例 2 · 拆旧控：每次开机先去旧号空转

**现象**：旧 TSCC 已撤，手台开机先静默一会儿再搜到新台。  
**四问**：① 短暂无信号；② **Commanded 记忆旧号**指纹；③ 记忆/短列表仍含旧 CHAN；④ 贴纸 A。  
**动作**：更新写频记忆与短列表；培训「先空转旧号」是预期残留，不是覆盖塌方。

### 例 3 · 新载频灵活缺行（手册02现象，本表根因）

**现象**：Grant 真有，老机掉回 TSCC。  
**四问**：① 已在 TSCC；主题是无声 → 贴纸 C；③ **灵活计划无 CHAN=`N`**；回填本表「缺行」。  
**动作**：补行或勿把老机派到 `N`；缺行演练记入网优周报。

### 例 4 · 固定计划 SEP 写错：大号 CHAN 全军覆没

**现象**：小号偶发可用，大号进业务全失败。  
**四问**：贴纸 C + 本表「SEP 系统性」；对照同公式批次。  
**动作**：校正写频间隔参数（内部流程）；公开材料只写「SEP 不一致」，不写真实 MHz。

### 例 5 · 「注册失败」工单：空口无 RAND

**现象**：坐席开手册01剧本，但无 Reason。  
**四问**：① **不在 TSCC**；④ 应贴 A 却误贴 B。  
**动作**：退回贴纸 A；补齐空口证据；禁止无码值结「鉴权失败」。

### 例 6 · 相邻站来回蹦

**现象**：站A/站B 之间反复切，业务时断时续。  
**四问**：① 两边都能解；② Short/邻站策略；③ 两边 TSCC 都在短列表且偏好接近；④ 贴纸 A（策略）而非单纯覆盖。  
**动作**：与网优对短列表偏置、Vote_Now/邻站公告；记录脱敏「双优站」。

### 例 7 · CHAN=4095 丢续块

**现象**：偶发呼叫失败，解码器只见 4095。  
**四问**：贴纸 C；③ 勾「4095」；查 MBC 第二块。  
**动作**：修复解码/抓包配置；勿滤掉 4095。

### 例 8 · 登记被拒后「又去搜网」——其实是规范接法

**现象**：`0x2A`/`0x2B` 后手台离开再猎。  
**四问**：先贴纸 B 走完手册01；再理解「回到登记前猎站阶段」（第37课）。  
**动作**：登记剧本与猎站指纹写在同一工单两段；别当成两个无关故障单。

### 例 9 ·（加分）Stun 后仍在搜网/登记

**现象**：调度以为「禁了还不老实」。  
**边界**：手册03——Stun **保留**猎站/登记/定位；成败看业务是否已停。  
**动作**：不在本篇开「猎站失败」单；回手册03话术。

---


### 例 10 ·（对照）干净成功：Hunt → 登记 → Grant → 有声

**现象**：新员工开机，30 秒内可通。  
**四问自检**：① 很快有 Aloha；② Commanded 或 Short 一次过；③ 门牌含本站 TSCC 与业务 CHAN；④ 无需贴纸（快乐路径）。  
**教学用途**：给新人当「正常长什么样」的对照样张；工单系统可存脱敏截图栏位名，不存真实 MHz。

## 8. 术语表（本篇约 28 词）+ 易错观念

| 术语 | 一句话 | 易错 |
|------|--------|------|
| **CHAN** | 12 bit 逻辑房号 | 当成 MHz |
| **门牌表** | 房号→频率的写频计划 | 以为 Grant 自带 MHz（4095 除外） |
| **固定计划** | 公式算频率 | SEP 写错会系统性跑偏 |

| **Resume** | 回上次确认 TSCC | — |
| **Commanded** | 单信道直调（记忆/MOVE/CLEAR） | 开机空转旧号当故障 |
| **Short Hunt** | 扫短列表 | — |
| **Comprehensive** | 扫全范围兜底 | 忽略 Comp_Flag 抑制 |
| **验证** | SYScode 等：是不是我家 | 听到同步就当验证过 |
| **确认** | 质量够不够用 | 与验证顺序颠倒 |

| **TSCC** | 控制信道前台 | — |

**题 11.（加分）** 登记 `0x2A` 后手台再猎，是「又一个无关故障」还是规范接法？应如何写工单？

**题 12.（加分）** Stun 后终端仍猎站，应引用哪本手册？本篇是否应开「猎站失败」单？

### 参考答案

1. **不是第 41 课。** 手册模式第 4 篇；服务运维 **Week‑3**：CHAN/Hunt 脱敏检查表。  
2. ①在猎站还是已在TSCC → ②Hunt阶段指纹 → ③CHAN计划与三段取值 → ④边界贴纸。证据例：SYScode、Aloha（或稳定本网控信道解码）。  
3. A猎站失败；B登记失败（手册01）；C Grant无声（手册02）。无 Reason/无 RAND → **贴纸 A**（先别开01）。  
4. 0：常无效；P_CLEAR 的 0 → 回上次确认 TSCC。300：逻辑房号查表。4095：看绝对续块。  
5. 缺行：常**仅**该 CHAN 受害。SEP 错：大号**系统性**跑偏。  
6. Resume 回老控；Commanded 受令/记忆单号；Short 扫短表；Comp 扫全范围。开机空转旧控 ≈ **Commanded 记忆**。  
7. 未确认身份与质量就发射会干扰/违规接入；铁律：**确认前不得发射**。  
8. 手册02：真Grant？CHAN/时隙/门牌？Payload身份？最后射频。根因回填本表 **CHAN/计划类型/备注(缺行)**。  
9. `站点|CHAN|计划类型|CC|备注`。真实批复频率属受控信息，学习推送/公开仓脱敏。  
10. **先**短列表/邻站/Vote_Now 策略对齐，再谈覆盖空洞。  
11. 规范接法：回到登记前猎站阶段。工单两段写：登记剧本 + 随后 Hunt 指纹。  
12. 手册03；一般**不应**当猎站失败单，先核业务是否已停。

## 11.7 常见问法速查（FAQ 式）

**Q1：搜网是不是就是注册失败？**  
A：不一定。先问在不在 TSCC；不在 → 贴纸 A。

**Q2：灵活缺行会不会没有 Grant？**  
A：常常**有** Grant 票样，但进不去 → 掉回 TSCC。按手册02+本表缺行。

**Q3：4095 要不要当噪声滤掉？**  
A：**不要。** 它表示绝对频率续块。

**Q4：检查表能不能写真实频率方便夜班？**  
A：**不能写进学习推送/公开仓。** 真实批复只留在受控内部系统。

**Q5：本篇要不要会手算 fbase 公式、手拆 C_SYScode？**  
A：值班检查表**不要求**重做第36/37课作业；会认三段取值与四阶段指纹即可。要深挖再回原课。

**Q6：和手册02如何分工？**  
A：手册02管「Grant无声四问」流程；门牌缺行/SEP/CC 根因**回填本篇主表**。
