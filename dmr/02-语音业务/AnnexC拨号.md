## C.1 定位
- **信息性**：厂商 MMI 可自由；本附录给 UI 编号 ↔ AI 地址的**建议映射**，避免歧义呼叫。
- 适用：带 CCITT 键盘（0–9 * #）和/或能显示这些符号的终端。
- 用户输入模型：**(a) 拨号数字 → (b) 发起**（`#` / PTT / 厂商键）。非法串不应上空气。

---

## C.2 UI ↔ AI 映射要点

### 个体（可拨）
- 用户侧常见 **7 位十进制** `"0000001"`…`"9999999"` → **真十进制转 24-bit**（算法 **B1**）。
- 串中含 `*` → 按**组呼**理解（非个呼）。

### 个体（不可拨扩展，prefix 10–14）
- **B3** 等算法把 8 位形态（中间固定 0）映到非可拨个号区；每 prefix 约 **10 000** 容量（细节 Table C.2）。

### 组呼 / 通配
- 低位若干位为 `*` → talkgroup / 通配集合。
- 另有：存储参数、临时（ad-hoc）安排、发端/收端规则、prefix 概念（C.2.1.2.*）。

### 缩位拨号
- 拨 **1…7** 位：视为替换**本机个号**最右对应位，再经 B1 等转 AI。  
  例：本机 `1234567`，拨 `43` → 目的 `1234543`。

### 网关 / 全组
- AI 侧网关与 All-MS 特殊 ID 对齐 Part 1 Annex A；电话/PABX/IP 经网关串（C.3.4.2）。

## C.3 呼叫修饰与行为（摘要）

以 `#` / `*` 开头的修饰串（厂商可裁剪）：

| 类 | 例意图 |
|----|--------|
| 广播 | Broadcast call |
| 优先级 / 紧急 | Priority / Emergency |
| 状态 | Status call |
|  Divert | Divert own call |
| OVCM / 强制组业务 | Open voice channel / Force TG |
| 电话 / PABX | 数字填充或 `*` 修饰格式 |
| IP 呼叫 | IP call 串 |
| 行为命令 | 编辑组表、排队来话、显示本机 ID/组表等 |

完整键位串与转换表 → PDF C.3.4；**不在此展开长表**。
