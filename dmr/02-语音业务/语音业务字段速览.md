## 1. Opcode 速查（Annex B）

### 1.1 FLCO（Table B.1）

| FLCO | Description | Alias | 典型承载 |
|------|-------------|-------|----------|
| 000000 | Group Voice Channel User | Grp_V_Ch_Usr | Voice LC Header / 嵌入 / Terminator with LC |
| 000011 | Unit to Unit Voice Channel User | UU_V_Ch_Usr | 同上（个呼） |
| 000100 | Talker Alias header | Talker_Alias_hdr | 嵌入 LC |
| 000101 | Talker Alias block 1 | Talker_Alias_blk1 | 嵌入 LC |
| 000110 | Talker Alias block 2 | Talker_Alias_blk2 | 嵌入 LC |

## 2. 语音呼叫过程与空口 PDU 对照（摘要）

引用：clause **5.2**（组呼/个呼）；Part 1 Data Type。

| 阶段 | Data Type / 场 | 典型 PDU | FLCO/CSBKO |
|------|----------------|----------|------------|
| 可选唤醒 BS | CSBK | BS_Dwn_Act | 111000 |
| 个呼存在性检查 | CSBK | UU_V_Req → UU_Ans_Rsp / NACK | 000100 / 000101 / 100110 |
| 语音开始 | Voice LC Header (`0001`) | Grp_V_Ch_Usr 或 UU_V_Ch_Usr | 000000 / 000011 |
| 超帧语音 | Voice + SYNC(A) / 嵌入(B–F) | 同 FLCO；可嵌 Talker Alias / GPS | — |
| 语音结束 | Terminator with LC (`0010`) | 同 Voice Channel User LC | 同上 |
| BS 挂起/保留 | Terminator with LC | BS 生成同 LC | — |
| 扫描/节电前导 | CSBK | Pre_CSBK | 111101 |
| CACH 空闲/活动 | Short LC | Nul_Msg / Act_Updt | SLCO 0000/0001 |

**Late entry**：靠超帧 A 的 Voice SYNC + 嵌入/头中的地址 LC（Part 1 **5.1.2**）。

## 6. Service Options 与相关 IE（clause 7.2）

### 6.1 Service Options（Table 7.11）— 8 bits

| 子域 | Len | 取值摘要 |
|------|-----|----------|
| Emergency | 1 | `0` 非紧急；`1` 紧急 |
| Privacy | 1 | 本规范未定义隐私算法（NOTE） |
| Reserved | 2 | `00` |
| Broadcast | 1 | `0` 非广播；`1` 广播（**仅组呼**） |
| Open Voice Call Mode (OVCM) | 1 | `0`/`1` |
| Priority level | 2 | `00` 无；`01` P1；`10` P2；`11` P3（最高） |

全呼/广播：Grp_V_Ch_Usr 中 Broadcast=`1`，并配合全呼地址约定（Part 1 编址 + clause **5.3.3**）。

### 6.2 Answer Response / Reason / Source Type

| IE | Len | 关键值 | 条款 |
|----|-----|--------|------|
| Answer Response | 8 | Proceed=`00100000`；Deny=`00100001` | 7.2.2 |
| Reason Code | 8 | 例：不支持业务=`00100001` | 7.2.3 |
| Service Type | 6 | = 相关 CSBKO | 7.2.4 |
| Source Type | 1 | `0` BS；`1` MS | 7.2.5 |
| CBF | 8 | preamble 后续块数（不含本块） | 7.2.7 |

### 6.3 Tier 2 RC Command（Table 7.27 指针）

Part 2 亦定义 Tier II MS Reverse Channel Command IE（clause **7.2.20**）。Tier III 闭环功率/强拆用的 4-bit RC Command 见 Part 4 Table **6.32**（与 Part 1 RC Info Payload 对接）。
