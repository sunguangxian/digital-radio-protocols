## 1. DMR 是什么（30 秒版）

**DMR（Digital Mobile Radio）** 是 ETSI 制定的专业数字移动无线电标准，面向陆地移动业务频段，目标是：

- 在现有 **12.5 kHz** 信道上数字化
- 用 **2 时隙 TDMA** 达到 **6.25 kHz 等效**频谱效率（同一载波上可支撑两路通话）
- 提供语音、短数据、分组数据等业务
- 低复杂度、可负担，兼容既有执照频谱规划

**一句话**：把模拟对讲“升级”成开放标准的数字对讲/集群，同时把一条 12.5 kHz 信道当两条用。

## 2. 三层 Tier（先选对层级，再读规范）

| Tier | 定位 | 怎么工作 | 你常关心什么 |
|------|------|----------|--------------|
| **I** | 低成本 / 数字 PMR446 类 | 一体天线、直通；Tier I 还可采用连续发射的 **FDMA 变体** | 消费/轻商用，覆盖范围有限 |
| **II** | 专业常规（conventional） | **点对点** 或 **中继**；2-slot TDMA / 12.5 kHz | 空口、语音业务、中继、数据 |
| **III** | 专业集群（trunking） | 有控制器自动分配信道 | 控制信道、登记、呼叫建立、集群业务 |

要点：

- Tier II / III 都可包含 **同播（simulcast）** 与非同播系统。
- **三层之间不要求互通**（各自独立产品族）。
- DMR Association 产业推动重点在 **Tier II / III**。

## 4. 空中接口骨架（读 Part 1 前先装这些）

### 4.1 时隙与帧

- **物理信道**：一条 RF 载波上的 TDMA 突发（burst）
- **TDMA-frame**：连续 **2 个时隙**
- **Superframe（超帧）**：连续 **6 个** TDMA burst，标号 **A–F**（语音超帧常用）
- 典型 **TDMA burst 时长约 30 ms**（另有不同长度突发定义，细节见 Part 1）
- 字段级表格式整理：[`01-空中接口/帧结构与字段定义.md`](./01-空中接口/帧结构与字段定义.md)

### 4.2 为什么是“6.25 kHz 等效”

2 时隙结构让 **同一 12.5 kHz 载波**可维持两路通话（中继或直通场景下），从而在频谱规划不变的前提下获得近似“把信道对半切”的容量收益。

### 4.3 工作模式直觉

| 模式 | 直觉 |
|------|------|
| 直通（Direct / peer-to-peer） | 终端互传，靠突发维持同步 |
| 中继（Repeater） | 基站转发；常配合 **CACH** 等嵌入信令 |
| 集群（Trunked，Tier III） | 控制信道调度，业务到业务信道 |

### 4.4 空口协议还强调什么（TR 归纳）

低信令时延、可选双工/网关、反向信道信令、礼貌信道接入（polite access）、声码器可由供应商选择、兼容既有执照频段规则、节电、窄带数据能力。

> 实现细节、状态机、接入算法 → **只读 Part 1**，不要在四本里搜同一概念。

## 5. 业务全景（语音 / 数据 / 补充业务）

### 5.1 业务怎么分类（电信习惯）

- **承载业务（Bearer）**：低层信息传送能力（如个呼承载、确认 PDP）
- **电信业务（Tele-service）**：含终端功能的完整用户通信能力
- **补充业务（Supplementary）**：依附于上述业务（如迟后进入 Late Entry）
- 另有 **网络规程**、**特性（Feature）**（如站址地址）

互操作关键：

- **SFID**（Standards Feature ID）：标准默认特性集  
- **MFID**：厂商私有特性集  
- **FLCO**：某特性集内的空中功能码  
- 标准特性应通过 **SFID + FLCO** 暴露，才能保证空口互操作

### 5.2 Tier I / II 常见语音类（概念层）

- 个呼（Individual Call）
- 组呼（Group Call）
- 未编址语音、全呼（All Call）、广播呼叫（Broadcast）等  
- 常见补充：迟后进入、主叫识别（Talking Party Identification）等  

→ 过程、PDU、定时：**Part 2**

### 5.3 数据（PDP）一张表说清

| 能力 | Tier I / II | Tier III |
|------|-------------|----------|
| 分组数据协议 PDP | 有（确认 / 非确认） | 业务信道上可用 PDP |
| IP over PDP | 有 | 有（业务信道） |
| 短数据 | 经 PDP（状态/预编码、原始、已定义数据等） | 控制信道有**自有短数据业务**；业务信道亦可走 PDP |

→ PDU、压缩头、确认窗：**Part 3**  
→ 集群控制信道短数据与登记/呼叫：**Part 4**

## 7. 关键术语速查（新人词汇表）

| 术语 | 含义（学习口径） |
|------|------------------|
| MS / BS | 移动台 / 基站 |
| AI | Air Interface，空中接口 |
| TDMA | 时分多址；DMR 专业层为 2 时隙 |
| Burst | 突发，物理层发送单元 |
| CACH | 嵌入控制信道相关信令（中继等场景常见） |
| Colour Code | 色码，区分同频系统/降低误听 |
| Vocoder | 声码器；标准允许供应商选择实现 |
| PDP | Packet Data Protocol，分组数据协议 |
| TSCC / TSCCAS | 集群控制信道相关概念；AS 为交替控制时隙类能力 |
| SFID / MFID / FLCO | 标准/厂商特性集与功能码 |
| Simulcast | 同播 |
| Polite access | 礼貌接入，降低干扰已建立通信 |
