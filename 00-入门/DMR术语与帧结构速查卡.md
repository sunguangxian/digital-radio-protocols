## A. 帧 / 时隙结构（先看这个）

```text
                    一个 TDMA frame = 60 ms
        ┌─────────────────────┬─────────────────────┐
        │     Timeslot 1      │     Timeslot 2      │
        │       30 ms         │       30 ms         │
        └─────────────────────┴─────────────────────┘

单个 TDMA burst（时隙内容）≈ 30 ms：
  · 其中 **27,5 ms** 承载 **264 bit** 内容
  · 另约 **2,5 ms**：
      - 入站（MS→BS）：常用作 **guard time**（功放爬升 / 传播时延）
      - 出站（BS→MS）：常用作 **CACH**（公共通告信道）

264 bit 突发内部（典型）：
  ┌──────────┬────────────────┬──────────┐
  │ 108 bit  │     48 bit     │ 108 bit  │
  │ Payload  │ SYNC 或嵌入信令 │ Payload  │
  └──────────┴────────────────┴──────────┘
  两个 payload 合计 **216 bit** → 足够携带约 **60 ms** 压缩语音
```

### 语音超帧（Voice superframe）

| 项 | 值 |
|----|-----|
| 组成 | 连续 **6** 个 TDMA burst，标号 **A–F** |
| 时长 | **360 ms**（6 × 30 ms） |
| 语音呼叫中 SYNC 机会 | 每信道约每 **360 ms** 一次（超帧级） |
| 数据/控制突发 SYNC | 可更密（入站可至约 60 ms 量级；出站因双时隙可见可至约 30 ms） |

### 中继时序直觉（两频 BS 常见）

- 出站持续发射时，两时隙都有内容可收  
- 入站与出站突发常见 **30 ms 偏移**对齐方案，便于 CACH 用同一信道编号指入/出站  
- 语音 / 数据用 **不同 SYNC 图案**，接收端可区分

## B. 四种基本信道形态（Part 1）

| 类型 | 一句话 |
|------|--------|
| Traffic + **CACH** | 业务时隙之间夹 CACH（出站常见） |
| Traffic + **Guard** | 业务时隙之间留保护间隔（入站常见） |
| **Bi-directional** | 同一载波上正反向分时 |
| **TDMA Direct Mode** | 直通 TDMA；另有连续发射类 Tier I 变体（偏 FDMA） |

## C. 术语速查（按出场频率）

### 系统与层级

| 术语 | 速记 |
|------|------|
| **DMR** | ETSI 数字专业移动无线电标准 |
| **Tier I / II / III** | 免执照轻量 / 常规执照 / 集群执照；**互不要求互通** |
| **MS / BS** | 移动台 / 基站 |
| **AI** | Air Interface，空中接口（Part 1） |
| **Conventional** | 常规（非集群），多指 Tier II |
| **Trunking** | 集群（Tier III），控制器分配信道 |
| **Simulcast** | 同播 |

### 物理与接入

| 术语 | 速记 |
|------|------|
| **12,5 kHz** | RF 载波带宽 |
| **2-slot TDMA** | 专业层主流多址；带来 **6,25 kHz 等效** |
| **Timeslot / Slot** | 时隙，**30 ms**，编号 1 或 2 |
| **TDMA-frame** | 两连续时隙 = **60 ms** |
| **Burst** | 突发，物理发送单元 |
| **Guard time** | 保护时间（约 2,5 ms 量级用途之一） |
| **CACH** | Common Announcement Channel：帧编号、接入指示、低速信令 |
| **SYNC** | 帧同步字段（48 bit 位置）；语音/数据图案不同 |
| **4FSK** | 四电平 FSK 调制（空口物理相关） |
| **Polite access** | 礼貌接入，降低干扰已建链通信 |
| **Colour Code** | 色码，区分同频系统、降低误听 |

### 协议与业务

| 术语 | 速记 |
|------|------|
| **Vocoder** | 声码器；标准允许供应商选择 |
| **CSBK** | Control Signalling Block，控制信令块 |
| **LC / Full LC** | Link Control，链路控制 |
| **PDP** | Packet Data Protocol（Part 3） |
| **Confirmed / Unconfirmed** | 确认 / 非确认数据 |
| **Short Data** | 短数据（状态/原始/已定义等） |
| **SFID / MFID** | 标准特性集 ID / 厂商特性集 ID |
| **FLCO** | 特性集内的空中功能码 |
| **Late Entry** | 迟后进入（补充业务） |
| **TSCC / TSCCAS** | 集群控制信道 / 交替控制时隙类能力 |

### 文档代号

| 代号 | 是什么 |
|------|--------|
| **TR 102 398** | 系统设计导读（不是规范） |
| **TS 102 361-1…4** | 空口 / 语音 / 数据 / 集群 四部规范 |

## D. 30 秒自测

1. 一个时隙多长？→ **30 ms**  
2. 一个 TDMA frame？→ **两个时隙 = 60 ms**  
3. 突发里多少 bit 内容？→ **264 bit**（约 27,5 ms）  
4. 语音超帧？→ **A–F，360 ms**  
5. 2,5 ms 在出站常干什么？→ **CACH**  
6. 想查 PDU/状态机去哪本？→ **Part 1**；语音过程 → **Part 2**；PDP → **Part 3**；集群 → **Part 4**
