## 1. Tier III 控制信道概念

引用：clause **4–6**（系统模型、随机接入、登记、呼叫）。

| 概念 | 含义（学习口径） | 条款提示 |
|------|------------------|----------|
| **TSCC** | Trunked Station Control Channel，集群控制信道 | 5.3 / 6.x |
| **Dedicated / Non-Dedicated TSCC** | 专用控制 vs 与业务共享形态 | 5.3.1–5.3.2 |
| **TSCCAS** | 交替控制时隙类能力（Aloha 中有标志） | 6.1.1.3；C_ALOHA |
| **Payload channel** | 业务（语音/数据）信道；由 Channel Grant 指定 | 7.1.1.1.1 |
| **Random access** | MS 在 TSCC 入站用 C_RAND 等争用接入 | 6.2；7.1.1.2.1 |
| **Registration** | 记录 MS 所在区域/站点；可由 Aloha/CACH 的 Reg 位要求 | 6.4 |
| **Aloha (C_ALOHA)** | 出站管理退避、Mask、Service Function、是否要求登记 | 7.1.1.1.4 |
| **Ahoy (C_AHOY)** | 出站点名/查询，要求 MS 响应 | 7.1.1.1.6 |
| **Channel Grant** | 把呼叫转到指定物理/逻辑业务信道 | 7.1.1.1.1 |
| **UDT on control** | 控制信道短数据/系统数据上下行 | 6.6.4；7.1.1.1.8 / 7.1.1.2.4 |
| **RC** | 反向信道：功率控制、停止发射等（4-bit Command） | 6.4.14；Part 1 RC PDU |

```text
典型语音建立（极简）：
  MS --C_RAND--> TSCC
  TSCC --C_ACKD/C_AHOY/...--> MS（可达性/排队等）
  TSCC --C_GRANT (×重复)--> 主被叫  （Logical Physical Channel + TDMA slot）
  MS/对端 --> Payload channel 通话
```

Channel Grant **不要求确认**，故常重复发送（clause 4 叙述性 MSC）。

## 3. Channel Grant 字段（代表表）

| PF | 1 | | |
| CSBKO | 6 | `110000` | |
| FID | 8 | `00000000` | |
| Logical Physical Channel Number | 12 | 业务信道或 `0xFFF`=绝对参数附块 | |
| Logical Channel Number | 1 | `0` TDMA ch1；`1` ch2 | |
| Reserved | 1 | `0` | |
| Emergency | 1 | `1`=紧急 | |
| Offset | 1 | `0` aligned；`1` offset timing | |
| Target Address | 24 | 被叫个号/网关 | |
| Source Address | 24 | 主叫/网关 | |

### 3.2 TV_GRANT — Talkgroup Voice（Table 7.11）CSBKO=`110001`

| IE | Len | 含义 |
|----|-----|------|
| LB / PF / CSBKO=`110001` / FID | 1+1+6+8 | |
| Logical Physical Channel Number | 12 | 同上 |
| Logical Channel Number | 1 | ch1/ch2 |

| Emergency | 1 | |

### 3.3 其余 Grant 变体 → 详表

PV_GRANT_DX / BTV / PD / PD_GRANT_DX / TD（含 SI/MI）的 **逐字段布局、CSBKO、差异对照、CG_AP / P_GRANT**：见 [`ReasonCode与Grant变体.md`](./ReasonCode与Grant变体.md) §10–§13。

要点：DX 用 **Call Direction** 且业务信道总是 offset timing；数据 Grant 用 **HI_RATE**（DX 数据固定单时隙）；组呼用 **Late_Entry**；信道号 `0xFFF` → 绝对频率附块 CG_AP。

## 4. C_ALOHA（Table 7.19）CSBKO=`011001`

随机接入与站点能力广播；MS 用 Mask / Service Function / Backoff / NRand_Wait 选隙。

| IE | Len | 含义 |
|----|-----|------|
| LB / PF | 1+1 | LB=`1` |
| CSBKO / FID | 6+8 | `011001` / SFID |
| Reserved | 1 | `0` |
| TSCCAS | 1 | 本 TSCC 是否正支持 TSCCAS |
| Site Timeslot Synchronization | 1 | 站点 TSCC 与业务信道是否时隙同步 |
| Version | 3 | 本 Part 4 文档版本控制 |
| Offset | 1 | TSCC aligned/offset |
| Active_Connection | 1 | TS 是否连网 |
| Mask | 5 | 地址掩码（细分争用人口） |
| Service Function | 2 | 允许的业务功能类 |
| NRand_Wait | 4 | 随机等待参数 |
| Reg | 1 | **`1`=要求 MS 登记后才可活跃** |
| Backoff | 4 | 退避号 |
| System Identity Code | 16 | |
| MS Address | 24 | 可指向特定 MS（Mask=24 时仅该台） |

Reg 位亦出现在 CACH / C_BCAST；与 C_ALOHA 应一致（clause **6.4**）。

## 6. C_AHOY（Table 7.22）CSBKO=`011100`

|----|-----|----------|
| LB / PF / CSBKO / FID | 1+1+6+8 | LB=`1` |
| Service_Options_Mirror | 7 | 与业务选项镜像相关 |

| Service_Kind | 4 | 服务种类 |
| 地址场 | 24+24 | 目标 / 附加信息 |

## 9. 登记与编址（要点）

引用：clause **6.4**；C_SYScode / Registration Record。

| 主题 | 要点 |
|------|------|
| 为何登记 | 宽区域网定位 MS；单站也可用于判断是否活跃 |
| Reg=0 | MS **不应**主动寻求登记 |
| Reg=1 | 须登记后才在该 TSCC 上活跃 |
| Denied Registration List | 拒绝登记区域缓存与老化 |
| Mass Registration | C_BCAST 公告触发大规模重登记 |
| 地址 | 24-bit MS / Talkgroup / Gateway 标识；全呼 ALLMSID* 见 Annex A；**拨号** → [`AnnexE拨号.md`](./AnnexE拨号.md)；**原生互操作** → [`AnnexG本地编址.md`](./AnnexG本地编址.md) |
| System Identity Code | 16-bit，出现在 Aloha/BCAST 等 |

登记可用随机接入（C_RAND + Service_Kind=登记类）或由 C_AHOY 驱动（过程表 6.4.x）。

## 11. Reverse Channel（RC）— Tier III

引用：Part 1 Table **9.6**（RC Info Payload 4 bit）；Part 4 Table **6.32** / clause **6.4.14**。

| RC Command | 含义 |
|------------|------|
| 0000 | 功率 +1 步 |
| 0001 | 功率 −1 步 |
| 0010 | 功率最高 |
| 0011 | 功率最低 |
| 0100 | **Cease transmission command**（强制停发） |
| 0101 | Cease transmission request |
| 0110–1111 | 保留 |

用途：闭环功率；紧急抢占/呼叫时长到期时让发射台停发，再 P_Clear 清呼叫。步长厂商相关。发射中的 MS 须按 clause **6.4.15.2** 监视出站 RC。

Part 2 另有 Tier II RC Command IE（7.2.20）；实现时区分场景。
