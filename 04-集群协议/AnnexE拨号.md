## 0. 拨号在系统里干什么

目标：带 CCITT 键盘（`0–9` `*` `#`）的 MS，把**用户域拨号串**映射到空口 **24-bit 地址** + 业务/优先级等标志，再发起随机接入等。

| 用户域 | 空口域 |
|--------|--------|
| 变长十进制拨号串（可含 `*` `#`） | 定长 24-bit 地址；呼叫修饰 → PDU 内优先级/广播等比特 |
| 目的：其他 MS、组、网关（PABX/PSTN 等）、特殊标识 | 见 E.2.1；网关数值见 **A.4** |

```text
用户拨号 (+ 可选 *修饰符*)
  → MS 应用：可逆算法映射
  → 24-bit Target / Gateway + Service 选项
  → C_RAND 等（线网号码常再经 UDT 上送）
```

用户输入两步（E.1）：① 拨数字；② **发起呼叫**（`#` / PTT / 厂商方式）。未识别串应拒绝并提示。

可限制拨号最小/最大长度（防误拨一位等）。部分业务仅 Tier III 中继适用。

## 1. 空口地址结构（E.3.1.1 / Tables E.1–E.2）

24-bit AI 地址拆成：

| 段 | 别名 | 比特 | 说明 |
|----|------|------|------|
| Network Area Identity | **NAI** | 9 | 网络区域 |
| Short Subscriber / Group Identity | **SSI** / **SGI** | 15 | 个号 / 组号 |

| 保留 / 范围 | 内容 | 条款 |
|-------------|------|------|
| `ADRNULL` = 0 | 保留（无实体） | E.3.1.1 NOTE；A.4 |
| 个呼 `1…0x0FFFFF` | **MPT1327 迁移**保留 | E.3.1.1 |
| NAI `0…31` | MPT1327 迁移 | Table E.2 NOTE 1 |
| NAI `32…511` | DMR 可用区（见 NP） | Table E.2 |
| SSI/SGI = 0 | 无效 | Table E.2 NOTE 2 |
| DMR 个台 `0x100000…0xFFFFFF` | DMR 个体地址空间 | E.3.1.1 |

**NP（Network Prefix）**（E.3.1.2）：

- `NP = NAI + 296`；许可 **NP = 328…806**（479 个）
- NAI `32…510` → 普通 MS Number Prefix；**NAI = 511** → 特殊网关
- NP `200…327`：MPT1327 迁移保留

## 2. 个体号码 ↔ AI 地址（E.3.1.3）

### 2.1 SSI

| SSI | 含义 |
|-----|------|
| 0 | NULL，无效 |
| 1…32 200 | 普通 Short Subscriber Identity |
| 32 201…32 767 | **特殊** Short Subscriber Identity（调度台等落此区） |

### 2.2 车队个体拨号形态

完整 **8 位**：`NP(3) ‖ FIN(2) ‖ IN(3)`  
缩短 **5 位**：`FIN ‖ IN`（本网 NP 预置）  
缩短 **3 位**：`IN`（本车队 FIN 预置）

| 字段 | 范围 | 备注 |
|------|------|------|
| FIN | 20…89 | 每 NP 最多 70 个个体车队 |
| IN（FIN 20…41） | 200…899 | 每 FIN 700 个号 |
| IN（FIN 42…89） | 200…549 | 每 FIN 350 个号 |

### 2.3 转换算法（E.3.1.3.3）

```text
FIN 20…41:
  AI = (NP − 328)×0x8000 + (FIN − 20)×700 + (IN − 200) + 0x100001

FIN 42…89:
  AI = (NP − 328)×0x8000 + (FIN − 42)×350 + (IN − 200) + 0x103C29
```

（`× 8 000₁₆` 即 ×0x8000；加数按原文十六进制写法。）

## 3. 组号码 ↔ CAI 地址（E.3.1.4）

### 3.1 SGI

| SGI | 含义 |
|-----|------|
| 0 | 保留 |
| 1…7 000 | 组身份 |
| 32 767 | **全车队 All Call**（按车队登记站点路由的 TG 全呼；异于 Site/Location/Network 三类 ALLMSID*） |
| 其余 | 保留 |

### 3.2 车队组拨号形态

完整 **8 位**：`NP(3) ‖ FGN(2) ‖ GN(3)`  
缩短 **5 / 3 位**：同个体（FGN/GN）

| 字段 | 范围 | 备注 |
|------|------|------|
| FGN | 20…89 | 与 FIN 对应，每 NP 70 组车队 |
| GN | 900…999 | 每组车队 100 个 GN → 每 NP 共 **7 000** 组号 |

### 3.3 转换算法（E.3.1.4.3）

```text
ID = (NP − 328)×0x8000 + (FGN − 20)×100 + (GN − 900) + 0x100001
```

## 4. 调度台 Dispatcher（E.3.2 / Table E.3 · E.3.3）

- **6 位**串：`NP ‖ 10n`（n = 0…9），走**个体地址空间**
- 公式：`AI = (NP − 328)×0x8000 + 32 481 + n + 0x100000`
- 本网 NP 预置时，可只拨 **3 位** `10n`

| 拨号 | ID（Table E.3） |
|------|-----------------|
| NP‖100 … NP‖109 | `(NP−328)×0x8000 + 32481…32490 + 0x100000` |

**短调度拨号**（E.3.3）：单键 `0…9` → MS 内最多 10 个预置个体地址；无对应则提示不可建呼。调度台可进入 callback 排队态。

## 5. 全呼 All Call ↔ ALLMSID*（E.3.4 / Tables E.4–E.7）

三类全呼占**组 ID 空间**；空口 ID 与 Annex **A.4** 一致：

| AI 地址 | 别名 | 范围 | 条款 |
|---------|------|------|------|
| `FFFFFD₁₆` | **ALLMSIDL** | 本站全部 MS（Site） | Table E.4 |
| `FFFFFE₁₆` | **ALLMSIDZ** | 系统内**部分站点**子集 | Table E.4 |
| `FFFFFF₁₆` | **ALLMSID** | 全网全部站点 | Table E.4 |

业务形态：按广播业务对待（E.3.0；正文 **6.6.1.7**）。

### 5.1 本站 Local（Table E.5）→ ALLMSIDL

| 拨号串 | 含义 |
|--------|------|
| `*1961` | High Priority All Call |
| `*1962` | Emergency All Call |
| `*1963` | Reserved |
| `*1964` | Emergency Data All Call |
| `*1965` | UDT Short Data All Call |
| `*1967` | Normal All Call |

### 5.2 站点子集（Table E.6）→ ALLMSIDZ

| 拨号串 | 含义 |
|--------|------|
| `*1971` … `*1975` / `*1977` | 同上业务类型（197x） |

### 5.3 全网（Table E.7）→ ALLMSID

| 拨号串 | 含义 |
|--------|------|
| `*1981` … `*1985` / `*1987` | 同上业务类型（198x） |

规律：`*19{6\|7\|8}{1\|2\|3\|4\|5\|7}` → 本站 / 子集 / 全网 × 优先级·紧急·数据·短数据·普通。

## 6. 呼叫修饰符 Call Modifiers（E.3.5 / Table E.8）

语法：`* <修饰码> * 目的地址 #`  
双态功能：置位用 `*…#`，清除用 `#…#`。可组合**不冲突**的修饰符（如不可 `*9` 与 `*8` 同拨）。

| 拨号串 | 含义 |
|--------|------|
| `*11*nn…#` | 广播呼叫 Broadcast |
| `*8*nn…#` | 高优先级（文档称 PRIORTY_SV 类） |
| `*8*1*nn…#` … `*8*3*nn…#` | 优先级 1…3 |
| `*9*nn…#` | 紧急 Emergency |
| `*12*nn…#` | MS–MS 全双工 |
| `*0ss*nn…#` | 状态投递：状态 ss → MS nn… |
| `*41*nn…#` | 本机呼叫转移到 nn… |
| `#41#` | 取消转移 |
| `*2*nn…*dddd#` | UDT 短数据 → nn…，数据 d |
| `*7*i…*i…*i…*i…#` | 点分 IP 目的（可省略前导零） |

示例（E.3.5）：

| 拨号 | 含义 |
|------|------|
| `*8*234#` | 个体高优先级 → 234 |
| `*8*1*234#` | 个体优先级 1 → 234 |
| `*18*934#` | 高优先级**广播** → 组 934（`*11` 与 `*8` 组合写法） |
| `*18*1*934#` | 优先级 1 广播 → 组 934 |
| `*057*234#` | 状态 57 → 234 |

未选优先级时默认 **Normal (low)**（E.3.0）。加密开关见下节 NOTE：本 TS **不定义**加密。

## 7. 功能拨号串（E.3.6）

| 串 | 功能 |
|----|------|
| `*#` | 放弃/取消呼叫（TSCC：未发随机接入则放弃；已发则取消；业务信道：取消呼叫） |
| `*47#` | 显示本机号码 |
| `*48#` / `#48#` | 置/取消 callback（仅语音） |
| `#` 或 PTT | 振铃时接听 |
| `#0#` | 取消 callback 请求 |
| `*46#` | 加密开关切换（NOTE：加密未在本 TS 定义） |
| `*461#` / `*462#` | 关 / 开加密（同上 NOTE） |

## 8. 线网目的：PSTN / PABX（E.3.7 / Table E.9）

| 起始拨号 | 含义 |
|----------|------|
| `01` + 至少 4 位，最长合计约 44 位量级 | 拨 **PSTN** |
| `02` + 同上 | 拨 **PABX** |
| `1000…8999`（4 位缩位） | 保留 |
| `9600…9699`（4 位） | 保留 |

行为要点（E.3.7.1.1–2）：

- 总长 ≥ 6 且前缀 `01` → Voice Call 随机接入，目的网关 **PSTNI**；号码经 **UDT** 上送（含前导 `0`）。例：拨 `0112345` → UDT 上传 `0112345`
- 前缀 `02` → 网关 **PABXI**；例：`021234` → UDT 上传 `021234`
- SIP 实现时 PSTN/PABX 可不区分（E.3.7.1.0 NOTE）

网关 24-bit 值（Annex **A.4** Table A.8，交叉引用）：

| ID | 别名 | 用途 |
|----|------|------|
| `FFFEC0₁₆` | **PSTNI** | PSTN（aligned） |
| `FFFEC1₁₆` | **PABXI** | PABX（aligned） |
| `FFFED0₁₆` / `FFFED1₁₆` | PSTNDI / PABXDI | offset timing 变体 |

过程细节（C_AHOY 拉号、Proxy 等）：正文 **6.6.x**，不在 Annex E 展开。

IP 目的另见修饰符 `*7*…#`（E.3.5）→ 网关 **IPI**（A.4）。

## 9. 与 MS 寻址 / 网关 / All_MS 的关系（一览）

```text
用户拨号串
  ├─ 3/5/8 位车队个号 ──算法──► 24-bit 个体 MS 地址（NAI‖SSI）
  ├─ 3/5/8 位车队组号 ──算法──► 24-bit 组地址（NAI‖SGI）
  ├─ 调度 10n / 短键 0–9 ─────► 个体空间特殊 SSI 区
  ├─ *196x / *197x / *198x ───► ALLMSIDL / ALLMSIDZ / ALLMSID
  ├─ *11* / *8* / *9* … ──────► 同目的地址 + 广播/优先级/紧急等
  └─ 01… / 02… ───────────────► Target=PSTNI/PABXI + UDT 号码
```

| 概念 | Annex E | 数值出处 |
|------|---------|----------|
| 个体 / 组映射 | E.3.1.3–4 | 算法见上 |
| All_MS 三类 | E.3.4 = ALLMSIDL/Z/ID | Table E.4 ≡ A.4 |
| 车队内全呼 SGI=32767 | E.3.1.4.1 | 组空间特殊值 |
| PSTN/PABX 网关 | E.3.7 行为 | ID 在 **A.4** |
| 互操作须能对全合法原生地址个性化/呼叫 | — | [`AnnexG本地编址.md`](./AnnexG本地编址.md)（Annex **G**） |

E.1 称若按本附件算法，个体/组用户界面可用七位十进制个性化；**完整车队形态**以 E.3.1 的 8 位 `NP‖Fxx‖xxx` 为准（缩短 5/3 位依赖预置 NP/FIN）。
