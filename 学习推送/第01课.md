> DMR 深入学习 · 阶段 A 通信地基  
> 适合：通信基础弱、但已经在 DMR 方向工作的人  
> 阅读量：约 20–25 分钟 · 不要求会推公式

## 0. 为什么从这里开始

你可能已经听过「频点、时隙、色码、组呼、中继、集群」这些词，但它们如果不落在**无线电在干什么**这件事上，就会变成一串要背的黑话。

本课目标只有一个：让你能用自己的话讲清——

> 一台电台怎么把「人说的话」变成「空中能传的东西」，对方又怎么变回来；中间大家必须事先约定什么。

后面所有 DMR 细节（12.5 kHz、2 时隙 TDMA、Part 1 突发结构）都是在给这件事加规则、加效率、加业务。

---

## 1. 一张总图（先装进脑子）

```text
  说话的人                         听的人
     │                               ▲
     ▼                               │
 麦克风 → 音频处理 → 【调制到射频】 → 天线
                                      │
                              空中传播（衰减、遮挡、干扰）
                                      │
                                   天线 → 【解调】 → 音频处理 → 喇叭
```

拆开看：

1. **音频侧**：声音是连续变化的气压；话筒把它变成电信号。  
2. **射频侧**：要把信息「搬」到很高的频率上，才能用较短的天线、在约定频段里传。这个「搬上去」叫**调制**；对方「搬下来」叫**解调**。  
3. **空中段**：能量会随距离散开，会被墙/山挡住，还会撞上别人的信号。

DMR 是**数字**系统：在「音频 → 射频」中间，多了一步「把声音压成比特流（声码器）再按协议打包」。但**空中仍然是电磁波**，物理约束没变。

## 2. 五个地基词（务必建立直觉）

### 2.1 频率（frequency）

电磁波每秒振动多少次，单位 **Hz / kHz / MHz / GHz**。  
对你工作的意义：选「频点」就是选你在频谱尺子上的位置。

类比：频率像电视频道号——大家必须拧到同一个频道，才能对话。

### 2.2 波长（wavelength）

波长 ≈ 光速 / 频率。频率越高，波长越短，天线可以做得更短，但传播特性也变（绕射、穿墙能力等会不同）。  
本课不深挖传播模型，只要知道：**频段选择不是随便挑好看的数字**。

### 2.3 信道（channel）

监管和规划里划出的「通话车道」。常见说法：

- **信道间隔（channel spacing）**：相邻信道中心频率差多少。陆地移动里常见 **12.5 kHz**（也有 25 kHz 遗留等）。  
- **占用带宽**：你的发射实际「铺」多宽。太宽会溅到邻道。

DMR 标准设计目标之一：在**现有 12.5 kHz 规划**里数字化，并尽量做到 **6.25 kHz 等效**效率（后面专课）。

### 2.4 载波（carrier）

还没加载你的信息时，电台发出的「纯净高频振荡」。调制 = 让载波的某种属性随信息变化。  
你听到的「沙沙声 / 静噪打开」等现象，很多都和「有没有足够强的载波/信号」有关。

### 2.5 干扰（interference）与噪声（noise）

| 类型 | 直觉 | 工作中常见样子 |
|------|------|----------------|
| 噪声 | 系统自己的「底噪」+ 环境热噪声等 | 远处声音发糊、静噪门限要调 |
| 同频干扰 | 别人也在同一频点说话 | 突然进来别的通话、拍频声 |
| 邻道干扰 | 旁边车道功率太强「糊边」 | 近距离大功率电台靠近时异常 |
| 互调等 | 多信号在非线性器件里「混出」新频率 | 基站密集区偶发怪干扰 |

**色码（Colour Code）** 解决不了物理干扰本身，但能帮接收机判断「这是不是我这套系统的合法信号」，减少误听。细节后面课讲。

## 3. 半双工：对讲机为什么要按 PTT

手机可以接近同时说和听（全双工思路）。  
多数专业对讲是**半双工**：同一时刻你主要在发或在收，按住 PTT（Push-To-Talk）才发射。

含义：

- 空中资源被「谁在说」占用；需要纪律（通联用语、信道忙闲）。  
- 数字系统用时隙后，可以在同一载波上更精细地安排谁发谁收（TDMA），但**用户体验仍常是按讲**。

中继台的存在：把你的弱信号收下来，再用另一频率（或另一时隙安排）大力转发出去，拉大覆盖。这就是「上行 / 下行」「入站 / 出站」直觉的来源——DMR Part 1 里大量时序图都建立在这上面。

## 4. 模拟 vs 数字：差在哪一层

| | 模拟对讲（直觉） | 数字对讲 / DMR |
|--|------------------|----------------|
| 声音怎么走 | 连续波形直接调上去 | 先编码成比特，再按帧/突发发送 |
| 变远时 | 往往逐渐变吵、变糊 | 常表现为「还能听 → 突然断」或错误比特增多 |
| 业务 | 主要是话音 | 话音 + 短数据/IP 数据等（协议规定） |
| 效率 | 一条模拟信道 ≈ 一路话 | DMR 用 2 时隙，可在 12.5 kHz 上支撑两路（专业层） |

你作为 DMR 工作人员，日常排障时要分清：

- **射频/覆盖问题**（收不到、RSSI 差、干扰）  
- **协议/参数问题**（色码不对、时隙不对、地址/组配置错、未登记）  
- **声码器/音频问题**（数字链路在，但音质配置差）

本课先建立「空中有物理层」的意识，避免一出问题就只改写频软件里的某个 ID。

## 5. 和 DMR 工作现场的对照表

把黑话翻译回今天的词：

| 现场说法 | 落在本课概念 |
|----------|----------------|
| 写频 / 频点 | 选载波频率 + 信道规划 |
| 信道间隔 12.5K | 车道有多宽、邻道离多远 |
| 时隙 1 / 时隙 2 | 同一载波上按时间再切（下几课 TDMA） |
| 色码 CC | 系统识别，降低误听 |
| 组呼 / 个呼 | 地址：叫一组人还是一个人 |
| 中继 / 直通 | 要不要基站转发 |
| 集群 / 常规 | 有没有控制器自动分配信道（Tier III vs II） |

建议你现在就养成习惯：听到一个术语，问自己两句——

1. 它改的是**物理车道**还是**谁有权说话/听**？  
2. 出问题时空中是**没信号**，还是**有信号但协议对不上**？

## 6. 一个「最小通联」故事（串起来）

假设仓库里两台 DMR 手台直通：

1. 双方写了**同一频点、同一色码**，都在时隙 1。  
2. A 按 PTT：电台把语音编码成比特，打成突发，在时隙 1 发射。  
3. 空中：电磁波传向 B；若距离远或有铁皮库遮挡，能量变弱。  
4. B 收到足够强的、色码匹配的突发，解出语音。  
5. 若这时另一套系统同频但色码不同，B 可以不把它当合法语音（仍可能受干扰影响灵敏度）。

集群场景会再多「先登记、控制器 Grant 信道」——那是后面阶段 E 的课；物理地基仍是今天这些。
