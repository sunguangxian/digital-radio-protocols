## 0. 开课前：加餐四句话复习（带新例子）

若你已读过 `学习推送/加餐_频率带宽与调制解调.md`，下面四句应能脱口而出。本课**不照抄加餐与第 2、3 课**，换成「频谱仪上看一眼 DMR 载波」的场景再钉一遍：

| # | 一句话 | 本课用的新例子 |
|---|--------|----------------|
| 1 | **频率** = 信号抖得有多快 | 写频填 `460.125 MHz`：这是**中心频点**。4FSK 并不是换一个全新频点，而是让实际瞬时频率在中心附近**左右小幅跳动**（大约 ±0.648 kHz 与 ±1.944 kHz 四档） |
| 2 | **带宽** = 频谱尺子上占多宽的一条带子 | 规划车道仍是 **12.5 kHz**。能量会在中心左右铺开一小段；成型滤波（根升余弦一类）是为了让这条带子**别溅到邻道**。数字调制照样占带宽，不是「变成一条无限细的线」 |
| 3 | **调制** = 把信息装进适合发射的高频波 | 本课主角：把每 **2 个比特**译成**四种规定频偏之一**，让载波按节拍「跳档」。名字叫 **4FSK**（四级频移键控） |
| 4 | **解调** = 从收到的高频波把信息卸下来 | 对方测每个符号时间里载波偏到哪一档，再译回两比特。偏错档 = 比特错 → 靠 FEC 扛一阵；扛不住就数字悬崖 |

再补一句和本课主线钉死的对照：

- **模拟 FM**：频偏大致**跟着话音连续变**（像拧旋钮，中间有无数中间值）。  
- **DMR 4FSK**：频偏只允许落在**有限几档**上（像电梯只停四个楼层），每一档代表固定的两比特。

若这四句仍糊：先打开加餐文读「调制 / 解调」两段，再回本课。本课主线是：**4FSK 在干什么、关键数字怎么记、和模拟 FM / 声码器各管哪一段、现场能对上什么现象**。

## 1. 为什么本课重要（动机）

现场与文档里你会反复撞到这些词：

- 「DMR 用的是 4FSK。」  
- 「符号率 4800，每符号 2 bit。」  
- 「恒包络，功放可以像模拟 FM 那样用。」  
- 「频偏 ±648 / ±1944 Hz。」  
- 频谱仪上：看起来像「窄带数字载波」，邻道要干净。

若只背「4FSK = 数字调制」五个字，后面读 ETSI Part1 的 clause 10、看仪器、跟射频/基带同事对话，都会卡在同一处：

> **比特到底怎样变成空中的「抖法」？**

本课目标是让你能自己讲清八件事（仍不推公式）：

1. FSK / 4FSK 名字里每个字母在说什么；  
2. 为什么是「4」档，而不是 2 档或 16 档；  
3. **符号（symbol）** 与 **比特** 的差别，以及为何是 **4800 symb/s → 9600 bit/s**；  
4. 四档频偏 **±0.648 kHz / ±1.944 kHz** 怎么记；  
5. **恒包络**对发射机意味着什么（和现场功放、功耗的直觉）；  
6. 成型滤波在「别干扰邻道」里扮演什么角色（知道存在即可）；  
7. 4FSK 与**声码器**、与**模拟 FM**、与后面的 **TDMA 30 ms 时隙**各管哪一段；  
8. 常见误区：把「12.5 kHz」当成频偏、把「6.25 kHz 等效」当成真切成两半频率等。

第 5 课才会专讲 FDMA/TDMA；本课到「比特如何骑上载波」为止。

## 2. 总图 / 故事：比特怎样「拧」载波

先把整课装进一张故事图。接上第 3 课：声音已经变成（并保护好的）比特流，现在轮到**物理层装车**：

```text
声码器输出的语音比特 + 信令/同步等
              │
              ▼
     按 2 bit 一捆（dibit / 双比特）
              │
              ▼
   ┌──────────────────────────────┐
   │  查表：这一捆对应哪一档频偏？ │
   │  01 → 偏高很多（约 +1.944 kHz）│
   │  00 → 偏高一点（约 +0.648 kHz）│
   │  10 → 偏低一点（约 −0.648 kHz）│
   │  11 → 偏低很多（约 −1.944 kHz）│
   └──────────────────────────────┘
              │
              ▼
     成型滤波（让跳档别太「方」、频谱别太脏）
              │
              ▼
     频率调制器：真正去拧 ~460.125 MHz 载波
              │
              ▼
           天线 → 空中（仍落在约 12.5 kHz 车道里）
              │
              ▼
     对方：估频偏 → 判是哪一档 → 还原两比特
              │
              ▼
     再交给纠错、解帧、声码器……
```

读图顺序（建议朗读一遍）：

1. **4FSK 不负责「好听」**：好听主要靠声码器 + 纠错；4FSK 负责「比特能否可靠变成射频花样」。  
2. **一次跳档 = 一个符号**：每个符号携带 **2 bit**，所以同样「跳多少次」，比特吞吐是 2FSK 的约两倍（在约定条件下）。  
3. **跳的是频率，不是音量**：幅度大致稳住（恒包络）——这点对功放很友好。  
4. **收端是「认档」**：像看电梯停在哪一层，而不是听模拟 FM 那种连续滑音。

一句话记总图：

> **4FSK = 用四种约定好的「载波抖快一点 / 抖慢一点」档位，来编码两比特一捆的数字信息。**

再补一个仓库比方（专门给通信基础弱的同事）：

> 模拟 FM 像把话筒接到「无连续调音高的哨子」上，音高随声音滑来滑去。  
> 4FSK 像规定哨子只能吹 **低低、低、高、高高** 四个音，每吹一个音维持一拍，两个人事先约定每个音代表哪两个比特。  
> 听哨的人不必听懂歌词，只要把音高序列翻译回比特；歌词（话音）是在更早的声码器阶段就已经打成比特说明书了。

## 3. 白话术语表（本课必会）

| 术语 | 白话 | 现场你怎么碰上 |
|------|------|----------------|
| **载波** | 约定频点上那根「纯净高频抖」 | 写频里的中心频率 |
| **调制** | 把信息装进载波 | 发射链路后半段 |
| **解调** | 从载波卸下信息 | 接收机前端之后 |
| **FSK** | 频移键控：用**频率跳到哪**表示数字 | 数字通信基础词 |
| **2FSK / BFSK** | 只分两档频率 → 通常 1 符号 1 bit | 教材入门例子 |
| **4FSK** | 四档频率 → 通常 1 符号 2 bit | **DMR 空口物理层** |
| **符号（symbol）** | 一次「选档并保持一小段时间」 | 符号率、眼图、定时 |
| **dibit** | 两个比特捆成一组（00/01/10/11） | 规范里的映射表 |
| **符号率** | 每秒送多少个符号 | DMR：**4800 symb/s** |
| **比特率（毛）** | 符号率 × 每符号比特数 | 约 **9600 bit/s**（未扣开销前的数量级） |
| **频偏 / 偏差** | 相对中心频率偏了多少 Hz | ±648 / ±1944 Hz** |
| **偏差指数 h** | 规范用来定义「偏多远」的参数 | DMR：**h = 0.27**（记结论即可） |
| **恒包络** | 幅度几乎不变，信息主要在频率里 | 功放可更像模拟 FM 那样用 |
| **成型滤波 / 根升余弦（RRC）** | 把「方波式跳档」抹圆润，压旁瓣 | 邻道干扰、杂散测试 |
| **L1 / 物理层** | 管比特如何变成射频波形 | Part1 clause 10 一带 |

不必一次背公式；先保证**能用自己的话解释表格里每一行**。

## 4. 从 2FSK 到 4FSK：为什么是「四级」

### 4.1 先看最简单的 2FSK（打地基）

约定：

| 比特 | 载波怎么做（示意） |
|------|---------------------|
| 0 | 相对中心，往低频偏一档 |
| 1 | 相对中心，往高频偏一档 |

发送端按节拍切换这两档；接收端判断「现在偏高还是偏低」。  
这就是 **Frequency Shift Keying**：用频率移动来键控（开关式地选择）信息。

生活比方：用两种不同音高的哨音表示 0/1——听的人只关心「高还是低」，不太关心哨声音量忽大忽小。

### 4.2 升级到 4FSK：一次带两比特

若每次只传 1 bit，要达到相近的比特吞吐，你就得跳得更勤，或占更宽的频谱资源。  
DMR 的选择是：

> **每次选四档之一 → 每档天然对应 2 bit。**

于是：

\[
4800\ \text{符号/秒} \times 2\ \text{bit/符号} = 9600\ \text{bit/秒}
\]

（这是物理层「毛」速率的数量级直觉；真正语音净荷还要扣同步、纠错、信令、时隙结构等，第 3 课已讲过声码器侧的压缩。）

### 4.3 为什么不是 8FSK、16FSK？

档越多，每符号比特越多，但对噪声更敏感：档位挤在一起，更容易判错。  
DMR 要在既有 **12.5 kHz** 窄带里、用相对简单的射频实现、还要兼顾从模拟迁数字——**4 档是工程折中**，不是数学上的「越多越好」。

## 5. DMR 里的关键数字（建议能默写）

下面数字以资料库口径为准（对齐 ETSI TS 102 361-1 原则摘要，见 `01-空中接口/跳过项原则说明.md`）：

### 5.1 符号与速率

| 项目 | 数值 | 怎么记 |
|------|------|--------|
| 符号率 | **4800 symb/s** | 每秒跳约 4800 次档 |
| 每符号比特 | **2 bit（dibit）** | 四档 ↔ 两比特 |
| 符号周期 | 约 **208.33 μs**（1/4800 s） | 每一档大约维持这么久 |
| RF 载波带宽规划 | **12.5 kHz** | 车道宽度（第 2 课） |

### 5.2 四档频偏映射（Table 10.3 原则）

| Bit1 Bit0 | 符号习惯叫法 | 相对中心的频偏（约） |
|-----------|--------------|----------------------|
| **0 1** | +3 | **+1.944 kHz** |
| **0 0** | +1 | **+0.648 kHz** |
| **1 0** | −1 | **−0.648 kHz** |
| **1 1** | −3 | **−1.944 kHz** |

记忆口诀（现场够用）：

> **两档「小偏」±0.648，两档「大偏」±1.944；最大大约 1.944 kHz。**

注意：网上个别科普/仿真文的映射表可能与 ETSI 不一致（符号编号或 bit 顺序对调）。**岗位上以 ETSI / 资料库摘要为准**，不要混用两套表去对仪表。

### 5.3 偏差指数 h = 0.27

规范用 \(D = 3h/(2T)\) 这类关系把「h」和最大频偏钉在一起；你只要记住结论：

> **h = 0.27 → 最大符号频偏约 1.944 kHz。**

考试式提问「h 是多少」能答 0.27；推导留给以后需要做仿真的同事。

### 5.4 恒包络 + 滤波链（直觉级）

规范侧的故事可以记成三步：

1. dibit → 映射成四电平；  
2. 经过**根升余弦类**成型，避免频谱太「炸」；  
3. 再去调频，得到近似**恒包络**的 4FSK 波形。

恒包络的现场好处（白话）：

- 发射机对「幅度必须极度线性」的压力相对小一些；  
- 功放可以工作在更高效的区域——这也是当年便于从模拟 FM 硬件思路迁移的原因之一（厂商培训材料常强调这点）。

### 5.5 和突发长度的一瞥（为后面课时埋伏笔）

正常突发大约 **132 个符号**（中心左右各 66），按 dibit 串行调制。  
你现在不必背 Annex E 的符号扫描表；只要建立画面：

> **一大串四档跳变 = 一个突发里的比特被送上天。**

时隙 **30 ms**、两时隙 TDMA 等，第 5 课与阶段 C 再展开。

## 6. 完整例子：跟一次「两比特上车」

假设中心频率写的是 **460.125000 MHz**（仅作故事数字），此时要发送 dibit `01`。

### 6.1 发送端

1. 上层交给物理层一串比特：`… 01 10 00 11 …`  
2. 取出 `01` → 查表 → 应对 **+3** 档 → 目标瞬时频率约  
   \(460.125\ \text{MHz} + 1.944\ \text{kHz}\)。  
3. 不是「瞬间方波切到新频率再不管滤波」，而是经成型后，频率平滑地靠近该档，并在约 **208 μs** 量级上体现该符号。  
4. 下一个 dibit `10` → 切到约 **−0.648 kHz** 那一档……如此节拍前进。

### 6.2 接收端

1. 前端把信号搬下来，估计「相对中心偏了多少」。  
2. 在抽样时刻看估计值最靠近哪一档：+1.944 / +0.648 / −0.648 / −1.944。  
3. 判成 `01`，交给后面的解交织、FEC、协议字段解析、声码器。  
4. 若噪声大，可能把 +0.648 错判成 +1.944 → 两比特错了 → FEC 尝试纠正；连续错多了，你就听到第 3 课说的**数字悬崖**。

### 6.3 和「按一次 PTT」的时间尺度对照

- **微秒～百微秒级**：符号跳动（本课）。  
- **毫秒～几十毫秒级**：突发、时隙（以后课，记住 **30 ms** 量级时隙）。  
- **秒级**：你按着 PTT 说话的时长。  

岗位沟通时分清尺度，能少很多鸡同鸭讲。

---



### 6.4 若你只能向领导汇报三句

1. DMR 空中用 **4FSK**：四种频偏代表两比特一捆。  
2. 节奏是 **每秒约 4800 次跳档**，最大偏大约 **1.9 kHz 量级**，整段仍规划在 **12.5 kHz** 信道里。  
3. 它和声码器分工明确：一个管声音压缩成比特，一个管比特变成射频跳法。


## 7. 现场对照：你在工作里会看见什么

| 现场场景 | 和 4FSK 的关系 | 你可以怎么说 |
|----------|----------------|--------------|
| 写频只填了频率/色码/时隙 | 4FSK 参数通常**写死在体制里**，用户界面很少让你改 h 或四档映射 | 「调制方式是标准规定的，不是信道列表里一项可选项。」 |
| 频谱仪看发射 | 能量集中在中心附近一小段，应落在 **12.5 kHz** 规划内；旁瓣/邻道看杂散与滤波 | 「看的是整段谱形是否干净，不是去数四根离散谱线当收音机。」 |
| 邻道干扰投诉 | 可能是功率、滤波、频偏不准、终端故障等；调制过「脏」会溅邻道 | 排查时把「频率不准」和「频谱再生/邻道抑制差」分开说 |
| 覆盖边缘听感 | 判档错误↑ → 比特误码↑ → 纠错失效 → 断续/静音 | 回到第 3 课数字悬崖，而不是先怪声码器「压缩太狠」 |
| 与射频同事对表 | 他们说 deviation、symbol rate、eye、EVM 类指标 | 你至少能接上：4800 symb/s、四档频偏、恒包络 |
| 与协议同事对表 | 他们说 SYNC、LC、CSBK、时隙 | 你清楚：那些是**比特语义**；4FSK 只是把比特送上天的货车 |
| 模拟/数字共址或迁移 | 同一 12.5 kHz 栅格上，数字用 4FSK+TDMA 挖容量 | 呼应第 2 课「6.25 kHz 等效」：效率口径，不是把载波真切成 6.25 |

**岗位一句话**：

> 我不一定会焊调制器，但我知道 DMR 空中「数字」长什么样：四档频偏按 4800 次/秒在跳，跳的是频率，幅度大致稳住，整段仍要待在 12.5 kHz 车道里。

## 7.5 若你明天要跟仪表/基带联调：问什么、不瞎问什么

**可以问、且显得你懂边界的问题：**

- 当前测的是上行还是下行？中心频率是否就是写频频点？  
- 符号率锁定是否按 4800？眼图/判决点稳不稳？  
- 频偏标定：四档是否落在约 ±0.648 / ±1.944 kHz 附近（允许实现容差）？  
- 邻道功率、占用带宽是否满足当地与设备指标？  
- 误码是在「解调后比特」测的，还是已经过 FEC 之后？

**暂时别假装很懂就乱抛的词（除非你真的在做那一层）：**

- 随口改 h、随口改映射表；  
- 把 EVM、相位噪声、晶振 ppb 和「声码器音质」直接画等号；  
- 要求对方「把 4FSK 改成 QPSK 试试」（体制级变化，不是旋钮）。

**联调口头禅（建议背）：**

> 我们先确认：载波中心对不对、符号定时在不在、四档频偏在不在窗子里、再谈协议字段和听感。


## 8. 和相邻概念划界（避免张冠李戴）

```text
嘴巴声波
   → 声码器：把「听感」压成低速比特          ← 第 3 课
   → 信道编码/组帧/SYNC/时隙安排           ← 后续课
   → 4FSK：把比特变成射频频率跳档          ← 本课
   → 天线与电波传播
   → 对方 4FSK 解调 → 纠错 → 声码器 → 喇叭
```

| 容易混的一对 | 正确边界 |
|--------------|----------|
| 声码器 vs 4FSK | 声码器管「声音↔比特」；4FSK 管「比特↔射频跳档」 |
| 模拟 FM vs 4FSK | 都动频率；前者连续跟话音，后者只停四档跟比特 |
| 12.5 kHz vs ±1.944 kHz | 12.5 kHz 是**信道间隔/车道宽**；1.944 kHz 是**最大符号频偏** |
| 6.25 kHz 等效 vs 真 6.25 信道 | 等效是**容量宣传口径**（两时隙），不是载波改到 6.25 kHz 中心间隔（第 2 课） |
| 比特率 9600 vs 你听到的音质 | 9600 是物理层毛速率量级；音质还取决于声码器、FEC、场强 |

## 8.5 加厚现场故事三则（把数字焊进经验）

### 故事 A：频谱仪前的两分钟

你和射频同事打开一台正在发射的 DMR 终端（或中继下行）。中心对准写频频点。你不会指望看见四根像音叉一样分立的谱线——实际看到的是**一团被滤波塑形后的窄带谱**。同事若说「邻道还有鼓包」，你们讨论的是掩模、功放、滤波与频偏是否超差，而不是「4FSK 是不是变成了 8FSK」。  
本课贡献：你知道谱的「心脏」里，信息靠的是**四档频偏节拍**，不是靠幅度乱晃。

### 故事 B：投诉单上的「数字一拐弯就没了」

用户从仓库深处走到货架尽头，模拟时代能嘶嘶着听，数字时代突然干净地没声。第 3 课给了「悬崖」名字；本课补机制：边缘处信噪比变差 → **判档错误变多** → FEC 救不动 → 声码器无合格比特可用。  
处理建议仍是：用可懂度/保持时间看覆盖，不要只用「模拟能嘶到的地方」当数字边界。

### 故事 C：文档里突然冒出 h = 0,27

欧洲标准常用逗号当小数点：`0,27` 就是 `0.27`。有人会误读成「零点二七以外还有别的神秘参数」。  
见到 `1,944 kHz` 同理。资料库摘要里已写成点号，但你翻 PDF 原文时要习惯逗号。

### 再做一个 30 秒口算

符号率 4800：平均每秒 4800 个符号。  
若一次通话突发里大约 132 个符号（正常突发量级），则单个突发大约：

\[
132 / 4800 \approx 0.0275\ \text{s} = 27.5\ \text{ms}
\]

这和以后要学的「时隙约 30 ms、突发装进时隙」是同一张时间地图上的邻居——今天先混个脸熟即可。


## 9. 常见误区

1. **「4FSK 就是四个载波频率四个台。」**  
   错。是**同一个信道中心**附近的四种频偏状态，不是四个独立频道。

2. **「频偏 ±1.944 kHz，所以信道只要 4 kHz 宽就行。」**  
   错。瞬时频偏数字 ≠ 占用带宽；还要看符号率、滤波、频谱旁瓣与监管掩模板。规划仍按 **12.5 kHz** 谈车道。

3. **「数字调制不占带宽。」**  
   错。第 0 节已钉：数字照样占带子，只是信息形态是比特。

4. **「恒包络 = 功率一直最大、不会干扰别人。」**  
   错。恒包络主要说幅度特性；邻道干不干净还看滤波、功率、杂散、天线与安装。

5. **「网上映射表和培训 PPT 不一致，一定是资料库错了。」**  
   先核对是否同一标准版本、bit 顺序（Bit1/Bit0）、符号编号习惯。岗位默认：**ETSI Table 10.3 原则 + 资料库摘要**。

6. **「解调失败一定是 4FSK 坏了。」**  
   也可能是频点/色码/时隙/密钥/中继配置错误，或场强不够。分层排查：射频 → 同步 → 协议 → 业务。

7. **「会背 4800 和 9600 就等于懂 DMR。」**  
   这只是物理层入口。没有帧结构、时隙、业务过程，仍会在系统联调时迷路——但本课把入口凿开了。
