## 0. 开课前：加餐四句话复习（半页，带新例子）

若你已读过 `学习推送/加餐_频率带宽与调制解调.md`，下面四句应能脱口而出。本课**不展开**频率/调制长文，只换成「今天要对 12.5 / 6.25e、写频、执照、时隙」的新例子钉一遍：

| # | 一句话 | 本课用的新例子 |
|---|--------|----------------|
| 1 | **频率** = 信号抖得有多快 | 写频软件里填的是 **460.xxx MHz** 这种大数字（中心频率）。**12.5 kHz** 不是你的发射频率；它是规划表上相邻信道中心通常隔多远。执照上的「频点」指的是那把大尺子上的刻度，不是 12.5 这个小数 |
| 2 | **带宽** = 频谱尺子上占多宽的一条带子 | DMR 专业层主路径仍在一条约按 **12.5 kHz** 规划的 RF 载波上发射；「6.25 kHz 等效」说的是**效率账**（一条载波两路话 ≈ 每路摊 6.25），**不是**把占用带宽物理切成两条 6.25 kHz 的细带子 |
| 3 | **调制** = 把信息装进适合发射的高频波 | 空口主路径仍是 **4FSK** 把比特装进**同一个**中心频率附近的载波。时隙 1 与时隙 2 **不换频点**，只是轮流占用时间片；调制规则没变成「两种更窄的调制」 |
| 4 | **解调** = 从收到的高频波把信息卸下来 | 接收机对准**同一中心频率**解调；再靠同步与时隙选择决定「听 Slot1 还是 Slot2」。解调「听得见载波」不等于两路都开喇叭——你还要选对时隙、色码、组号 |

再补一句和本课主线钉死的对照：

- **12.5 kHz（信道间隔 / 规划格子）** 回答：「执照与信道表怎么排车道？」  
- **约 12.5 kHz 量级的 RF 信道轮廓** 回答：「这一路发射在频谱尺子上大概占多宽？」  
- **6.25 kHz 等效** 回答：「同一载波用时间切开两路话之后，**平均每路**摊多少频谱？」  
- **时隙 1 / 2（约 30 ms）** 回答：「时间切片怎么切？写频 CPS 里勾哪一项？」

若这四句仍糊：先打开加餐文，再回本课。本课主线是：**12.5 与 6.25e 到底在说什么、现场怎么写频与对外解释、别把「等效」讲成「频率对半切」**。

## 1. 为什么本课重要（动机）

第 9 课已经钉死：DMR 是 ETSI 标准族、三层 Tier 独立、II/III 主路径用 2 时隙换效率。走进现场与标书，你会立刻撞到下一层糊涂：

- 「我们要 6.25，请把频率表按 6.25 间隔重写。」——把**效率口号**当成了**规划格子**。  
- 「DMR 占用带宽是 6.25 kHz。」——把**等效**当成了**物理更窄的信道**。  
- 「时隙 1 用 460.100，时隙 2 用 460.10625。」——把**时间切片**当成了**频率偏移半格**。  
- 「升级 DMR 必须重新办执照、重新划频。」——忽略了「在既有 12.5 规划上数字化」这一设计初衷。  
- 「直通两个人各占一时隙，就一定等于两套独立信道。」——中继故事讲溜了，直通 nuance 没补上。  
- 客户问：「你们说频谱效率翻倍，频谱分析仪上怎么还是一条 12.5 量级的鼓包？」——你若答不上「时间换容量」，项目信任感会掉一截。

若只背「DMR = 6.25」五个字，后面会卡在同一处：

> **12.5 kHz 是规划车道的格子（也常用来描述这条 RF 信道的量级）；6.25 kHz 等效是「同一条 12.5 载波上用 2 时隙 TDMA 撑两路话」的效率说法。等效 ≠ 把频率切成两个相差 6.25 kHz 的中心。**

本课目标是让你能自己讲清十件事（仍不推公式）：

1. **12.5 kHz** 首先是**信道间隔 / 规划网格**（相邻中心通常差 12.5 kHz）；  
2. 它**不是**你的发射频率（发射频率是 MHz 级频点）；  
3. 它也**不自动等于**占用带宽的精确测量值（占用带宽要看发射掩模与实测，量级常与 12.5 规划配套）；  
4. **6.25 kHz 等效（6.25e）** = 效率账：2-slot TDMA × 一条 12.5 RF 载波 ≈ 每路摊 6.25；  
5. RF 信道轮廓仍按约 **12.5 kHz** 这一档来谈，**不是**真 FDMA 6.25 窄道；  
6. 时间图：约 **30 ms** 一时隙；TDMA 帧 = 2 时隙；Slot1/Slot2 在**同一中心频率**上交替；  
7. **中继模式**经典故事：一台中继 / 一副天线 / 一套双工器，可支撑两路相对独立的通话 → 「6.25e」对外主叙事；  
8. **直通模式 nuance**：没有协调时，未必像中继那样稳定地「两套完全独立信道」；标准会区分直通与 TDMA 直通等表述（12.5e vs 6.25e 语境）——用白话记住边界，不编造条款细节；  
9. 与真 **6.25 kHz FDMA**（如 dPMR 一类思路）对比：FDMA 是频率上更窄的物理道；DMR 主路径是**频率保持 12.5 量级、时间上加倍**；  
10. 监管与市场为什么在乎：容量翻倍叙事、往往不必为「改成 6.25 间隔」去重划执照——写频仍是 12.5 格子 + 时隙勾选。

第 11 课会专攻「TR + Part1–4 各管什么」文档地图；本课到「频谱效率账算清、现场能解释」为止。

## 2. 总图 / 故事：一条 12.5 车道，怎么「当两条用」

先把整课装进两张故事图。

### 2.1 频谱尺子上：格子还是 12.5

```text
频谱尺子（频点中心，单位 kHz 间隔示意）：

  …  |----12.5----|----12.5----|----12.5----|  …
     ▲            ▲            ▲
   信道 n      信道 n+1      信道 n+2
   (例: 460.100) (460.1125)  (460.125)

【12.5 kHz = 规划格子 / 信道间隔】
  · 相邻合法中心，通常差 12.5 kHz
  · 写频信道表、执照附件，大多仍按这张格子排
  · 不是「发射频率 = 12.5 kHz」（那是音频量级，对讲机射频是 MHz）

【这一路上的 RF 鼓包】
  · DMR 发射仍落在所选中心附近一条带子上
  · 规划与对外叙述习惯按 ~12.5 kHz 信道档来谈
  · 「6.25e」不是把鼓包削成两半窄鼓包
```

### 2.2 时间尺子上：同一中心，两时隙轮流

```text
同一中心频率 f0（例如中继下行 460.xxx MHz）

时间 →
| Slot1 (~30 ms) | Slot2 (~30 ms) | Slot1 | Slot2 | Slot1 | …
|  通话组 A 说话  |  通话组 B 说话  |  A…  |  B…  |  A…  |

一个 TDMA 帧 = Slot1 + Slot2（约 2×30 ms）
两路话「同时进行」的体感，靠的是快速轮流，不是两个相差 6.25 kHz 的载波

【中继经典故事】
  一台中继机 + 一副天线 + 一套双工器
  → 同一对上下行频率上，可撑两路相对独立的通话
  → 对外常说：频谱效率约等于「每路 6.25 kHz」

【千万别画成】
  f0          f0+6.25 kHz
  Slot1 专用   Slot2 专用     ← 这是把 TDMA 误画成 FDMA 半格切分
```

三句话记牢：

| 说法 | 真正在说 | 现场落点 |
|------|----------|----------|
| **12.5 kHz** | 规划格子 / 信道间隔（也常描述 RF 信道档） | 信道表、执照、邻道规划 |
| **6.25 kHz 等效** | 效率：一路话平均摊多少频谱 | 标书、投标、对客户讲「翻倍」 |
| **时隙 1/2** | 时间切片（约 30 ms） | CPS 写频勾选、对讲机显示 Slot |

第 5 课解决「TDMA 是时间切片」；第 9 课解决「DMR 用它换效率」；本课解决「数字怎么对外讲、现场怎么不讲歪」。

## 3. 白话术语表

| 术语 | 白话 | 现场你会碰到 |
|------|------|----------------|
| **信道间隔（channel spacing）** | 相邻信道**中心**隔多远；陆地移动常见 12.5 / 25 kHz | 执照附件、频率规划表、「按 12.5 间隔编排」 |
| **中心频率 / 频点** | 尺子上那一刻度，写频填的 MHz 大数 | `460.125000`、RX/TX 对频 |
| **占用带宽 / 发射带宽** | 信号实际铺开的宽度（车身有多宽） | 射频测试、邻道功率、型式认证话术 |
| **12.5 kHz 信道** | 按 12.5 格子规划、量级按 12.5 档来谈的一条 RF 道 | 「现有 12.5 执照升级数字」 |
| **6.25 kHz 等效 / 6.25e** | **效率说法**：2 时隙 × 一条 12.5 载波 ≈ 每路摊 6.25 | 标书「等效 6.25」、协会宣传图 |
| **2-slot TDMA** | 同一载波上切两个时间片轮流传 | Tier II/III 主路径 |
| **时隙（Timeslot / Slot）** | 时间片；DMR 专业层典型约 **30 ms** 一片 | CPS：Slot 1 / Slot 2 |
| **TDMA 帧** | 连续 2 个时隙组成一帧 | 后续第 15 课细抠；本课记「两片一轮」 |
| **突发（burst）** | 一个时隙里发出的那一段数字波形 | 「约 30 ms 突发」口语 |
| **Colour Code（色码）** | 同频系统区分用的数字「油漆色」；**不是**时隙 | CC=1…；与 Slot 分开设 |
| **中继 / BS** | 基地台转发；上下行成对频率 | 双工器、机房、「一台中继两路话」 |
| **直通 / Direct** | 电台对电台，不经中继 | 现场对讲、应急直通信道 |
| **12.5e / 6.25e（语境标签）** | 有人用「e」强调**等效效率**叙事；直通与 TDMA 直通语境下表述可能不同 | 资料/白皮书对比图；以标准与实测为准 |
| **FDMA 6.25** | **真的**在频率上划更窄的道（另一类技术路线） | dPMR 等对比时用；**不是** DMR 主路径做法 |
| **4FSK** | DMR 空口主路径调制（四种频率状态装比特） | 本课只轻提：装货方式没变成「半宽调制」 |
| **CPS / 写频软件** | 给电台写信道参数的工具 | 频率、色码、时隙、联系人…… |

口诀：**格子是 12.5，效率喊 6.25e，切开靠时间，别切错频率。**

## 4. 现场对照（写频、执照、中继双时隙、对外解释）

| 现场动作 | 和本课哪句话有关 | 怎么做才不歪 |
|----------|------------------|--------------|
| **写频：信道列表** | 12.5 = 规划格子 | 频点仍按执照/规划的 **12.5 网格**填；不要凭空改成「每隔 6.25 一个新中心」除非规划部门真发了新表 |
| **写频：Timeslot** | 6.25e 靠时间切片 | 同一频点上为不同业务组勾 **Slot 1** 或 **Slot 2**；两路可以同频同色码、不同时隙 |
| **写频：Colour Code** | 与时隙独立 | 色码解决「同频系统油漆色」；**不要**用色码代替时隙，也**不要**以为改色码等于换了 6.25 半格 |
| **执照 / 频率批文** | 监管认的是频点与信道档 | 常见叙事：在既有 **12.5** 陆地移动规划上升级 DMR，强调容量，而不是先要求全国改成 6.25 间隔网格（具体以当地监管为准，对外别绝对化） |
| **中继机房** | 经典 6.25e 故事 | 一台数字中继、一对上下行、一套双工与天线系统，可同时服务两路通话（两时隙）——对外讲「频谱效率」，对内排「时隙分配表」 |
| **直通应急信道** | nuance | 直通也能用时隙，但**两路完全独立、稳定并发**的条件与中继不同；培训时别把中继 PPT 原封不动套到直通 |
| **标书 / 投标** | 「等效」语言 | 写「在 12.5 kHz 信道上通过 2 时隙 TDMA 达到约 6.25 kHz 等效效率」；避免写「占用带宽改为 6.25」除非有测试依据 |
| **客户问频谱仪** | 效率 ≠ 窄鼓包 | 解释：仪表示的是**频率域**鼓包仍约在 12.5 档；第二路容量在**时间域**轮流出现 |
| **与模拟并存** | 邻道与混用 | 数字信道仍按 12.5 格子与邻道规划相处；「翻倍」指同载波时隙，不自动消灭邻道干扰物理 |

给领导的 30 秒版：

> 「我们执照还是 12.5 那张表。DMR 不是把频率切成 6.25 两半，而是同一频率上切两个约 30 毫秒的时间片，一台中继往往就能当两条通话用——所以宣传里叫 6.25 等效。」

## 5. 深挖一：12.5 kHz 到底是什么（以及不是什么）

### 5.1 它是「规划格子 / 信道间隔」

想象停车场划线：每条车位中心线相隔固定距离。陆地移动无线电里，很多地方长期用 **12.5 kHz** 作为相邻信道中心的间隔。于是：

- 信道表：… 460.100 → 460.1125 → 460.125 …（示意）  
- 规划软件、执照附件、写频下拉列表，都围着这张格子转。

所以当你听到「12.5 kHz 信道」，第一反应应是：

> **这是按 12.5 间隔规划出来的一条道（中心在某个 MHz），不是收音机上的「12.5 这个发射频率」。**

### 5.2 它不是你的发射频率

| 你写在 CPS 里的 | 典型数量级 | 角色 |
|-----------------|------------|------|
| `460.125000 MHz` | 几百 MHz | **中心频率 / 频点** |
| `12.5 kHz` | 千赫 | **间隔或信道档口述** |
| `25 W` | 功率 | 力气，不是频率 |

把 12.5 kHz 填进「发射频率」框，等于把车道宽度当成车牌号——写频软件通常也不让你这么干，但口头汇报时最容易说滑。

### 5.3 它不自动等于「占用带宽的精确值」

加餐课讲过：间隔像车道宽，占用带宽像车身宽。

- 规划可以说：我们按 12.5 kHz 间隔排道。  
- 射频实验室会测：你的发射在掩模下实际铺多宽、邻道漏多少。  

DMR 对外常说「工作在 12.5 kHz 信道」，指的是**系统按这个信道档设计与规划**；把这句话偷换成「占用带宽精确等于 12.5.000 kHz」会在验收抬杠时站不住。本课你只要守住：

> **12.5 = 规划与叙述用的信道档 / 间隔；占用带宽是另一张测量成绩单。两者相关，不是同一个名词。**

### 5.4 和「25 kHz 老模拟」的对照（直觉）

更早的模拟时代常见 25 kHz 间隔。后来大量规划收窄到 12.5。DMR 的设计故事之一，就是：**在已经收窄到 12.5 的格子上继续数字化，并用时分再挖一层容量**——而不是再要求全世界先改成 6.25 间隔网格才能上数字。

## 6. 深挖二：6.25 kHz 等效到底在夸什么

### 6.1 效率账（小学算术就够）

- 一条 RF 载波，按 **12.5 kHz** 信道档占用规划资源。  
- 用 **2 时隙 TDMA**，同一载波上可以维持**两路**通话（中继故事最典型）。  
- 平均下来：每路通话「摊到」的频谱 ≈ 12.5 ÷ 2 = **6.25 kHz**。  

所以叫 **6.25 kHz equivalent（6.25e）**：

> **等价于「每条话路只消耗 6.25 kHz 规划资源」的效率说法；不是物理上出现了两条中心相差 6.25 kHz 的独立载波。**

### 6.2 RF 轮廓仍是约 12.5 档

协会与厂商图示常画：左边 FDMA 要两条更窄（或两条相邻）频率资源才能两路话；右边 TDMA 一条 12.5 载波切两时隙。要点：

- **频率域**：仍是一条载波、一个中心。  
- **时间域**：两路轮流。  
- **宣传域**：效率按 6.25e 说。

客户拿频谱仪看中继下行：通常仍看到**一个**主鼓包在你的下行频点附近，而不是两个相隔 6.25 kHz 的瘦鼓包。若你承诺「仪上会变成 6.25」，验收现场会很尴尬。

### 6.3 明确说「不是什么」

| 错误图像 | 为什么错 |
|----------|----------|
| 把 12.5 信道从中心劈成 460.100 与 460.10625 两个发射频率 | 那是半格 **FDMA** 幻想，不是 DMR 2-slot TDMA |
| 「Slot2 = 频率 +6.25 kHz」 | 时隙是时间参数，不是频偏 |
| 「上了 DMR，占用带宽自动减半」 | 减的是**每路摊到的规划资源**，不是魔术变窄车身 |
| 「6.25e = 必须改执照间隔为 6.25」 | 设计初衷恰恰是尽量吃住现有 12.5 规划习惯 |

## 7. 深挖三：时间图——约 30 ms、两时隙、同一中心

### 7.1 数字要记牢的三个

| 数字 | 含义 | 本课精度 |
|------|------|----------|
| **12.5 kHz** | 信道间隔 / 规划档 | 精确记 |
| **6.25 kHz** | 等效效率（12.5÷2） | 精确记「等效」二字 |
| **~30 ms** | 一个时隙 / 典型突发量级 | 记约数；细则第 15 课 |

4FSK 只提醒一句：比特仍用四种频率状态装进**这一条**载波；本课不展开星座与偏差值。

### 7.2 ASCII 时间线（中继下行直觉）

```text
中继下行频率固定 = f_down（同一中心）

t=0          30ms         60ms         90ms        120ms
|-------------|-------------|-------------|-------------|
|   SLOT 1    |   SLOT 2    |   SLOT 1    |   SLOT 2    |
| 安监组语音  | 物流组语音  | 安监组…     | 物流组…     |
|-------------|-------------|-------------|-------------|
     ↑               ↑
  手台A听Slot1    手台B听Slot2
  （同频、同色码、不同时隙）
```

用户体感：两组「好像同时在讲」。  
物理事实：载波在时间上左右横跳着服务两组——跳得够快，听感连续。

### 7.3 写频落点

同一信道条目里常见组合：

- RX / TX 频率（中继成对或直通同频）  
- Colour Code  
- **Timeslot = 1 或 2**  
- 联系人 / 接收组（第 7 课）  

两路独立业务：往往 **同频、同色码、不同时隙、不同组号**。  
排障口诀：频点对了却「半场人说话像吵架」——先查是不是大家都挤在同一时隙。

## 8. 深挖四：中继模式——「6.25e」经典故事为什么好讲

中继（BS）场景是对外解释 6.25e 的最佳样板：

1. **频率资源**：通常一对上下行（半双工中继），仍落在既有 12.5 规划。  
2. **硬件资源**：一台中继主机、一副天线系统、一套双工器——机房面积与天面资源不按「两套模拟中继」翻倍。  
3. **容量资源**：两个时隙 → 两路通话可并发（在话务与许可配置下）。  
4. **叙事**：所以说「同等频谱下容量接近翻倍 / 达到 6.25e」。

现场规划常用法：

- 时隙 1：安全生产组  
- 时隙 2：物流 / 后勤组  
- 或：一路语音 + 一路数据（视产品与许可）  

注意：翻倍是**容量潜力**，不是「随便怎么呼都永不排队」。话务设计、组呼范围、许可与干扰仍会限制体感。

## 9. 深挖五：直通模式的 nuance（小心讲）

直通（电台对电台）时，标准与产业材料里会出现比中继更细的表述差异，例如有人区分：

- 普通直通语境下的效率说法（有时被放在 12.5e 一类对比里）；  
- **TDMA 直通**（双方按双时隙规则协调）才更接近「同一载波稳定两路」的 6.25e 故事。

你不需要在本课背条款号，但要建立**现场边界感**：

| 场景 | 可以对外怎么说 | 别夸到哪一步 |
|------|----------------|--------------|
| **中继双时隙已开通** | 「一台中继、同一对频，两路并发」 | 别承诺无限路数 |
| **直通、未做时隙协调** | 「仍是 12.5 档数字直通信道」 | 别保证「一定有两套完全独立的并发路」 |
| **直通且终端按 TDMA 直通规则工作** | 「在协议与终端支持下，同一载波可按双时隙使用」 | 细节以产品说明与联调为准，不编造空口状态机 |

一句话：

> **中继是 6.25e 故事的主舞台；直通要加一句「取决于是否按双时隙方式协调」，不要把机房 PPT 原样贴到手台对手台。**

（更细的突发/帧/直通过程，留给第 15 课及空口专课；本课只钉效率叙事边界。）

## 10. 深挖六：对比真·6.25 kHz FDMA（避免家族混淆）

世界上还有一类思路：**在频率上直接划 6.25 kHz 宽的窄道**（FDMA），一路话一条更窄的物理信道。dPMR 等技术常被拿来与 DMR 对比。

| 维度 | DMR 专业层主路径（本课） | 真 6.25 FDMA 思路（对比用） |
|------|---------------------------|------------------------------|
| 怎么「变两路」 | **时间**切两时隙 | **频率**划两条更窄道 |
| 单路 RF 中心 | 通常仍一个 12.5 档载波中心 | 可能出现更密的 6.25 中心网格 |
| 频谱仪直觉 | 一条载波鼓包 + 时间上复用 | 更可能看到更窄/更密的频率占用图案 |
| 对外一句话 | 「12.5 上 TDMA → 6.25e」 | 「物理 6.25 信道」 |
| 写频/执照习惯 | 大量项目保留 12.5 表 + 勾时隙 | 依赖是否存在 6.25 规划与设备生态 |

记住对比的目的：

> **听到「6.25」先问：是等效效率，还是物理窄道？DMR 主叙事是前者。**

## 11. 深挖七：监管与市场为什么在乎

1. **容量**：同样频点资源，数字双时隙常带来「接近两倍话路」的规划空间。  
2. **迁移成本**：很多用户已有 12.5 模拟或既有数字规划；「在原格子上升级」比「全国重划 6.25 间隔」好卖。  
3. **天面与机房**：一台中继两时隙，对比两台模拟中继的天面/双工器/耗电，TCO 故事好听。  
4. **标书语言**：写清「12.5 kHz 信道 + 2-slot TDMA + 约 6.25 kHz 等效」，评审专家不容易和「真 6.25 FDMA」或其他制式搅在一起。  
5. **诚实边界**：具体能否免于重办/变更执照，**以当地无线电管理机构批复为准**；课程给的是设计意图与常见工程叙事，不是法律意见。

## 13. 完整例子（三个正例 + 一个反例）

### 例子 A · 正例：工厂中继双时隙（经典 6.25e）

- **场景**：厂区原有 12.5 kHz 间隔执照对频；模拟中继忙时打架；安监与物流经常同时要讲话。  
- **做法**：上 Tier II 数字中继；下行/上行仍用原规划频点对；色码统一；**时隙 1 = 安监组，时隙 2 = 物流组**。  
- **对外解释**：「没有把频率改成 6.25 间隔；是同一对频上切两个约 30 ms 时隙，效率上相当于每路 6.25。」  
- **验收看点**：两组可近乎同时通话；频谱仪看下行仍是一个主频点鼓包；写频表仍是 12.5 格子。  
- **一句话**：格子不变，时间切开，故事成立。

### 例子 B · 正例：投标材料怎么写「等效」

- **场景**：市政项目招标，评委既有通信工程师也有财务。  
- **正确表述示例**：  
  - 「系统工作于既有 **12.5 kHz** 信道规划；」  
  - 「采用 **2 时隙 TDMA**，在单载波上提供两路语音能力；」  
  - 「频谱效率约等于 **6.25 kHz 等效（6.25e）**。」  
- **配套图**：左：两路 = 两份频率资源；右：两路 = 一份 12.5 资源 × 两时隙。  
- **一句话**：标书写「等效」，评审才不会按 FDMA 窄道去抠你的频谱仪截图。

### 例子 C · 正例：写频员一天的正确操作

- **任务**：给 50 台终端写「物流信道」。  
- **步骤直觉**：  
  1. 从规划表选中继 RX/TX（12.5 网格上的 MHz）；  
  2. 填 Colour Code；  
  3. **Timeslot = 2**（按系统分配表）；  
  4. 发射联系人 = 物流组呼；接收组含物流组。  
- **不做的事**：把频率改成「原频点 ±6.25 kHz」幻想出 Slot2 专用频；或把色码当成时隙。  
- **一句话**：频率抄执照，时隙抄分配表，色码抄系统规划——三件事三本账。

### 例子 D · 反例：把 6.25e 讲成「频率对半切」

- **错误培训稿**：「DMR 把原来 12.5 信道从中间切开，变成两个 6.25 频点；时隙 1 用较低频点，时隙 2 用较高频点。」  
- **后果**：新来的写频员真的去改频率表；与友邻单位对频失败；频谱仪与规划表对不上；客户质疑「你们是不是私有跳频」。  
- **纠正稿**：删除「切开频点」；改为「同一中心频率上，约 30 ms 轮流的两个时隙」；并加直通 nuance 脚注。  
- **教训**：**等效是除法（12.5÷2），不是把载波从中心撕成两半。**

## 14. 常见误区（请逐条用自己的话复述）

1. **「12.5 kHz 就是我的发射频率。」**  
   错。发射频率是 MHz 级频点；12.5 是间隔/信道档。

2. **「6.25 kHz 等效 = 占用带宽变成 6.25。」**  
   错。等效是效率账；RF 仍按约 12.5 信道档来谈。

3. **「时隙 2 = 频率加 6.25 kHz。」**  
   错。时隙是时间片，约 30 ms，同中心交替。

4. **「上 DMR 必须把执照改成 6.25 间隔网格。」**  
   不成立为默认。设计故事是尽量在既有 12.5 规划上数字化；是否变更执照看当地批复。

5. **「有双时隙就等于集群 Tier III。」**  
   错（第 9 课已钉）。双时隙是效率手段；集群是控制器派信道。

6. **「直通一定也能稳定两路独立，和中继一模一样。」**  
   过分。直通要看是否按 TDMA 直通方式协调；别把中继故事无条件外推。

7. **「色码可以代替时隙。」**  
   错。色码是同频系统区分；时隙是时间切片；常要同时正确。

8. **「DMR 的 6.25 和 dPMR 类真 6.25 FDMA 是一回事。」**  
   错。一个是 TDMA 等效，一个是频率窄道思路。

9. **「频谱仪上看不到两个鼓包，说明 6.25e 是假的。」**  
   错。本来就不该看成两个频偏 6.25 的鼓包；第二路在时间域。

10. **「反正都是营销词，12.5 / 6.25e / 30 ms 不用记。」**  
    错。这三个数是你对外解释与对内写频的共同语言；记错会直接写错参数。

11. **（加分防坑）「两路并发 = 永远不排队。」**  
    错。时隙只有两个；组呼范围大、话务高峰时仍会争用。6.25e 描述的是资源效率，不是无限容量。

## 15. 自测（建议先闭卷写，再对答案）

1. **填空**：陆地移动规划里，**12.5 kHz** 首先通常指 ______；写频里的发射频率则是 ______ 量级的频点。  
2. **选择**：所谓「6.25 kHz 等效」最准确的理解是：  
   A. 把载波中心拆成两个相差 6.25 kHz 的频率  
   B. 在一条 12.5 kHz 档 RF 载波上用 2 时隙，使每路话平均摊约 6.25 kHz 规划资源

3. **判断**：Slot1 与 Slot2 在中继下行上使用两个不同的中心频率。对 / 错？  
4. **填空**：一个时隙典型量级约 ______ ms；一个 TDMA 帧包含 ______ 个时隙。  
5. **简答**：客户拿频谱仪看中继下行，只看到一个主鼓包，问「第二路在哪？」你怎么用两句话解释？  
6. **场景题**：同事写培训材料：「直通时也一定保证和中继一样，随便两对终端各占一时隙就完全独立永不互相影响。」请问哪里不严谨？应如何改口？

### 参考答案

1. **信道间隔 / 规划网格（信道档）；MHz（例如 460.xxx）。**  
2. **B。**  
3. **错。** 同一中心频率上按时间交替；不是两个中心。  
4. **约 30；2。**  
5. **第二路不在另一个频偏 6.25 kHz 的鼓包上，而在时间域的另一个约 30 ms 时隙里轮流出现；所以频率域看仍是一条载波，效率账才叫 6.25e。**  
6. **把中继经典故事无条件套到直通。应改为：直通能否稳定获得「双时隙两路独立」取决于终端与系统是否按 TDMA 直通方式协调；对外先讲中继 6.25e，直通单独加注。**
