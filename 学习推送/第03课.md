## 0. 开课前：加餐四句话复习（带新例子）

若你已读过 `学习推送/加餐_频率带宽与调制解调.md`，下面四句应能脱口而出。本课**不照抄加餐与第 2 课**，换成「按一次 PTT」的场景再钉一遍：

| # | 一句话 | 本课用的新例子 |
|---|--------|----------------|
| 1 | **频率** = 信号抖得有多快 | 你们约定在 `460.125 MHz` 通话：载波大约每秒抖 **4.60125 亿次**。模拟机和数字机都可以站在这同一个「刻度」上——差别不在「站哪」，而在「声音怎么装进载波」 |
| 2 | **带宽** = 频谱尺子上占多宽的一条带子 | 无论模拟 FM 还是 DMR，发射时能量都会在中心频率左右铺开一小段。车道规划常见仍是 **12.5 kHz** 间隔；数字并不是「不占带宽」，而是用比特 + 纠错把同一条带子用得更「聪明」 |
| 3 | **调制** = 把信息装进适合发射的高频波 | **模拟路径**：话筒电压连续地「拧」载波的频率（FM 直觉）。**数字路径**：先把声音变成一串 0/1，再让载波按约定的数字花样抖（DMR 里常见是 **4FSK**，第 4 课细讲） |
| 4 | **解调** = 从收到的高频波把信息卸下来 | **模拟**：从频率抖法里直接还原出连续音频电压 → 喇叭。**数字**：先认出比特，再经纠错/声码器还原成声音；比特对不上时，往往不是「沙沙变吵」，而是**突然听不清或静音** |

再补一句和本课主线钉死的对照：

- **模拟对讲**：信息在空中时，大致还「长得像声音波形」（连续变化）。  
- **数字对讲**：信息在空中时，长得像**比特流**；声音只在发端和收端两端「现身」。

若这四句仍糊：先打开加餐文读「调制 / 解调」两段，再回本课。本课主线是：**声音如何变成比特、模拟与数字两条链路差在哪、现场听感与业务能力为何不同**。

## 1. 为什么本课重要（动机）

现场里你会反复碰到这类对话：

- 「怎么数字机边缘一拐弯就没声了？模拟还能嘶嘶着听。」  
- 「数字不是更清晰吗？为什么有时机器人音、有时干脆断？」  
- 「都是 12.5K，为什么数字还能两路？」  
- 「加密、个呼、短消息、GPS——这些模拟为啥很难做？」

这些问题的根，几乎都落在同一句话上：

> **模拟：声音（连续波形）直接骑上射频。**  
> **数字：声音先变成比特，比特再骑上射频。**

不懂「声音怎么变成比特」，后面的声码器、FEC、SYNC、时隙、加密都会像黑话。本课目标是让你能自己讲清六件事：

1. 模拟 FM 对讲的大致链路（不推公式）；  
2. 采样、量化、编码是什么意思（白话级）；  
3. 为什么窄带对讲不能空中直接传「CD 级 PCM」；  
4. **声码器**在干什么（参数压缩，不是 MP3 拷贝）；  
5. 为什么数字听感常呈「悬崖」而模拟常呈「渐变」；  
6. 这些差别如何映射到写频、覆盖测试、投诉处理和业务功能。

第 4 课才会专讲 **4FSK**；本课到「比特流准备上射频」为止，先把「信息形态」分清。

## 2. 总图 / 故事：从嘴边声波到空中射频的两条路

先把整课装进一张故事图。同一句「仓库三号门，收到请回答」，在两种体制里走的路不一样：

```text
                    你的嘴巴（声波）
                           │
                           ▼
                    话筒 → 音频电信号（连续电压）
                           │
           ┌───────────────┴───────────────┐
           │                               │
           ▼  【模拟对讲】                  ▼  【数字对讲 / DMR】
   音频电压直接参与调制              采样 → 量化 →（PCM 很胖）
   （常见：调频 FM）                        │
           │                         声码器压缩成「低速比特」
           │                               │
           │                         信道编码 / 交织（抗误码）
           │                               │
           │                         组帧、SYNC、时隙安排…
           │                               │
           ▼                               ▼
   射频载波「跟着声音连续变花样」    射频载波「按数字符号变花样」
           │                         （如 4FSK，下节课）
           └───────────────┬───────────────┘
                           ▼
                      天线 → 空中
                           │
                           ▼
                      对方天线 → 射频前端
                           │
           ┌───────────────┴───────────────┐
           │                               │
           ▼  模拟                          ▼  数字
   解调出连续音频                     解调出比特 → 纠错
           │                         声码器还原语音
           ▼                               ▼
        喇叭里的声音                    喇叭里的声音
```

读图顺序（建议朗读一遍）：

1. **共同点**：两边都从声波开始，都要最终变成喇叭里的声波；两边都要用**调制**把「要传的东西」装进适合飞的高频载波。  
2. **分叉点**：模拟在「音频电信号」之后几乎立刻去拧载波；数字在拧载波之前，先把声音做成**比特工厂**的产品。  
3. **空中形态**：模拟空中更像「被声音揉过的载波」；数字空中更像「按规定跳舞的符号串」。  
4. **收端脾气**：模拟噪声会掺进音频里一起变吵；数字只要比特还能纠回来，听感可以一直干净——纠不回来就塌。

一句话记总图：

> **模拟传的是「像声音的波」；数字传的是「关于声音的说明书（比特）」再在对端照说明书合成声音。**

## 3. 白话术语表（本课必会）

| 术语 | 白话 | 现场你怎么碰上 |
|------|------|----------------|
| **模拟信号** | 随时间连续变化的量（电压、声波） | 传统 FM 对讲、收音机听感 |
| **数字信号 / 比特** | 用有限符号表示的信息，常说 0/1 | 数字机、加密、短数据、协议分析 |
| **采样** | 按固定节拍「量一下」幅度 | ADC、录音、声码器前端 |
| **采样率** | 每秒量多少次（Hz） | 「8 kHz 电话音」「44.1 kHz CD」 |
| **量化** | 把连续幅度归到有限档位 | 位深 / bit depth；档粗就糙 |
| **PCM** | 采样+量化后的「波形原样数字化」 | 很胖；电话约 64 kbps 量级 |
| **声码器（vocoder）** | 不硬传波形，而传「发音特征参数」再合成 | DMR 语音能塞进窄带的关键 |
| **信道编码 / FEC** | 故意加冗余，方便收端发现/纠正错误 | 「还能听」与「突然断」的分界之一 |
| **调制 / 解调** | 装上载波 / 从载波卸下 | 加餐四句话；第 4 课细讲 4FSK |
| **数字悬崖（cliff）** | 链路尚可时音质稳，再差一点突然不可用 | 覆盖边缘、室内拐角投诉 |
| **时隙（slot）** | 同一频点上按时间轮流占用 | DMR：约 **30 ms** 一个时隙，两时隙共享 **12.5 kHz** 规划 |

口诀：

> **模拟：波骑波。数字：声→比特→波。听感：模拟渐变，数字易悬崖。**

## 4. 模拟对讲：声音怎么「骑」上载波（FM 直觉）

### 4.1 半双工与 PTT

传统模拟对讲常见是**半双工**：同一时刻你方要么说要么听，靠 **PTT**（Push-To-Talk）切换。按下去 → 发射链路工作；松开 → 回到接收。这和「手机全双工同时说听」不是同一套体验。

### 4.2 FM 的直觉（不推公式）

调频（Frequency Modulation）可以想成：

> 载波本来在某个中心频率附近抖。  
> 你的声音大一点，就让它「抖得偏得更远一点」；声音的音调变化，则体现在这种偏移怎么随时间扭动。

麦克风把声波变成连续电压 → 调制器让载波频率跟着这电压变 → 功放 → 天线。  
对方：天线 → 滤波/混频等射频处理 → **鉴频/解调**取出音频电压 → 放大 → 喇叭。

整条链路的特点是：

- **信息形态一直偏「连续」**；  
- 空中干扰、热噪声、同频抢占，往往会**直接变成喇叭里的沙沙、劈啪、断续**；  
- 距离拉远时，常见体验是「越来越吵、越来越糊」，而不是瞬间消失（当然也可能弱到听不见）。

### 4.3 模拟链路上「信令」通常很瘦

模拟机也可以有亚音频（CTCSS）、数字静噪（DCS）等，用来减少乱响、做简单分组。但复杂的个呼身份、短消息、精细控制，做起来别扭——因为空中主力仍是「音频波形通道」，不是「结构化比特管道」。

### 4.4 和加餐的挂钩

- **频率**：你们仍要约定中心频点（例如 460.xxx MHz）。  
- **带宽**：FM 话音会让能量在中心附近铺开；规划上仍要守车道（常见 12.5 / 25 kHz 间隔语境）。  
- **调制/解调**：这里的调制对象主要是**连续音频**本身。

## 5. 数字对讲：声音怎么变成比特（再到射频）

数字对讲（含 DMR）的关键变化是：

> **原始语音不再直接调制载波。**  
> 先变成数字码流，再以数字调制方式加载到射频。

下面按「工厂流水线」拆开。不必记住芯片型号；要记住**每一步在解决什么问题**。

### 5.1 第一步：采样——时间上切成一串快照

连续声音像一条光滑曲线。采样就是按节拍在时间轴上「点名」：

```text
连续波形：  ～～～～～～～～～～～～
采样点：     •  •  •  •  •  •  •  •
```

- **采样率越高**：时间轴上的点越密，越能跟上更快的抖动（更高音频频率成分）。  
- 经验锚点（建立数量级，不必背考试）：  
  - 电话语音常见约 **8 kHz** 采样量级；  
  - CD 音频常见 **44.1 kHz**。  

对讲语音不需要当音乐听，采样率通常远低于 Hi‑Fi。本课只要建立直觉：

> **采样 = 把「连续时间」变成「一串离散时刻的幅度」。**

### 5.2 第二步：量化——幅度上归到有限档

每个采样点的幅度本来可以是任意精细的实数。量化就是：

> 规定只有有限个「台阶」，把真实幅度归到最近的一档。

档位多少由**位数（bit depth）**决定：位数越多，台阶越细，量化误差越小，数据也越胖。

```text
细台阶（位数多）：更贴原波形，比特更多
粗台阶（位数少）：像像素放大，更糙，比特更少
```

### 5.3 第三步：得到 PCM——以及为什么空中传不起「胖 PCM」

采样 + 量化之后，若按「波形原样」编码，就是常说的 **PCM** 思路。粗算数量级（帮助建立恐惧感，不是要你背公式）：

> 若每秒 8000 个样点，每样点 8 bit，则约 **64 kbps**——这还只是单声道路电话量级的「胖」数据。

陆地移动对讲常见信道间隔是 **12.5 kHz** 量级的窄带规划。空中还能再塞信令、同步、保护间隔、两时隙共享……  
结论很朴素：

> **窄带数字对讲几乎不可能把「未经压缩的 PCM 波形」原样喷到空中。**  
> 必须再压缩：这就是声码器登场的原因。

### 5.4 第四步：声码器——传「怎么发音」而不是「波形照片」

声码器（vocoder）可以想成：

| 做法 | 比喻 | 空中数据 |
|------|------|----------|
| 波形编码（如胖 PCM） | 每秒拍几千张声音照片寄过去 | 很胖 |
| **参数 / 声码器编码** | 寄「声带怎么振动、口腔怎么共鸣」的说明书，对端按说明书合成 | 可以压到很低速率 |

人说话有很多冗余：不是每个样点都同等重要。声码器抓住对「可懂度」关键的特征，把速率压到窄带塞得下的水平（业界常见讨论低速声码器在约 **1.2～4.8 kbps** 量级；具体芯片与标准组合各异）。

对 DMR 现场人员，先记住三句就够：

1. **空中飞的不是 MP3 文件**，也不是手机微信语音封包的简单拷贝；  
2. 是面向**窄带无线、低延迟、可纠错**优化的专业语音编码；  
3. 听感有时略「数字味 / 机器味」，换来的是抗干扰与业务能力。

（具体编解码器商标、精确比特率表，留给以后对照厂家与标准文档；本课不要求背型号。）

### 5.5 第五步：信道编码——给比特穿上防弹衣

无线信道会翻比特（0 变 1）。语音压缩后已经很「瘦」，再错几个关键比特，合成音可能直接崩。

于是发送前常做 **FEC（前向纠错）**：故意加一些冗余比特，让收端有机会发现并纠正部分错误。  
这和「把文件打成 zip 更小」相反——这里是**变胖一点，换可靠性**。

直觉：

> 声码器负责「说清楚用更少比特」；  
> 信道编码负责「这些比特路上被磕碰还能修」。

### 5.6 第六步：组帧与时隙——比特要排队上车

DMR 专业模式还要在 **12.5 kHz** 规划的一条车道里，用 **2 时隙 TDMA** 尽量跑两路：每个时隙大约 **30 ms** 量级（以后空口课会拆 264 bit 突发、超帧 A–F）。  
也就是说：比特流不是「随便连续喷」，而要按协议切成突发、加上同步字（SYNC）、嵌入信令等。

本课只要建立：

> **数字语音 = 声码器比特 + 保护 + 帧结构 +（再）数字调制。**

### 5.7 第七步：才轮到「数字调制」上射频

比特仍是基带世界的东西。要飞出去，还得**调制**到射频载波上。  
DMR 常见故事是 **4FSK**（四个频率/电平符号表达比特）——**第 4 课专讲**。  
这里先钉死顺序，避免概念打架：

```text
正确顺序：
声音 → 采样量化 → 声码器 → （FEC/组帧） → 数字调制(如4FSK) → 射频

常见搞反：
「数字机也是直接 FM 语音」← 不准确（数模兼容模式另说）
「4FSK 就是声码器」← 错，一个管语音压缩，一个管比特怎么上载波
```

### 5.8 收端反过来走

对方大致：射频解调出符号/比特 → 解交织/纠错 → 取出声码器帧 → 合成语音 → DAC/音频放大 → 喇叭。  
任一层挂掉，听感都可能「奇怪」或「没声」——排障时要会问：是射频弱？同步丢？纠错顶不住？还是声码器参数毁了？


### 5.9 和加餐四句话再对一次（数字路径版）

把数字链路按加餐词汇翻译一遍，防止「学了采样忘了调制」：

| 加餐词 | 在数字对讲里落在哪 |
|--------|-------------------|
| 频率 | 写频中心仍是 MHz 刻度；两时隙共享的是同一中心附近的那条车道 |
| 带宽 | 发射仍占一条有宽度的带子；纠错与符号成形都会影响实际铺开，但纪律仍是邻道别刮蹭 |
| 调制 | 装进载波的是**已经数字化并压缩保护过的符号/比特**，不是话筒电压本身 |
| 解调 | 先卸下符号得比特，再谈声码器；解调成功 ≠ 你一定听得懂——后面还有纠错与解码 |

---

### 5.10 「数模兼容」别和「原理混为一谈」

很多手台支持模拟信道与数字信道并存，甚至同一机在不同信道切换。那是**产品能力**，不等于「数字发射时仍在走模拟 FM 语音主路径」。  
排障时先问清楚：当前信道模式是 Analog 还是 Digital？Colour Code / 时隙 / 联系人配了吗？不要用模拟经验硬套数字无声。

## 6. 现场对照：听感、覆盖、写频与业务

### 6.1 听感：渐变雾 vs 悬崖

| | 模拟 | 数字（典型体验） |
|--|------|------------------|
| 信号变差时 | 噪声渐渐变大，仍可能「嘶嘶着听懂」 | 较长区间保持相对清晰 |
| 再差一点 | 继续恶化 | 可能突然错码、机器人音、断续、静音 |
| 投诉话术 | 「好吵、好远」 | 「怎么突然没了 / 只有嘟嘟」 |

这就是常说的 **digital cliff（数字悬崖）**。不是数字「更娇气」，而是：纠错与判决有工作区；出了工作区，系统宁可「不可懂」也不假装「带噪可懂」。

覆盖测试时要注意：

- 用模拟习惯的「能嘶到」当边界，会**高估**数字可用区；  
- 数字要以**可懂通话 / 协议仍锁得住**为标准，结合场强与误码相关指示（视机型）。

### 6.2 同频干扰与「抢话」脾气

- 模拟：两台同频齐发，常出现难听的差拍、啸叫、谁功率大谁「压」过谁。  
- 数字：两路比特搅在一起，接收机可能谁都解不好；有时表现为一方「伪成功」、更多是双方都惨——具体与捕获效应、定时、Colour Code 等有关（后课再展开 Colour Code）。

### 6.3 频谱效率：和「6.25 kHz 等效」的关系

第 2 课已强调：DMR 的 **6.25 kHz 等效**，常常是指在 **12.5 kHz** 规划里用 **2×30 ms 时隙**顶两路，不是把写频中心改成差 6.25 kHz 的两个物理频点。  
本课补一句因果：

> 之所以能在时间上切两刀，是因为语音已被压成可按时隙搬运的比特块；  
> 模拟连续话音波形很难用同一套「30 ms 积木」干净地做同样的事。

### 6.4 业务能力：比特管道带来的「额外行李」

因为空中主力是比特，所以更容易叠加：

- 个呼 / 组呼身份与寻址；  
- 短数据、状态消息；  
- 加密（对比特流做变换，而不是简单倒频）；  
- 更丰富的控制信令（CSBK、LC……后课）；  
- 集群里的登记、Grant、Reason Code（更后面）。

模拟不是「完全不能做附加功能」，而是主通道形态决定了：**复杂结构化业务更天然地属于数字。**

### 6.5 写频与模式切换

现场常见：

- **纯模拟信道** vs **纯数字信道** vs **数模兼容 / 双模**；  
- 同一频点表格里，模式选错 → 「有信号灯却无语音」或「只能模拟通」；  
- Colour Code、时隙、联系人（Contact）、组列表配错，会表现为「听得到别人数字噪音/无声但仪表有动静」——根因仍是：**数字链路要的是比特对齐，不只是射频有能量**。

### 6.6 电池与发射占空（直觉级）

数字体制里发射机不一定像模拟那样在整段讲话期间以同一种连续方式「一直占满」（还与时隙、直通/中继、厂商实现有关）。宣传材料常谈续航优势——你把它当成**可能的系统级结果**，具体机型以实测为准，不要背成绝对定律。

## 7. 完整例子：按一次 PTT，从按下到对方喇叭

设定：两人直通（无中继），约定频点 `460.125 MHz`，信道间隔语境 **12.5 kHz**。A 对 B 说：「三号门，收到请回答。」

### 7.1 若走模拟 FM

1. A 按 PTT，发射机上电射频链路。  
2. 声波 → 话筒电压（连续）。  
3. FM 调制：载波频率随音频电压扭动。  
4. 功放 → 天线，能量落在约定车道附近。  
5. B 的接收机对准同频，解调出音频电压。  
6. 若信号尚可：喇叭出声，可能带一点沙沙。  
7. A 松 PTT；B 再按 PTT 回话。

故障直觉：频点错、间隔规划错、静噪/亚音不匹配、距离太远、同频干扰 → 多表现为吵、断、无声但「有噪声门」等模拟老经验。

### 7.2 若走 DMR 数字语音（直通示意）

1. A 按 PTT。  
2. 声波 → 话筒 →（模数）采样/量化。  
3. 声码器把一段段语音压成短比特帧。  
4. 加上纠错与帧结构，排进约 **30 ms** 量级的时隙突发；带上同步等信息。  
5. **数字调制**（如 4FSK）把比特变成射频上的符号花样；中心仍在约定频点附近，占用仍须落在 **12.5 kHz** 车道纪律里。  
6. B 先锁同步、解符号得比特，纠错，再声码器合成语音。  
7. 若误码在可纠范围：听感往往干净；若跌出范围：可能突然坏掉。  
8. 松 PTT；若配置了个呼/组呼，空中还可能有结构化地址信息（后课）。

对照表（建议收藏）：

| 步骤 | 模拟 | 数字 DMR |
|------|------|----------|
| 信息主形态（空中） | 连续调频话音 | 受保护的语音比特 + 信令 |
| 关键「翻译器」 | FM 调制/解调 | 声码器 + 数字调制/解调 |
| 变差时听感 | 渐吵 | 易悬崖 |
| 多一路通话 | 通常再要频谱资源 | 同车道两时隙（专业模式） |
| 加密/短数据 | 弱/别扭 | 相对自然 |

## 8. 常见误区（本课重点排雷）

1. **「数字 = 无限清晰、永远比模拟好听」**  
   错。数字在覆盖良好时往往更干净；边缘可能突然不可用。音质还取决于声码器与实现，不是魔法。

2. **「数字不占带宽 / 不需要 12.5 kHz」**  
   错。数字照样占频谱带子；DMR 专业模式常见仍是在 **12.5 kHz** 规划里做事。「6.25 kHz 等效」是效率口径，不是让你乱改物理栅格（见第 2 课）。

3. **「比特率 = 射频频率」**  
   错。比特率是信息快慢（bps）；射频频率是载波抖多快（MHz）。一个是「货有多少」，一个是「货车跑在哪条高速」。

4. **「采样率越高越好，无条件」**  
   错。更高采样率带来更多数据；窄带链路塞不下就毫无意义。对讲要的是可懂、低时延、可靠，不是工作室录音指标。

5. **「DMR 声码器 = 手机里的 MP3/AAC」**  
   错。目标场景、时延、抗误码、码率都不同。不要用下载歌曲的经验硬套空口语音。

6. **「有信号灯就等于数字通话一定成功」**  
   错。射频有能量 ≠ 比特帧完整可解。同步、Colour Code、时隙、联系人、密钥都可能让你「看得到世界，听不到人话」。

7. **「调制就是声码器」**  
   错。声码器解决「声音↔比特」；调制解决「比特↔射频波」。中间还隔着信道编码与帧结构。

8. **「模拟没有调制」**  
   错。模拟也有调制（如 FM）；只是装上载波的是连续音频，而不是声码器比特。

## 9. 自测（建议先闭卷做，再对答案）

**题 1（判断）**  
数字对讲在空中传输的主信息形态，通常已经是比特流（再经数字调制上射频），而不是未经数字化的连续话筒电压直接 FM。  
（对 / 错）

**题 2（选择）**  
把连续声音在时间上打成一串幅度快照，这一步叫：  
A. 调制　B. 采样　C. 鉴权　D. Colour Code

**题 3（简答）**  
为什么窄带数字对讲一般不能把「电话量级 PCM」原样喷到空中？缺了哪一类关键技术会撑不住？

**题 4（选择）**  
现场信号变差时，数字通话突然从清晰变成不可懂/静音，而模拟往往先变吵——这种数字现象常被叫做：  
A. 多普勒　B. 数字悬崖　C. 镜频干扰　D. 驻波比

**题 5（简答）**  
用两句话区分：**声码器** 与 **4FSK（数字调制）** 各管哪一段。

**题 6（综合）**  
同事说：「我们都是 460.125，数字应该和模拟听感一样慢慢变差。」你怎么用本课原理解释他可能错在哪？并补一句测试建议。

### 参考答案

1. **对。**  
2. **B. 采样。**  
3. PCM 太胖，12.5 kHz 窄带塞不下还要留给信令/同步/时隙等；需要**声码器（低速语音编码）**把速率压下来，再加信道编码保护。  
4. **B. 数字悬崖。**  
5. 声码器：声音 ↔ 压缩语音比特。4FSK：比特/符号 ↔ 射频载波上的数字调制花样。  
6. 数字有纠错工作区，出区后听感常断崖，不像模拟噪声渐增；测试应用「可懂/可保持」标准看边缘，不能只用模拟式「能嘶到」当边界。
