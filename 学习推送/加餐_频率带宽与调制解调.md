# 加餐课 · 频率、带宽、调制、解调（零基础版）

> 专门针对「通讯基础比较差、这块总糊」  
> 阅读约 25–35 分钟 · 几乎不推公式 · 读完应能用自己的话讲给同事听

---

## 先记住四句话（整课浓缩）

1. **频率** = 信号抖得有多快（振动快慢）。  
2. **带宽** = 这条信号在频谱尺子上**占多宽的一条带子**。  
3. **调制** = 把你要传的信息「装进」适合发射的高频波里。  
4. **解调** = 对方从收到的高频波里把信息「卸下来」。

DMR、手机、Wi‑Fi、广播，底层都在做 3 和 4；差别只是装的方式、占多宽、规则多严。

---

## 第一部分：频率到底是什么

### 1.1 用水波想

往平静水面扔一块石头，水波一圈圈荡开。  
你盯着一个浮标：它上下晃。

- **晃得慢** → 频率低  
- **晃得快** → 频率高  

电磁波你看不见，但也可以想成「空间里某种量在按某个快慢抖」。  
单位：

| 写法 | 意思 |
|------|------|
| 1 Hz | 每秒抖 1 次 |
| 1 kHz | 每秒 1000 次 |
| 1 MHz | 每秒 100 万次 |
| 1 GHz | 每秒 10 亿次 |

人耳能听的声音，大致在几百 Hz 到几千 Hz（数量级直觉即可）。  
对讲机射频常在 **几十到几百 MHz**（例如 VHF/UHF 一带）——比声音快得多，所以要用天线，不能靠喇叭直接「喊」到几公里外。

### 1.2 频率 ≠ 音量，也 ≠ 功率

很多人会混：

| 概念 | 是什么 | 不是什么 |
|------|--------|----------|
| 频率 | 抖多快 | 不是声音多响 |
| 功率 | 力气多大（发多猛） | 不是频道号 |
| 频率（频点） | 在频谱尺子上的位置 | 不是音质好坏 |

写频软件里填的「462.xxxxx MHz」是**频点（中心频率）**，不是音量旋钮。

### 1.3 频谱尺子（非常重要的一张图）

把所有可能的频率排成一把很长的尺子：

```text
低频 ←————————————————————————→ 高频
  声音能听到的     对讲机常用     Wi‑Fi/手机更高…
  (kHz 级)         (MHz 级)        (GHz 级)
```

**选频点** = 大家约定：我们站在尺子的哪一刻度上通话。  
站错刻度 = 对方收音机拧错台 = 听不见（或听见别人）。

## 第二部分：带宽是什么（最容易混）

### 2.1 一个点 vs 一条带子

- **中心频率**：尺子上的一个刻度（比如信道中心）。  
- **带宽**：你的信号实际要占**左右一小段宽度**，不是无限细的一条线。

```text
频谱尺子：
──────────────[████████]──────────────
                 ▲
              中心频率
              ←带宽→
```

为什么一定占宽度？  
因为信息本身在变化：你说话时声波在变，数字比特在跳。  
「变化的东西」在频谱上看，就不会只是一根无限细的针，而会铺开一点。铺开的宽度就和**带宽**相关。

### 2.2 两个容易混的「宽」

| 名词 | 白话 | 写频/规划里常见 |
|------|------|------------------|
| **信道间隔** | 相邻两条合法车道中心，隔多远 | 常见 12.5 kHz、25 kHz |
| **占用带宽 / 发射带宽** | 你开车时车身实际有多宽 | 太宽会压到邻道 |

类比：

- 高速公路车道宽 3.5 米 → 有点像**信道间隔**的规划。  
- 你的车身 2 米宽 → 有点像**占用带宽**。  
车身比车道还宽 → 会刮到旁边的车 → **邻道干扰**。

DMR 说「在 12.5 kHz 信道里工作」，意思是：规划给你的车道按 12.5 kHz 来排；你的发射必须规矩，别严重越界。

### 2.3 「6.25 kHz 等效」先建立直觉（细节以后课）

以前模拟常是：一条 12.5 kHz 车道 ≈ 一路通话。  
若能在同一条 12.5 kHz 车道里塞**两路**通话，效率就好像把车道划成 6.25 kHz 那么「省」。  
DMR 专业层用 **2 时隙 TDMA** 做这件事——不是真的把频率切成两半，而是**同一频率上按时间轮流**。  
先有这个画面即可：带宽/间隔是「频率尺子上的宽度」；时隙是「时间上的切片」。

## 第三部分：调制是什么（装货）

### 3.1 为什么要调制？

假如你只把「话筒里的低频电信号」直接接到天线：

- 天线尺寸会不合适；  
- 所有人的声音都挤在同一低频区域，无法分工；  
- 也无法用执照频段那一套规划。

所以要找一辆「适合上路的车」——**高频载波**，再把信息装上车。

```text
信息（声音/比特）  +  载波（高频）  →  已调信号（拿去发射）
        装货过程 = 调制
```

### 3.2 可以改载波的哪一门？

载波可以想成：一直在抖的「纯音」。你可以改它的：

| 改什么 | 名字（知道即可） | 生活直觉 |
|--------|------------------|----------|
| 抖的强弱（幅度） | AM 调幅 | 广播里一种老方式 |
| 抖的快慢（频率） | FM 调频 | 模拟对讲很常见 |
| 抖的「起步早晚」（相位） | PM / 相位类 | 很多数字系统沾边 |
| 一次只允许几种离散状态 | 数字调制（如 4FSK） | DMR 物理层相关 |

**模拟对讲**常见：让载波频率跟着话音变 → 听起来像调频。  
**DMR**：先把话变成比特，再让载波在几种规定的频率偏移之间跳（你可以先记：**用几种固定的「抖法」代表 00/01/10/11**）。名字叫 4FSK，细节以后课；今天只要懂「数字调制 = 用有限种波形状态代表比特」。

### 3.3 一个极简数字例子（帮助建立画面）

假设约定：

| 比特 | 载波怎么抖（示意） |
|------|---------------------|
| 00 | 往低频偏一点 |
| 01 | 往低频偏多一点 |
| 10 | 往高频偏一点 |
| 11 | 往高频偏多一点 |

发送端：比特流进来 → 选出对应「偏法」→ 天线发出去。  
这就是**调制**在数字世界的样子。

你不需要会画星座图；需要会说：

> 调制就是把比特（或话音）翻译成「空中允许的那种波形变化」。

## 第四部分：解调是什么（卸货）

接收端做反向的事：

```text
天线收到已调信号 → 看出它在怎么变 → 还原成话音或比特 → 喇叭/上层协议
                      卸货 = 解调
```

解调要成功，通常需要：

1. **大致在同一频点**（拧对台）；  
2. **信号够强、干扰别太大**（物理条件）；  
3. **双方约定同一套「翻译规则」**（模拟用同类调制；数字还要同一协议、色码、时隙等）。

所以现场「解调失败」可能表现为：没声音、断续、乱码感、数字电台显示收不到同步——原因可能在射频，也可能在参数不一致。

## 第五部分：四件事怎么串在一次通话里

```text
你说话
  → 声码器变成比特（数字）
  → 按 DMR 规则打包成突发
  → 【调制】装到射频载波上
  → 经天线飞出去（占某频点附近一小段带宽）
  → 对方天线收到
  → 【解调】卸下比特
  → 解包、解码成声音
```

对照写频参数：

| 你设的 | 主要影响哪一步 |
|--------|----------------|
| 频点 | 载波在尺子哪一刻度 |
| 信道间隔 | 规划车道多宽、邻道多远 |
| 色码/时隙/地址 | 解调之后「这是不是给我的合法包」 |
| 功率 | 飞多远、干扰别人多狠（不是频率） |

## 第六部分：专门澄清 5 个糊涂点

**糊涂 1：带宽是不是频率？**  
不是。频率是位置；带宽是宽度。

**糊涂 2：12.5 kHz 是不是我的发射频率？**  
一般不是。12.5 kHz 常是**间隔**；发射频率是比如 460.xxx MHz 那种大数字。

**糊涂 3：调制是不是加密？**  
不是。调制是「怎么装上车」；加密是「装车前把内容打乱」。DMR 里还有色码、鉴权等，都和调制不是同一层。

**糊涂 4：解调是不是解码？**  
接近但不等。解调偏「从射频波形拿回基带符号/比特」；后面还有纠错、组帧、声码器解码等。可以说解调是大门第一道。

**糊涂 5：数字就不怕干扰了？**  
不是。数字在干扰下常常撑到某点然后「断崖」，模拟则常「慢慢变差」。干扰仍是物理问题。

## 第七部分：用仓库场景再走一遍

1. 两台机器都写 **同一 MHz 频点** → 站在尺子同一刻度。  
2. 信道间隔都按 **12.5 kHz** 规划理解 → 知道邻道在哪。  
3. A 按 PTT → 比特出来 → **调制**成射频 → 占用该频点附近一窄条带宽飞出。  
4. B **解调** → 若色码/时隙也对 → 听到声音。  
5. 若邻道有大功率电台，你的「车身」被刮到 → 可能误码、断续——这是带宽/间隔/干扰问题，不是「ID 写错」一种原因能概括。
