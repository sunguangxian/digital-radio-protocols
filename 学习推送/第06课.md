# 第 6 课 · 双工、半双工、中继、直通

> DMR 深入学习 · 阶段 A 通信地基  
> 适合：已懂「多人如何分频/分时共用信道」，但还不清楚「说话与听话是同频还是异频、中继到底转了什么」的人  
> 阅读量：约 30–40 分钟 · 几乎不推公式 · 要把「半双工手台 vs 全双工中继」「上行/下行/频差」「直通/绕讲」钉死

## 0. 开课前：加餐四句话复习（带新例子）

若你已读过 `学习推送/加餐_频率带宽与调制解调.md`，下面四句应能脱口而出。本课**不照抄加餐与第 2–5 课**，换成「一座山上的中继台帮两部手台接力」的场景再钉一遍：

| # | 一句话 | 本课用的新例子 |
|---|--------|----------------|
| 1 | **频率** = 信号抖得有多快 | 中继不是「一个频点」，而是**一对频点**：手台听的是下行（例如 `460.125 MHz`），按 PTT 时发的是上行（例如 `450.125 MHz`）。两个中心频率相差一个固定的「频差」 |
| 2 | **带宽** = 频谱尺子上占多宽的一条带子 | 上行、下行各自仍是一条 **12.5 kHz** 规划车道。中继同时收又发，所以频谱上会同时亮着**两条**带子（隔开一定频差），不是把一条 12.5 kHz 撕成两半 |
| 3 | **调制** = 把信息装进适合发射的高频波 | 手台按住 PTT：把语音比特（经声码器）用 **4FSK** 装进**上行**载波；中继收到后，再装进**下行**载波转发出去。装车方式没变，变的是「车开在哪条频点车道上」 |
| 4 | **解调** = 从收到的高频波把信息卸下来 | 对方手台在**下行**频点解调；中继自己的接收机在**上行**频点解调。写频把 RX/TX 写反了，就像拧错台：解调再努力也听不到该听的那一路 |

再补一句和本课主线钉死的对照：

- **直通（同频）**：双方收发都在同一个中心频率上，靠半双工轮流说。  
- **经中继（异频）**：你听下行、发上行；中继同时听上行、发下行——**中继是全双工，手台通常仍是半双工**。

若这四句仍糊：先打开加餐文，再回本课。本课主线是：**谁能同时说与听、中继如何用一对频率接力、直通少了什么、这些词在 DMR 写频与现场怎么落地**。

## 1. 为什么本课重要（动机）

现场与文档里你会反复撞到这些说法：

- 「这是半双工对讲，要按 PTT。」  
- 「中继是收发异频，注意频差 / offset。」  
- 「直通模式 / Direct Mode / Talkaround / 绕讲。」  
- 「手台半双工，中继台全双工——这两个说法不矛盾。」  
- 「DMR 中继一个频点对上两个时隙；直通双时隙更吃同步。」

若只背「中继就是放大信号」六个字，后面读写频软件、跟规划同事对 RX/TX、判断「为什么能听中继却上不去」、区分「同频直通 vs 异频中继」，都会卡在同一处：

> **说话和听话，到底是同一条频率车道，还是一上一下两条？谁必须同时收发？直通又省掉了什么？**

本课目标是让你能自己讲清八件事（仍不推公式）：

1. **单工 / 半双工 / 全双工** 各允许怎样的「说与听」；  
2. 为什么普通对讲机几乎总是 **半双工 + PTT**；  
3. **直通（simplex / direct）** 与 **经中继（repeater）** 的频点关系；  
4. **上行 / 下行 / 频差（offset）** 怎么读、怎么写进 CPS；  
5. 为什么**中继必须接近全双工**，而**用户电台通常仍是半双工**；  
6. **双工器**在中继机柜里干什么（隔离收发，防自己干扰自己）；  
7. DMR 里：中继双时隙、直通模式、绕讲（Talkaround）各落在哪；  
8. 常见误区：把「异频」当成「全双工手台」、把频差写反、以为直通也自动有中继那样的覆盖。

第 7 课才会专讲寻址（个呼/组呼）；本课到「说听方向与中继/直通地图」为止。

## 2. 总图 / 故事：对讲机是「对讲机」，不是「手机」

先把整课装进一张故事图。想象两种「打电话」：

```text
手机通话（全双工直觉）
  你说 ←──同时──→ 对方说
  （两边可以一边说一边听对方插话）

普通对讲（半双工直觉）
  按住 PTT → 只能说
  松开 PTT → 只能听
  （同一时刻，信道上通常只允许一个方向在「大声说话」）

经中继的半双工手台
  你的手台：按住 → 发到「上行」；松开 → 听「下行」
  山上的中继：同时听上行 + 发下行（全双工接力）
              │
              ▼
        覆盖变大、山谷两边能通
```

三句话记牢：

| 场景 | 频点怎么用 | 谁在同时收发 |
|------|------------|--------------|
| **直通** | 双方同一频率轮流说 | 无人需要同时收发；大家半双工 |
| **经中继** | 手台听下行、发上行 | **中继**同时收发；手台仍半双工 |
| **手机式全双工** | 上下行分开且终端也能同时说听 | 基站与手机都按系统设计同时工作 |

DMR 常规对讲的日常体验，更接近表格前两行，而不是手机那一行。

## 3. 白话术语表

| 术语 | 白话 | 现场你会碰到 |
|------|------|----------------|
| **单工 Simplex（狭义通信）** | 只能单向传：A→B，B 不能回 | 广播、遥测；对讲里较少单独拿出来谈 |
| **半双工 Half-duplex** | 能双向，但**同一时刻只能一个方向** | PTT 对讲、大多数手台/车台 |
| **全双工 Full-duplex** | 能双向，且**可同时**说与听 | 手机通话；**中继台本体**必须接近这种能力 |
| **直通 / 同频 / Simplex（对讲习惯）** | 电台之间直接通，收发同频，不经中继 | 「切到直通信道」「车队近距离用直频」 |
| **中继 / Repeater** | 架高处的「接力站」：收一侧频率，几乎同时在另一侧频率转发出去 | 机房中继、楼顶天线、覆盖规划 |
| **上行 Uplink / 输入 Input** | **你发给中继**、中继**接收**的那条频率 | 写频里的 TX（经中继信道时） |
| **下行 Downlink / 输出 Output** | **中继发给你**、你**守听**的那条频率 | 写频里的 RX；别人说「中继频率」常指这条 |
| **频差 / Offset / Split** | 上行与下行中心频率之差（含 +/− 方向） | CPS 里的 Offset、+/-、异频设置 |
| **双工器 Duplexer** | 让收发共用天线（或紧邻）时，用滤波器把上行/下行隔开，避免发射机「震聋」自己的接收机 | 中继机柜旁那组腔体滤波器 |
| **PTT** | Push-To-Talk：按住才发射 | 半双工的操作开关 |
| **直通模式 / Direct Mode（DMR）** | 终端之间不经中继的 DMR 通信（可单时隙或双时隙，看实现与配置） | Tier I、直通信道、应急近距离 |
| **绕讲 / Talkaround** | 仍守听中继**下行**，但发射改到与下行同频（或约定的直通方式），以便近距离不占中继上行 | 专业写频里的 Talkaround；业余侧更常单独建直通信道 |
| **时隙（复习）** | DMR 在 12.5 kHz 载波上切出的 30 ms 时间片 | 中继上 Slot1/Slot2 可跑两路业务 |

## 4. 半双工：为什么对讲要「按着说、松开关听」

### 4.1 机制

半双工允许 A↔B 双向通信，但共享的射频资源在同一时刻通常只给**一个发射方向**。对讲机用 **PTT** 做开关：

- 按下：本机发射机工作，接收支路让路（或明显降敏）；  
- 松开：停止发射，回到接收守听。

这样设计的原因很朴素：

1. **同一天线、同一频点**上，自己的发射功率极大，接收机若同时开着会被「震聋」；  
2. 专业对讲强调**组呼调度**：同一时刻本来就希望信道上主要是一个人在指挥，其他人听；  
3. 硬件更简单、更省电、更便宜——手台不必做成手机那样的同时收发终端。

### 4.2 和「礼貌用语」的关系

半双工没有「边说边听对方插话」的舒适感，所以现场习惯是：说完留空、说「完毕 / OVER」、不要死按 PTT。这不是客套，是**信道使用权**的交接。

### 4.3 对照第 5 课

第 5 课讲的是**多人如何分资源**（FDMA/TDMA）。本课讲的是**一对收发方向如何安排**。两者正交：

- 你可以半双工 + FDMA（模拟常规一个频点一路）；  
- 也可以半双工 + TDMA（DMR：你在自己的 30 ms 时隙里发射，其余时间听）。

---

## 5. 全双工：谁真的需要「同时说与听」

### 5.1 机制

全双工要求设备在发射的同时仍能正常接收。实现上通常要：

- **频率分开**（频分双工 FDD）：上行一条带、下行另一条带；和/或  
- **时间分开**（时分双工 TDD）：严格轮流，但快到用户感觉像同时；  
- 足够好的**隔离**（双工器、天线间距、滤波），让发射能量进不了自己的接收前端。

### 5.2 对讲现场的真相（非常重要）

| 角色 | 典型双工能力 | 原因 |
|------|--------------|------|
| 手台 / 车台用户 | **半双工** | 按 PTT；即使经中继用了两个频率，也是「发的时候不听、听的时候不发」 |
| 中继台 | **全双工（或等效同时收发）** | 必须一边听你的上行，一边把内容转到下行；否则接力断掉 |
| 手机 | 终端侧也按系统设计同时说听 | 蜂窝有严格的上下行资源与功率控制 |

所以同事说「我们是半双工系统」和「中继是全双工」**可以同时成立**：说的是不同设备。

## 6. 直通：同频、面对面（或隔几公里）

### 6.1 机制

```text
手台 A                          手台 B
  RX = f0  ←———— 同频 f0 ————→  RX = f0
  TX = f0                        TX = f0
         （半双工：同一时刻只能一方 TX）
```

特点：

- **配置简单**：双方 RX=TX=同一频点（再加色码、时隙、组呼等数字参数）；  
- **覆盖有限**：受功率、天线高度、遮挡限制，没有「山上大喇叭」帮忙；  
- **不依赖基础设施**：中继停电、机房故障时，近距离直通往往还能救急；  
- **占用行为直观**：同一物理频率上，同时只能有一个强信号主导（模拟更明显；数字还有时隙规则）。

### 6.2 DMR 直通要注意什么

- 仍是 **12.5 kHz** 载波规划；双时隙直通时，双方要对齐时隙节拍（没有中继提供公共节拍时，同步更挑实现与距离）。  
- 写频时色码、时隙、联系人/组呼要一致，否则「有信号却不解」——这和第 5 课「时隙对错」是同一类坑。  
- 专业侧有时把「在中继下行频率上直通」叫 **Talkaround（绕讲）**：你仍能听到中继在喊什么，但近距离互聊不必再占上行；业余爱好者侧更常见做法是单独规划直通频率，避免干扰中继输出。

## 7. 中继：山上的全双工接力站

### 7.1 一句话

中继在高处（或覆盖好的位置）**接收你的上行**，几乎同时在**下行**用更大功率/更好天线把内容转发出去，让山谷两边、楼宇之间原本听不见的手台能互通。

### 7.2 频率故事（请把数字读顺）

业余与专业习惯略有不同，但机制相同。用一个**示意数字**（请按你单位执照与规划替换，不要背成全世界唯一标准）：

```text
约定（示意）：
  下行（中继发、你听）= 460.125 MHz
  上行（你发、中继收）= 450.125 MHz
  频差 offset        = 10 MHz（此处仅为示意；业余 UHF 常见约 5 MHz，VHF 常见约 600 kHz）

你的写频（经中继信道）：
  RX = 460.125 MHz   ← 守听下行
  TX = 450.125 MHz   ← 按 PTT 发上行

中继机柜：
  接收机锁在 450.125（听上行）
  发射机锁在 460.125（发下行）
  双工器把两路隔开，共天线或紧邻天线
```

业余爱好者常说的经验数量级（便于对照文章/视频，**专业执照以批复为准**）：

| 频段直觉 | 常见频差数量级（业余习惯） |
|----------|----------------------------|
| VHF（约 144 MHz 段） | 约 **600 kHz（0.6 MHz）** |
| UHF（约 430/440 MHz 段） | 约 **5 MHz** |

专业对讲的上下行间隔由频率规划和执照决定，可能是几 MHz 到更多，**不要把业余习惯硬套进客户执照**。

### 7.3 为什么必须异频 + 双工器

中继发射功率大、天线高。若收发同频，自己的发射会直接灌进自己的接收机，灵敏度断崖下跌——等于「边喊边聋」。  
所以要：

1. **频差够大**，滤波器才分得开；  
2. **双工器**（或收发天线拉开足够垂直/水平隔离），保证「发的时候还能听」。

这就是「中继全双工」的硬件代价。

### 7.4 和亚音 / 色码的关系（本课只需脸熟）

- 模拟中继常用 **CTCSS/DCS 亚音**：上行带着正确亚音才转发，减少乱触发。  
- DMR 中继用 **Colour Code（色码）** 等数字参数做类似「是不是自己人」的门禁；还有时隙、准入规则等。  
细节留给后面课；本课只要记住：**频率对了只是门槛的一半，门禁参数不对照样上不去。**

### 7.5 DMR 中继多了一层：双时隙

在**同一对**上下行 12.5 kHz 载波上，DMR 中继还可以用 **Slot1 / Slot2** 同时承载两路逻辑业务（复习第 5 课）。  
所以规划同事说「一个中继顶两路」，意思是：

- 频率资源：一对上下行（FDD 味道的中继频点对）；  
- 时间资源：每条下行/上行载波上再切 TDMA 双时隙。

不要说成「中继把载波切成两条 6.25 kHz」——那是假的切法。

## 8. 完整例子：一次「听得见中继、发不上去」的排障

### 8.1 现象

小王听得见调度在中继上下命令，自己按 PTT 讲话，调度说「收不到你」。

### 8.2 用本课语言逐步查

1. **先分清 RX/TX**  
   - 能听到 → 下行 RX、音量、天线大体正常。  
   - 发不上去 → 重点查 **TX 频率是否等于中继上行**、频差方向是否写反、功率、天线、门禁（亚音/色码）、是否选错时隙。

2. **对照写频表（示意）**

| 项 | 正确示意 | 常见错误 |
|----|----------|----------|
| RX | 460.125 | 误写成上行 |
| TX | 450.125 | 误写成与 RX 相同（变成直通，中继听不见你的「下行同频乱喊」或根本不对上行） |
| Offset | −10 MHz（示意） | 方向 +/- 反了 |
| 色码 / 亚音 | 与中继一致 | 差 1 个色码 → 有载波不解/不转发 |
| 时隙 | Slot1 | 业务实际在 Slot2 |

3. **再问覆盖**  
   你在地下室：能勉强听下行（中继功率大），但上行用手台小功率打不穿——这是**链路不对称**，不是「半双工坏了」。解决靠换位置、外接天线、靠近窗口，而不是把频差再改乱。

### 8.3 对照直通救急

若两人距离很近、中继故障：切到约定**直通信道**（RX=TX），半双工对讲即可。这就是基础设施失效时的退路。

## 9. 现场对照速查

| 你听到的话 | 翻译成本课语言 | 你该立刻核对 |
|------------|----------------|--------------|
| 「切直通」 | RX=TX，不经中继 | 双方同频、同色码、同时隙、同组 |
| 「走中继」 | 听下行、发上行 | RX/TX/频差方向、门禁、时隙 |
| 「频差 5 个兆」 | offset ≈ 5 MHz | 是 + 还是 −；RX 到底是哪一个 |
| 「手台半双工」 | 按 PTT 才发 | 不要期望边说边听中继插话的手机体验 |
| 「中继全双工」 | 中继同时收发 | 双工器/隔离是否正常；收发是否互相压死 |
| 「绕讲 / Talkaround」 | 近距离直聊，少占中继上行 | 是否误干扰了别人的下行守听 |
| 「双时隙中继」 | 一对频率 + 两个 30 ms 时隙 | Slot 与组呼规划 |

## 10. 常见误区

1. **「异频 = 手台全双工」**  
   错。异频只说明收发频率不同；手台仍可（且通常）是半双工：发时不听、听时不发。

2. **「中继就是把同一频率放大再发出去」**  
   绝大多数常规中继是**收一个频率、发另一个频率**。同频中继是特殊设计（有额外隔离/时序要求），不能当默认模型。

3. **「写频只填一个频率就够了」**  
   经中继信道至少要成对理解 RX/TX（或频率+offset）。只填一个数时，软件往往默认另一个，**默认错了就全错**。

4. **「能听到中继 = 一定能上中继」**  
   错。下行链路与上行链路不对称很常见。

5. **「直通和中继覆盖一样」**  
   错。直通没有高站接力，覆盖通常小得多。

6. **「DMR 的 6.25e 是把中继上下行各切成 6.25 kHz」**  
   错。6.25e 仍是频谱效率记账（复习第 5 课）；中继上下行各自仍是 12.5 kHz 量级的规划载波（具体以标准与执照为准）。

7. **「半双工所以不需要双时隙同步」**  
   半双工描述的是说听切换；DMR 双时隙直通/中继仍要时隙对齐。两套概念不要并成一句胡话。

## 11. 自测（建议先闭卷做）

**题 1（判断）**  
普通手台通过中继通话时，手台本身通常是全双工的。  
（对 / 错）

**题 2（选择）**  
关于中继，哪一句最准确？  
A. 中继与手台使用完全相同的单一频率，只是功率更大  
B. 中继在上行接收、在下行发射，自身需要同时收发能力  
C. 中继只接收不发射  
D. 中继把 12.5 kHz 真切成两条 6.25 kHz 给两个用户

**题 3（填空）**  
经中继时，你守听的是____行频率；按 PTT 发射的是____行频率。两者中心频率之差叫____。

**题 4（选择）**  
直通模式的核心特征是：  
A. 必须使用互联网  
B. 收发同频、不经中继转发  
C. 手台变成手机式全双工  
D. 只能使用 Slot2

**题 5（简答）**  
用两句话说明：为什么可以说「系统是半双工」同时又说「中继是全双工」？

**题 6（综合）**  
写频显示 RX=`461.000`，TX=`461.000`，同事却说「这是中继信道」。请指出矛盾，并写出经中继时应如何改（用符号说明即可：RX=下行，TX=上行）。

### 参考答案

1. **错。**（手台通常半双工；中继才需要同时收发。）  
2. **B。**  
3. **下；上；频差 / offset。**  
4. **B。**  
5. 「半双工」多指用户电台按 PTT、同一时刻只做一个方向；「中继全双工」指中继设备必须同时听上行并发下行做接力。对象不同。  
6. RX=TX 是直通特征，不是典型中继信道。经中继应改为 RX=中继下行、TX=中继上行（二者相差规划频差），并核对色码/时隙等门禁。
