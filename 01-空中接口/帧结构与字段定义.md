## 2. TDMA 时序核心数字

引用：clauses **3（定义）**, **4.2**, **5.1.2.1**。

| 项 | 值 | 说明 |
|----|-----|------|
| Timeslot（时隙） | **30 ms** | 编号 1 或 2 |
| TDMA frame | **60 ms** | 连续两个 timeslot |
| Traffic burst 内容时长 | **27,5 ms** | 承载 **264 bits** |
| Guard / CACH 间隔 | **约 2,5 ms** | 入站：guard（PA 爬升/传播）；出站：**CACH** |
| Voice superframe | **360 ms** | 连续 **6** 个 traffic burst，标号 **A–F** |
| Traffic burst 总比特 | **264** | = 108 + 48 + 108 |
| Payload（语音） | **216 bits** | 两段 108；可承载约 60 ms 压缩语音 |
| CACH burst | **24 bits** | 仅出站；每 30 ms 一次 |
| Standalone RC burst | **96 bits** | 48 SYNC + 48 嵌入信令窗口 |

```text
                    一个 TDMA frame = 60 ms
        ┌─────────────────────┬─────────────────────┐
        │     Timeslot 1      │     Timeslot 2      │
        │       30 ms         │       30 ms         │
        └─────────────────────┴─────────────────────┘

入站（MS→BS）典型：
  [ payload | SYNC/EMB | payload |==== 2.5 ms guard ====| … ]
出站（BS→MS）典型：
  [ payload | SYNC/EMB | payload |==== 2.5 ms CACH ====| … ]
```

要点（clause 4.2.1）：

- 入/出站突发**中心对齐**；入站相对出站常见 **30 ms** 偏移编号方案，便于 CACH 用同一信道号指入/出站。
- 语音与数据使用**不同 SYNC 图案**；入站与出站图案亦不同。
- Colour Code (CC) 出现在嵌入信令与一般数据突发中，用于区分同频系统。

## 3. 通用突发内部布局（108 + 48 + 108）

引用：clause **4.2.2** figure 4.3；语音 **6.1**；数据 **6.2**。

```text
                         一个 Traffic burst = 264 bits ≈ 27,5 ms
        ┌──────────────────┬──────────────────┬──────────────────┐
        │   108 bits       │     48 bits      │   108 bits       │
        │   Payload        │ SYNC 或 嵌入信令 │   Payload        │
        └──────────────────┴──────────────────┴──────────────────┘
              ▲                    ▲                    ▲
              │                    │                    │
         VS / Info            中心场                  VS / Info
         (左半)               (便于 RC)               (右半)

时隙总长 30,0 ms = 27,5 ms 内容 + 2,5 ms (guard 或 CACH)
中间 48 bits 场宽约 5,0 ms（规范图注）
```

### 3.1 语音突发（Vocoder socket）— clause 6.1

| 场 | 比特 | 用途 |
|----|------|------|
| Voice payload 左 | 108 | VS(215)…VS(108) |
| SYNC **或** EMB+嵌入 | 48 | 超帧 A：Voice SYNC；B–F：嵌入 |
| Voice payload 右 | 108 | VS(107)…VS(0) |

例：20 ms 声码帧时，一突发可携带 3×72 bit（含 FEC）声码帧 + 48 bit 中心场。

**带嵌入信令时中心 48 bit 再分**（figure 6.4）：

```text
  Voice(108) | EMB(8) | Embedded signalling(32) | EMB(8) | Voice(108)
               └──────── EMB PDU 共 16 bit ────────┘
```

EMB 信息元见下文 §7 / Table 9.3。

### 3.2 一般数据/控制突发 — clause 6.2

数据突发将两侧 payload 收为 **98 + 98 = 196** 信息比特，并腾出 **20 bit Slot Type (SLOT)**：

```text
  Info(98) | SlotType(10) | SYNC或嵌入(48) | SlotType(10) | Info(98)
             └──────── SLOT PDU 共 20 bit ────────┘
```

| 场 | 比特 | 用途 |
|----|------|------|
| Info（左/右） | 98+98 | 经 FEC 后的控制/数据载荷 |
| SLOT | 20 | CC(4)+Data Type(4)+Parity(12) |
| 中心 | 48 | Data SYNC 或 RC 等嵌入 |

**Data Type**（Table 6.1 / 9.22）决定 196 信息比特含义与 FEC：

| Data Type（摘要） | 用途 | 典型 Payload FEC |
|-------------------|------|------------------|
| PI Header | 隐私指示（本文件保留） | BPTC(196,96) |
| Voice LC Header | 语音开始，携带地址 | BPTC(196,96) |
| Terminator with LC | 语音结束，带 LC | BPTC(196,96) |
| CSBK | 控制信令块 | BPTC(196,96) |
| MBC Header / Continuation | 多块控制 | BPTC(196,96) |
| Data Header | 分组数据头（寻址/编号） | BPTC(196,96) |
| Rate ½ / ¾ / 1 Data | 分组数据续块 | BPTC 或 Trellis |
| Idle | 填充 | BPTC(196,96) |
| Unified Single Block Data | 单块控制/数据 | BPTC(196,96) |

编码值见 §8 Table 9.22。

## 4. 语音超帧 A–F / 360 ms

引用：clause **5.1.2.1** figure 5.3；嵌入 **7.1.3**。

```text
  … F | A | B | C | D | E | F | A | B …
        └────────── Voice superframe = 360 ms ──────────┘

  Burst A : 中心 = Voice SYNC（超帧边界；支持 late entry）
  Burst B–E: 中心 = 嵌入 LC 分片（典型 4 突发拼完一条 Full LC）
  Burst F : 出站可为 RC / Privacy / Null；入站常为 Null 嵌入
```

| 项 | 约定 |
|----|------|
| 超帧长度 | 6 bursts × 30 ms = **360 ms** |
| SYNC 机会（语音） | 每逻辑信道约每 **360 ms**（burst A） |
| LC 嵌入起点 | 超帧内第一个非 SYNC 突发（burst **B**） |
| 一条 Full LC | 72 bit LC + FEC 后拆入 **4** 个嵌入场（BPTC，见 Annex B.2.1） |
| 常规语音发起 | Voice LC Header（可选再 PI Header）→ 再进超帧 A…（5.1.2.2） |
| 语音结束 | 末语音突发后可跟 Terminator with LC（数据 SYNC）（5.1.2.3 / 7.1.2） |

SYNC 疏密对照（clause 4.3）：

| 方向 | 数据/控制 SYNC | 语音 SYNC | 最坏情形（语音） |
|------|----------------|-----------|------------------|
| 入站 | 可至约每 **60 ms** | 每 **360 ms** | — |
| 出站 | 双时隙可见可至约每 **30 ms** | 每信道 **360 ms** | 双语音超帧错 30 ms → 约 **330 ms** |

## 5. CACH 结构与字段

引用：clauses **4.5**, **6.3**, **9.1.4**。

- **仅出站**；夹在两 outbound burst 之间；与 slot 1/2 **共用**。
- 每 **30 ms** 一个 CACH → 载荷约 **17 bit / 30 ms ≈ 566,67 bit/s**（TACT 另计）。
- 用途：① 入站时隙 Idle/Busy（AT）；② 信道号 1/2（TC）；③ 低速 Short LC（LCSS 分片）。

```text
  Outbound burst          CACH (24)         Outbound burst
  ├─ 30 ms ─┤            ├─ 2.5 ms ─┤      ├─ 30 ms ─┤

  CACH 24 bits（交织后）：
  ┌────┬────┬──────┬─────┬────────────────────┐
  │ AT │ TC │ LCSS │ FEC │  Signalling (17)   │
  │ 1  │ 1  │  2   │  3  │  (无 CACH 层 FEC)  │
  └────┴────┴──────┴─────┴────────────────────┘
        └──── TACT PDU = 7 bits ────┘
              Hamming (7,4)
```

### TACT PDU（Table 9.5）— 7 bits

| Information element | Length | 含义 |
|---------------------|--------|------|
| Access Type (**AT**) | 1 | `0` 入站 idle；`1` 入站 busy（连续发模式 AT=1） |
| TDMA Channel (**TC**) | 1 | `0` 随后 outbound 为 ch1；`1` 为 ch2 |
| Link Control Start/Stop (**LCSS**) | 2 | Short LC / CSBK 分片起止（见 LCSS 表） |
| TACT parity | 3 | Hamming (7,4) |

时序直觉（figure 4.8 / 4.9）：某 CACH 指示的入站 busy/信道号相对 outbound **延迟约一个时隙**，给 MS 解码与收发切换时间。

无 CACH 载荷时发送 Null Short LC（Part 2 `Nul_Msg`，SLCO=`0000`）。

## 6. SYNC 类型（摘要）

引用：clauses **4.3**, **9.1.1** Tables 9.1–9.2。

| 项 | 值 |
|----|-----|
| SYNC PDU 长度 | **48 bits** |
| 语音 vs 数据 | 图案**逐符号互补**（单相关器：语音正峰 / 数据负峰） |

已定义图案类别（不在此复制 hex/bit 全文；实现查 Table 9.2）：

| 类别 | 区分目的 |
|------|----------|
| BS sourced Voice / Data | 基站出站语音 vs 数据 |
| MS sourced Voice / Data | 移动台上行语音 vs 数据 |
| MS sourced standalone RC | 独立反向信道 |
| TDMA DM TS1 Voice / Data | 直通时隙 1 |
| TDMA DM TS2 Voice / Data | 直通时隙 2 |
| Reserved | 预留 |

规则摘要：两频 BS 入站与单频传输的**首突发必须带 SYNC**；后续按突发类型填 SYNC 或嵌入。

## 7. 关键 Layer 2 PDU 与字段布局

引用：clause **9.1**。八位组级 CSBK/LC/EMB 与 FEC 名称表见 [`CSBK与LC字段详表.md`](./CSBK与LC字段详表.md)。

### 7.0 八位组外壳对照（ASCII）

```text
FULL LC (figure 7.1):
  [PF|R|FLCO][FID][-------- Full LC Data 56 --------][+CRC]
CSBK (figure 7.8):
  [LB|PF|CSBKO][FID][-------- CSBK Data 64 --------][CRC-16]
SHORT LC (figure 7.2):
  [SLCO][---- Short LC Data 24 ----][CRC-8]
EMB 在突发中心两侧各 8 bit，夹 32 bit 嵌入载荷。
```

### 7.1 EMB PDU（Table 9.3）— 16 bits

| IE | Len | 备注 |
|----|-----|------|
| Colour Code (CC) | 4 | |
| Pre-emption and power control Indicator (PI) | 1 | `0` 本逻辑信道/Null；`1` 对端 RC（对齐定时） |
| Link Control Start/Stop (LCSS) | 2 | 见 §8 |
| EMB parity | 9 | Quadratic Residue (16,7,6) |

### 7.2 SLOT PDU（Table 9.4）— 20 bits

| IE | Len | 备注 |
|----|-----|------|
| Colour Code (CC) | 4 | |
| Data Type | 4 | Table 9.22 |
| Slot Type parity | 12 | Golay (20,8) |

### 7.3 FULL LC PDU（Table 9.7）

头/终止突发 **96 bits**；嵌入路径信息场 **77 bits**（CRC 变短）。

| IE | Len | 备注 |
|----|-----|------|
| Protect Flag (PF) | 1 | 现行规范置 `0` |
| Reserved | 1 | |
| Full Link Control Opcode (**FLCO**) | 6 | 细则 Part 2 |
| Feature set ID (**FID**) | 8 | SFID / MFID |
| Full LC Data | 56 | 特性相关（如源/目的地址） |
| Full LC CRC | 24 或 5 | 头/终止 RS(12,9)；嵌入 5-bit checksum |

消息结构直觉（figure 7.1）：Octet0 = PF|R|FLCO；Octet1 = FID；Octet2–8 = Data（72 bit 信息场）。

### 7.4 SHORT LC PDU（Table 9.8）— 36 bits（经 CACH）

| IE | Len | 备注 |
|----|-----|------|
| Short LC Opcode (**SLCO**) | 4 | 细则 Part 2 |
| Short LC Data | 24 | |
| Short LC CRC | 8 | |

figure 7.2：28 bit 信息场（SLCO+Data）+ CRC → CACH 侧再 BPTC（Annex B.2.3）。

### 7.5 CSBK PDU（Table 9.9）— 96 bits

| IE | Len | 备注 |
|----|-----|------|
| Last Block (LB) | 1 | 单块 CSBK 置 `1` |
| Protect Flag | 1 | |
| CSBK Opcode (**CSBKO**) | 6 | 细则 Part 2 |
| FID | 8 | |
| CSBK Data | 64 | |
| CSBK CRC | 16 | CRC-CCITT |

figure 7.8 直觉：Octet0 = LB|PF|CSBKO；Octet1 = FID；其后 Data。

业务体（UU_V_Req、NACK、Pre_CSBK、CT_CSBK 等）八位组表 → Part 2；Tier III（C_GRANT、C_ALOHA…）→ Part 4。外壳字段详表 → [`CSBK与LC字段详表.md`](./CSBK与LC字段详表.md)。

### 7.6 RC PDU（Table 9.6）— 32 bits

| IE | Len | 备注 |
|----|-----|------|
| RC Info Payload | 4 | 内容见 Part 4 |
| RC Info CRC | 7 | |
| RC parity | 21 | Single Burst BPTC |

### 7.7 其它

| PDU | 长度 | 用途 |
|-----|------|------|
| PR FILL | 96 | Idle 填充（clause 7.3 / D.2） |
